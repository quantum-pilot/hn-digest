# Scripts I wrote that I use all the time

- Score: 414 | [HN](https://news.ycombinator.com/item?id=45670052) | Link: https://evanhahn.com/scripts-i-wrote-that-i-use-all-the-time/

### TL;DR

Evan Hahn catalogs small scripts accumulated over more than a decade of dotfile maintenance, ranging from clipboard wrappers and disposable directories to media downloaders, text filters, timers, process helpers, REPL launchers, notifications, and theme switching. Crucially, he states how often each tool is used and links its source, turning a personal configuration dump into a practical workflow inventory. The collection favors memorable commands and cross-platform consistency, even when native utilities already provide similar behavior, because reducing friction makes recurring tasks composable and habitual.

### Comment pulse

- Readers suggested native replacements such as `trash`, `uuidgen`, `jq`, Python's JSON tool, and `sed`.
- Debate contrasted deeply customized environments with portable, mostly vanilla shells across many machines.

### LLM perspective

- View: The strongest idea is measuring personal tooling by repeated friction removed, not novelty or code volume.
- Impact: Tiny stable commands can turn awkward occasional operations into dependable building blocks for new workflows.
