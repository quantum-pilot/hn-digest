# Playball – Watch MLB games from a terminal

- Score: 280 | [HN](https://news.ycombinator.com/item?id=45451577) | Link: https://github.com/paaatrick/playball

### TL;DR

Playball is an MIT-licensed terminal interface for following Major League Baseball without video. It presents schedules, standings, scores, base state, counts, and a scrollable play-by-play view, with keyboard navigation modeled on familiar terminal controls. Users can try it through `npx`, install it globally through npm, or run a Docker image. Configuration covers colors and highlighted favorite teams. The project uses MLB's accessible game-data endpoints, turning baseball's unusually structured event stream into a compact, discreet live display.
