# Typst 0.14

- Score: 504 | [HN](https://news.ycombinator.com/item?id=45693978) | Link: https://typst.app/blog/2025/typst-0.14/

### TL;DR

Typst 0.14 makes tagged PDFs the default and adds optional PDF/UA-1 checks for missing titles, heading-order problems and absent alternative text. It supports multiple PDF and PDF/A versions, embeds PDF pages as images across output formats through a portable Rust library, and introduces character-level spacing for better justification. Experimental HTML export now maps most semantic model elements and offers typed element construction, though styling-heavy elements remain incomplete. Migration is relatively calm, with stricter validation, a few renames and a web-app assistant that compares projects across compiler versions.
