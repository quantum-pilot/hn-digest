# Asahi Linux Still Working on Apple M3 Support, M1n1 Bootloader Going Rust

- Score: 258 | [HN](https://news.ycombinator.com/item?id=45694767) | Link: https://www.phoronix.com/news/Asahi-Linux-M3-m1n1-Update

### TL;DR

Asahi Linux’s latest progress includes upstream kernel work for Linux 6.17 and 6.18, device trees for several M2 variants, expanding game support, and Wine running outside muvm. The m1n1 bootloader is moving toward Rust for maintainability and safety. Early M3 bring-up can initialize cores and key peripherals and boot an Asahi kernel, but currently reaches only a blinking cursor, so it is a reverse-engineering milestone rather than usable support. Commenters debated whether annual Apple chips make sustained hardware enablement impractical.
