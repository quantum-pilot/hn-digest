# Superpowers: How I'm using coding agents in October 2025

- Score: 335 | [HN](https://news.ycombinator.com/item?id=45547344) | Link: https://blog.fsck.com/2025/10/09/superpowers/

### TL;DR

“Superpowers” packages the author’s coding-agent practices as Claude Code skills: mandatory skill discovery, brainstorming before implementation, saved plans, isolated Git worktrees, test-driven development, sequential subagents, code review, and structured finishing choices. Skills are themselves generated, revised, and tested through realistic pressure scenarios rather than quizzes. The author also describes mining past conversation notes for reusable procedures and an unfinished searchable memory system. The project shipped early with Anthropic’s plugin framework; sharing and memory integration remain incomplete, and the author flags unresolved intellectual-property concerns around skills extracted from books.

### Comment pulse

- Supporters saw reusable behavioral instructions as an ambitious way to systematize agent workflows and institutional learning.
- Critics requested concrete outcome metrics and questioned whether dramatic persuasion language improves modern models or merely increases prompt maintenance.

### LLM perspective

- View: The valuable abstraction is versioned operational knowledge, not the “superpower” framing or anthropomorphic pressure tests.
- Impact: Skills can make recurring engineering discipline portable, but brittle mandates may outlive the model behavior they target.
- Watch next: Measured coding outcomes, realistic skill evaluations, consentful sharing, memory quality, and prompt simplification.
