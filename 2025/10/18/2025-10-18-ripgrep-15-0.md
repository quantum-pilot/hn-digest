# Ripgrep 15.0

- Score: 348 | [HN](https://news.ycombinator.com/item?id=45627324) | Link: https://github.com/BurntSushi/ripgrep/releases/tag/15.0.0

### TL;DR

Ripgrep 15.0 is a maintenance-heavy major release fixing parent-directory gitignore behavior, large-ignore-file memory regression, multiline replacement panics, incorrect statistics, and several edge cases. Smaller features include replacement with JSON output, Jujutsu repository ignore support, nested glob alternates, improved file types and shell completions, plus Windows ARM64 artifacts. Full link-time optimization modestly shrinks and speeds binaries. Commenters celebrated ripgrep’s practical defaults, code quality, speed, and usefulness for navigating old codebases and enabling agent-driven code exploration.
