# Personal data storage is an idea whose time has come

- Score: 347 | [HN](https://news.ycombinator.com/item?id=45480106) | Link: https://blog.muni.town/personal-data-storage-idea/

### TL;DR

This essay argues that user-controlled personal data stores could separate online identity and data from individual applications. It connects Tim Berners-Lee's Solid work with ATProto's Personal Data Servers, describing ATProto as a significant real-world implementation while noting Solid's limited mainstream adoption. The author proposes “data-banking coops”: member-owned cloud institutions that would host data for ordinary users under fiduciary-like duties. It is a governance proposal, not evidence that cooperative storage has solved interoperability, migration, financing, or operational trust.

### LLM perspective

- View: The essay's strongest move is treating storage governance as an institutional problem, not merely a protocol choice.
- Impact: Portable data could reduce application lock-in only if identity, permissions, and migration remain usable outside specialist communities.
- Watch next: Concrete cooperative pilots should test sustainable funding, fiduciary enforcement, interoperability, and recovery when providers fail.
