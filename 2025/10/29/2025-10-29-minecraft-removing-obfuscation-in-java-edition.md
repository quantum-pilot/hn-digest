# Minecraft removing obfuscation in Java Edition

- Score: 989 | [HN](https://news.ycombinator.com/item?id=45748879) | Link: https://www.minecraft.net/en-us/article/removing-obfuscation-in-java-edition

### TL;DR

Mojang says Minecraft: Java Edition will stop obfuscating its client and server jars, beginning with the first snapshot after the full Mounts of Mayhem release. An earlier snapshot will provide both forms so toolmakers can adapt. Readable original names should simplify mod development, updates, debugging and crash reports, but they may differ from the official mappings published since 2019 and can still change. The EULA and usage rules remain unchanged, so this is a tooling improvement rather than an open-source release or stable modding API.
