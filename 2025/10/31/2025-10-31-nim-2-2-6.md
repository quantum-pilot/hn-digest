# Nim 2.2.6

- Score: 144 | [HN](https://news.ycombinator.com/item?id=45772224) | Link: https://nim-lang.org//blog/2025/10/31/nim-226.html

### TL;DR

Nim 2.2.6 is the third patch release in the stable 2.2 line, arriving six months after 2.2.4 with 141 commits. Its headline changes rewrite the closure-iterator transformation to stabilize exception handling with async code and let `return obj.field` move rather than copy. The long fix list spans crashes, code generation, ownership, iterators, VM behavior, and performance. Commenters praise Nim’s C interoperability and concise systems programming, but flag ecosystem maintenance, compiler rough edges, and contentious project governance as adoption risks.
