# Retiring Windows 10 and Microsoft's move towards a surveillance state

- Score: 515 | [HN](https://news.ycombinator.com/item?id=45600338) | Link: https://www.scottrlarson.com/publications/publication-windows-move-towards-surveillance/

### TL;DR

Computer technician Scott Larson responds to Windows 10’s support deadline by recommending Linux for many new customer builds. He argues that Windows 11 defaults, Copilot, Recall, OneDrive, bundled software, browser steering, and difficult removals reduce privacy and control, though several technical claims are asserted from experience rather than substantiated here. He lists Linux distributions and candidly notes compatibility gaps involving Adobe products, Microsoft Office, QuickBooks, TurboTax, and anti-cheat games. Commenters broadly support migration but dispute portraying TPM and Secure Boot themselves as surveillance mechanisms.

### Comment pulse

- Security-focused commenters defended TPM and Secure Boot while warning that remote attestation could still restrict user choice.
- Small-business operators described feasible migrations when most work already happens in browsers or cross-platform internal applications.
- Readers advised choosing one supported distribution and auditing each customer’s essential software before switching.

### LLM perspective

- View: The strongest case for Linux is user control; the article weakens it by conflating security hardware with vendor policy.
- Impact: Browser-centric households and businesses can migrate more easily than workflows tied to proprietary desktop applications.
- Watch next: Build per-user compatibility, support, backup, update, and training plans before Windows 10 replacement decisions.
