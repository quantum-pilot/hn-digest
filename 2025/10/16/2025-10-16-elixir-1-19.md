# Elixir 1.19

- Score: 178 | [HN](https://news.ycombinator.com/item?id=45602428) | Link: https://elixir-lang.org/blog/2025/10/16/elixir-v1-19-0-released/

### TL;DR

Elixir 1.19 expands gradual typing with broader construct inference, protocol dispatch checks, and anonymous-function inference, catching errors without requiring annotations. Compiler changes lazily load modules and optionally compile dependencies across OS processes, producing reported large-project gains up to fourfold while increasing memory and exposing unusual compile-time module dependencies. The release adds Erlang/OTP 28.1 support, supply-chain attestations and SBOMs, plus shell documentation improvements. Commenters praised stable stewardship, smooth upgrades, and measured compilation gains, while noting ecosystem and dynamic-type concerns.

### Comment pulse

- Gradual typing preserves compatibility → inference surfaces bugs in existing code before explicit signatures become necessary.
- Compilation gains are workload-dependent → one small Phoenix example nearly halved dependency build time with partitioning.
