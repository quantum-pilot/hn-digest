# Mac Source Ports – Run old games on new Macs

- Score: 152 | [HN](https://news.ycombinator.com/item?id=45591865) | Link: https://www.macsourceports.com/

### TL;DR

Mac Source Ports catalogs native builds that let modern Apple Silicon and Intel Macs run older games when users supply legally obtained data files. The displayed Carmageddon entry uses the reverse-engineered Dethrace port, marked early access, signed, notarized, and compatible with macOS 10.15 onward. Commenters valued the site as both a preservation resource and an incidental directory of Linux-friendly ports, while requesting easier browsing and discussing source releases, browser ports, aging discs, and safe acquisition of original assets.

### Comment pulse
