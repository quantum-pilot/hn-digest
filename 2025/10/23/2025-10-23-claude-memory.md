# Claude Memory

- Score: 328 | [HN](https://news.ycombinator.com/item?id=45684134) | Link: https://www.anthropic.com/news/memory

### TL;DR

Anthropic is extending optional Claude memory to Pro and Max users after launching it for Team and Enterprise. Users can initialize memory from prior chats, inspect or edit its summary, keep memories separated by project, and use incognito chats that neither read nor save memory. Enterprise administrators may disable the feature. Anthropic says it tested risks including harmful reinforcement and safeguard bypasses, but commenters remain split between convenience for recurring context and concern that invisible, stale, or incorrect memories will confound results.

### Comment pulse

- Supporters value carrying stable preferences and setup details across loosely phrased requests.
- Skeptics want per-chat previews or confirmation because stale memories may leak irrelevant context and reinforce errors.
