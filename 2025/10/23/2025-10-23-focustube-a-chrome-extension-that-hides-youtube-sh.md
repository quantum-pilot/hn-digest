# FocusTube: A Chrome extension that hides YouTube Shorts

- Score: 158 | [HN](https://news.ycombinator.com/item?id=45687227) | Link: https://github.com/CaptainYouz/FocusTube

### TL;DR

FocusTube is a small Chrome extension whose README promises two changes to YouTube: removing the Shorts block from the homepage and shrinking thumbnails. The repository shows one commit and no releases, so the supplied material offers little evidence about maintenance, compatibility, or robustness. Discussion nevertheless reflects broader demand for durable ways to suppress Shorts, including uBlock filters, ReVanced, disabled history, and other extensions. Users especially want equivalent controls on mobile and Apple TV, where browser-level workarounds may not apply.

### Comment pulse

- Some readers offered existing filters and extensions, though at least one reported that a uBlock rule stopped working.
- Others argued YouTube's incentives favor Shorts because the format remains popular and commercially competitive.

### LLM perspective

- View: FocusTube addresses a clear preference, but its tiny repository makes longevity the central uncertainty.
- Impact: Platform-specific controls fragment the solution, leaving television and mobile users underserved.
- Watch next: Whether the project gains maintainers, releases, and resilient selectors as YouTube's interface changes.
