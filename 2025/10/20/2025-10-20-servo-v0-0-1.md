# Servo v0.0.1

- Score: 454 | [HN](https://news.ycombinator.com/item?id=45643357) | Link: https://github.com/servo/servo

### TL;DR

Servo tagged v0.0.1, turning a recent servoshell nightly into a manually tested GitHub release for its supported platforms. According to the release details quoted in discussion, this is primarily a new monthly release cadence and reference point, not a feature-packed milestone; there are no current plans for crates.io or app-store distribution. Servo positions itself as a lightweight, high-performance engine for embedding web technologies. Early commenter testing found text-heavy sites promising but more customized layouts inconsistent, with memory use reportedly above Firefox in that small anecdotal trial.
