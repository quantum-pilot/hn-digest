# Qt Creator 18 Released

- Score: 131 | [HN](https://news.ycombinator.com/item?id=45761789) | Link: https://www.qt.io/blog/qt-creator-18-released

### TL;DR

Qt Creator 18 adds experimental Development Container support that detects `devcontainer.json`, creates Docker environments, and discovers or accepts custom kits. The release also introduces optional editor tabs, Clangd/LLVM 21.1, newer C++ fixes, independent QML language-server downloads, GitHub Enterprise Copilot, CMake Test Presets, better remote-device tooling, synchronized run configurations, and expanded Git actions. Project settings move into `.qtcreator/` while old files remain compatible. HN discussion is mostly appreciative, recalling Qt Creator as a lightweight, capable cross-platform C++ IDE.
