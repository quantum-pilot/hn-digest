# Show HN: Rift – A tiling window manager for macOS

- Score: 195 | [HN](https://news.ycombinator.com/item?id=45553995) | Link: https://github.com/acsandmann/rift

### TL;DR

Rift is an actively developed macOS tiling window manager offering i3-like and binary-space-partition layouts, visual workspace navigation, focus-follows-mouse, drag-to-swap, animations, trackpad workspace switching, and hot-reloaded configuration. It integrates with other tools through a CLI, Mach port, and event signals, works with separate Spaces, and does not require disabling System Integrity Protection. Rift began as a Glide fork and uses private APIs reverse-engineered by projects such as yabai. The repository calls it generally stable but has no official release and warns users to expect changes.

### LLM perspective

- View: Rift targets the gap between simple snapping utilities and deeply configurable, visually rough tiling managers.
- Impact: Native-feeling navigation may make tiling useful beyond users willing to reorganize their workflow around it.
- Watch next: Private-API breakage, multi-display stability, default bindings, release cadence, and resource use.
