# Show HN: I made an esoteric programming language that's read like a spellbook

- Score: 129 | [HN](https://news.ycombinator.com/item?id=45555523) | Link: https://github.com/sirbread/spellscript

### TL;DR

Spellscript is a Python-based esoteric language designed so programs read like magical incantations in a “grimoire.” It maps familiar constructs to themed prose: variables are summoned or enchanted, functions become rituals, strings are whispers, and output is inscribed. The interpreter supports dynamic typing, arrays, functions, loops, conditionals, conversion, input, and string operations without requiring indentation or newlines. Intentional limitations include no recursion, comments, modulo, nested arrays, null, string indexing, or loop breaks, making it primarily a playful language-design exercise rather than practical tooling.
