# Context is the bottleneck for coding agents now

- Score: 164 | [HN](https://news.ycombinator.com/item?id=45387374) | Link: https://runnercode.com/blog/context-is-the-bottleneck-for-coding-agents-now

### TL;DR

The author argues that coding agents reliably handle commits but not major features because their bottleneck is organizational context rather than programming intelligence. Beyond code and documentation, agents need architecture, conventions, historical rationale, deployment practices, product requirements, and knowledge scattered across reviews, incidents, conversations, and developers' heads. The proposed path is broader access, preprocessing that reconciles conflicting material, continued expert input, and agents that recognize uncertainty and ask questions. Commenters counter that attention, intent, and reasoning still fail even when context is available.

### Comment pulse

- Several readers say stale exploration overwhelms later corrections, making selective forgetting and focus more important than larger windows.
