# Claude Code 2.0

- Score: 615 | [HN](https://news.ycombinator.com/item?id=45416228) | Link: https://www.npmjs.com/package/@anthropic-ai/claude-code

### TL;DR

The supplied npm page describes Claude Code as a terminal and IDE agent for codebase tasks, but displays version 1.0.89 rather than 2.0. HN commenters supplied the apparent 2.0 changelog: a native VS Code extension, conversation rewind with code rollback, usage visibility, persistent thinking controls, history search, UI changes, hook fixes, and a renamed Agent SDK with dynamically configured subagents. Reception welcomed checkpoints and broader automation, while raising extension bugs, high terminal-memory use, dangerous shell capabilities, cost, and conversation-data handling.

### Comment pulse

- Checkpoints solve a real pain → rewind makes experimental agent edits easier to undo, though version-control tools can offer richer history.
- Coding agents are general shell agents → broad command access enables media and document tasks but requires strong isolation and permissions.
- Privacy wording unsettled users → paid customers questioned collection of usage, conversations, and feedback despite stated training restrictions.
