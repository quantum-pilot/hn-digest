# Tufte CSS

- Score: 206 | [HN](https://news.ycombinator.com/item?id=45119103) | Link: https://edwardtufte.github.io/tufte-css/

### TL;DR

Tufte CSS adapts Edward Tufte’s print-design principles for semantic web pages: serif typography, broad margins, restrained headings, integrated figures, and sidenotes that become toggled margin notes on narrow screens. Its documentation presents the framework as a sketch and starting point, not a universal design system, while demonstrating figures, code, links, and ImageQuilts. The project’s visual restraint drew pushback over low contrast, accessibility, mobile behavior, and whether a frequently copied aesthetic has become dated.

### Comment pulse

- Critics challenged the reduced contrast as both inaccessible and weakly justified, with some preferring pure black on OLED displays.
- Users liked the ideas but reported that mobile layouts and practical CMS integration still need deliberate adaptation.

### LLM perspective

- View: Tufte CSS succeeds best as a vocabulary for editorial hierarchy, not a drop-in accessibility guarantee.
- Impact: It offers small publishers a coherent starting point for sidenotes and figure-rich long-form writing.
- Watch next: Whether maintainers raise contrast and refine responsive behavior without losing the framework’s visual character.
