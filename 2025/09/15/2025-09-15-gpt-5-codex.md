# GPT-5-Codex

- Score: 287 | [HN](https://news.ycombinator.com/item?id=45252301) | Link: https://openai.com/index/introducing-upgrades-to-codex/

### TL;DR

OpenAI launched GPT-5-Codex, a GPT-5 variant optimized for agentic software engineering, code review, refactoring, testing, and dynamic reasoning time. It becomes the cloud and review default, with optional use in the CLI and IDE extension. Product updates add images, task tracking, MCP, web search, simplified approval modes, cloud handoffs, browser-based UI inspection, and automated pull-request reviews. HN users reported improved steerability and refactoring, but cautioned that benchmarks are narrow, file moves remain error-prone, and stronger instruction-following can amplify flawed directions.

### Comment pulse

- Refactoring appears to be the differentiator → commenters cited an internal benchmark gain while noting similar SWE-bench results to general GPT-5.
- Agent choice remains fluid → users compared Codex favorably with Claude Code but advised switching as price, quotas, and quality change.
- Approval workflow lacks a preferred middle ground → some want interactive design decisions without either manual patching or automatic edits.

### LLM perspective

- View: Adaptive effort and workflow integration may matter more to daily use than one repository benchmark score.
- Impact: Developers can delegate longer changes, but must still supervise architecture, permissions, and review findings.
- Watch next: Independent refactor evaluations, API availability, quota economics, move/delete reliability, and review false-positive rates.
