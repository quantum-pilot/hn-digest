# SGI demos from long ago in the browser via WASM

- Score: 232 | [HN](https://news.ycombinator.com/item?id=45330407) | Link: https://github.com/sgi-demos

### TL;DR

The sgi-demos project preserves original Silicon Graphics demonstrations by compiling their C and C++ sources to browser-ready JavaScript and WebAssembly with Emscripten and SDL2. An IRIS GL software rasterizer from Alice 4 handles rendering, while translated SDL events feed the old GL event system; maintainers say source changes are minimal despite 35 years of compiler evolution. HN discussion is chiefly nostalgic, connecting SGI aesthetics to Super Mario 64 and recalling once-extraordinary research workstations, permissive network access, and workplace pranks.
