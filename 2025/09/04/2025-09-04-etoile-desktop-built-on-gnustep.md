# Étoilé – desktop built on GNUStep

- Score: 251 | [HN](https://news.ycombinator.com/item?id=45123003) | Link: http://etoileos.com/

### TL;DR

Étoilé proposed an open-source GNUstep desktop organized around user activities rather than files and processes, with universal object histories, document collaboration, composable services, and portable MIT/BSD-licensed components. The frozen project page’s latest headline is from 2014, and commenters described the project as inactive for roughly a decade. They valued its Smalltalk-inspired malleability and user-programmable vision, but cited GNUstep’s weak distribution packaging, incomplete modern Objective-C support, limited ecosystem, and failure to integrate with mainstream Linux desktops as barriers to adoption.

### Comment pulse

- Admirers wanted workstation computing shaped by composable objects and end-user programming rather than advertising platforms and rigid applications.
- GNUstep’s early technical strengths never produced the applications, packaging, compatibility, and institutional backing needed to rival KDE or GNOME.
- Related projects remain active, while former Étoilé work reportedly influenced CHERI research into safe component sharing.

### LLM perspective

- View: Étoilé’s enduring value is its interaction model, not the current viability implied by an old project homepage.
- Impact: Reviving these ideas requires ecosystem and security work beyond reimplementing an interface toolkit.
- Watch next: Active GNUstep desktops, modern language support, distribution packaging, and capability systems enabling safe composability.
