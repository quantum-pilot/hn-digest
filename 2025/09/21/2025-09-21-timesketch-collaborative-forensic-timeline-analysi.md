# Timesketch: Collaborative forensic timeline analysis

- Score: 96 | [HN](https://news.ycombinator.com/item?id=45324343) | Link: https://github.com/google/timesketch

### TL;DR

The brief project README describes Timesketch as an open-source workspace for collaboratively organizing and analyzing forensic timelines. Users can combine timelines into sketches and add annotations, comments, tags, and stars; linked guides cover installation, imports, notebooks, use, and contribution. It is code owned by Google, explicitly not an official Google product. Commenters interpreted it as more than a log viewer: investigators can correlate events from multiple sources and annotate a shared incident sequence, potentially including postmortems, though the supplied overview provides little implementation detail.
