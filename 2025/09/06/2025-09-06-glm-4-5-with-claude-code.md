# GLM 4.5 with Claude Code

- Score: 210 | [HN](https://news.ycombinator.com/item?id=45145457) | Link: https://docs.z.ai/guides/llm/glm-4.5

### TL;DR

Z.AI presents GLM-4.5 and GLM-4.5-Air as agent-oriented mixture-of-experts models with 128K context, selectable thinking, tool use, and Claude Code integration. It reports 355B total/32B active parameters for GLM-4.5 and 106B/12B for Air, plus low API pricing and strong benchmark placement. These are vendor claims, though Z.AI released 52 coding tasks and trajectories for examination. Commenters find the models potentially cost-effective but report uneven provider quality, quantization effects, weaker agent behavior, and substantial privacy concerns.

### Comment pulse
