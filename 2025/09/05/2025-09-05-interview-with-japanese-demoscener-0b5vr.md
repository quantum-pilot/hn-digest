# Interview with Japanese Demoscener 0b5vr

- Score: 241 | [HN](https://news.ycombinator.com/item?id=45137245) | Link: https://6octaves.com/2025/09/interview-with-demoscener-0b5vr.html

### TL;DR

Japanese demoscener 0b5vr explains how “0mix” combines techno-demo aesthetics, live coding, and a 64KB intro: an HTML file procedurally generates audiovisuals while displayed GLSL code controls music. Building the engine, coding environment, composition, and assets took roughly a year, and the work won Revision 2023’s crowd-favorite vote. The interview follows that experiment into Wavenerd live performances, 4K collaborations, VRChat-linked Japanese scene growth, open source and detailed commit histories. 0b5vr presents the demoscene as cooperative, noncommercial expression that welcomes technical and nontechnical audiences alike.
