# Nest 1st gen and 2nd gen thermostats no longer supported from Oct 25

- Score: 282 | [HN](https://news.ycombinator.com/item?id=45143879) | Link: https://community.hubitat.com/t/nest-1st-gen-and-2nd-gen-thermostats-no-longer-supported-by-google-from-10-25-2025/152952

### TL;DR

A Hubitat community thread reports that Google will end connected support for first- and second-generation Nest thermostats on October 25, 2025. The devices should continue local thermostat operation, but the reported API retirement removes Nest/Home app control and Hubitat integration, leaving the physical dial. One owner says eight units would need replacement. Discussion favors local-first Zigbee or Z-Wave alternatives, while an open-source project aims to reuse second-generation enclosures and displays with a replacement ESP32-C6 board. The packet contains user reports, not Google's notice itself.

### Comment pulse

- Readers treat cloud-only hardware as disposable and ask vendors to provide a supported local API before service retirement.
- A former Nest employee cautions that securely retrofitting old 2010–11 devices would require substantial engineering, not a trivial final update.
