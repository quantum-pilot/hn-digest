# GNU Midnight Commander

- Score: 492 | [HN](https://news.ycombinator.com/item?id=45271481) | Link: https://midnight-commander.org/

### TL;DR

GNU Midnight Commander is a GPL-licensed, dual-pane, full-screen file manager for terminals, consoles, SSH sessions, and remote shells. It bundles file operations, search, a subshell, viewer, editor, and diff viewer, with standard package-manager installation and context-sensitive help. HN users praised its speed and keyboard-driven workflows, especially switching between panels and a shell. Others found its Norton Commander-derived shortcuts unintuitive, preferred core utilities or newer terminal managers, and debated whether specialized keyboard layouts still confer meaningful efficiency.

### Comment pulse

- Long-time users prize fluent composition → selection, archiving, navigation, and shell commands remain close together without leaving the terminal.
- Familiarity divides adoption → Norton Commander veterans find shortcuts natural, while GUI-trained users prefer nnn, coreutils, or graphical managers.
