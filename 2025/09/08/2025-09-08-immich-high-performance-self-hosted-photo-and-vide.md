# Immich – High performance self-hosted photo and video management

- Score: 557 | [HN](https://news.ycombinator.com/item?id=45165684) | Link: https://github.com/immich-app/immich

### TL;DR

Immich is an AGPL self-hosted photo and video manager with mobile and web uploads, deduplication, albums, sharing, metadata and semantic search, facial clustering, maps, memories, multiple users, OAuth, and offline mobile access. Its README prominently warns that development is very active, bugs and breaking changes should be expected, and it must not be the only copy of a library. HN users praised its Google Photos-like experience and migration tools, but reported mixed mobile performance while debating dependency churn, hosting storage, encryption, remote access, and backup responsibility.

### Comment pulse

- Product experience is increasingly strong → several users described easy migrations, useful CLI automation, and near-drop-in photo management.
- Maturity remains contested → rapid dependency updates inspire either supply-chain concern or confidence in active maintenance.
- Self-hosting shifts operational burden → reliable power, off-site backups, storage economics, networking, and family-friendly access become user responsibilities.

### LLM perspective

- View: Immich is feature-rich photo infrastructure, but self-hosting control does not substitute for independent backup design.
- Impact: Families can reduce platform dependence while taking ownership of availability, upgrades, security, and data durability.
- Watch next: Stable release criteria, mobile backup reliability, object-storage support, dependency policy, encryption options, and recovery testing.
