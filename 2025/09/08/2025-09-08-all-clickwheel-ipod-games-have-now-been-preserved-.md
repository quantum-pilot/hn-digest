# All clickwheel iPod games have now been preserved for posterity

- Score: 255 | [HN](https://news.ycombinator.com/item?id=45171733) | Link: https://arstechnica.com/gaming/2025/09/all-54-lost-clickwheel-ipod-games-have-now-been-preserved-for-posterity/

### TL;DR

The iPod Clickwheel Games Preservation Project says it has assembled all 54 official downloadable games after finally obtaining a working copy of Real Soccer 2009. Because Apple's FairPlay DRM ties games to authorized accounts, contributors synchronized surviving purchases into a coordinated virtual machine, creating a master library that can provision compatible iPods. The effort depended on owners with intact hardware, files, and credentials; several transfers failed, including one corrupted device. Commenters celebrated access to an obscure platform and recalled its unusually secretive development culture.
