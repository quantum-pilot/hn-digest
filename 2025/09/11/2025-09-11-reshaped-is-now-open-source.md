# Reshaped is now open source

- Score: 252 | [HN](https://news.ycombinator.com/item?id=45209558) | Link: https://reshaped.so/blog/reshaped-oss

### TL;DR

After five years as a paid design-system product, Reshaped has opened its React source code and published its Figma library through the community. The creator says the system targets common interface needs while preserving low-level flexibility, aligning design and engineering across accessibility, themes, dark mode, and animation. Earlier license revenue supported focused development; existing buyers retain future updates. The planned business direction is advanced, opinionated premium components above the free core. Commenters praised the release while flagging noticeable documentation navigation delays.

### Comment pulse

- The creator attributed slow navigation to server-side MDX scanning and basic authentication, and plans a static export.
- Users asked about WordPress integration and more deliberately designed micro-interactions.
