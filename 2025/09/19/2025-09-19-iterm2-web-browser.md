# iTerm2 Web Browser

- Score: 131 | [HN](https://news.ycombinator.com/item?id=45298793) | Link: https://iterm2.com/documentation-web.html

### TL;DR

iTerm2 now supports browser profiles, placing WKWebView sessions beside terminals in its tab and split-pane hierarchy through an optional plugin. Terminal-like features extend to selection, regex search, key bindings, triggers, broadcast input, replay, bookmarks, remote SSH files, and AI chat over reader-mode content. Privacy options include diskless browsing, popup and basic ad blocking, and separate password storage; passkeys and browser-specific Python APIs are absent. Commenters appreciated the developer's playful motivation, though some questioned the expanded security surface.

### Comment pulse
