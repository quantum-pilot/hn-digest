# QEMU 10.1.0

- Score: 302 | [HN](https://news.ycombinator.com/item?id=45037947) | Link: https://wiki.qemu.org/ChangeLog/10.1

### TL;DR

QEMU 10.1 expands system emulation and virtualization across Arm, RISC-V, x86, VFIO, migration, networking, graphics, and tooling. Highlights include new Arm vector and matrix features, x86 TDX support, confidential-guest VFIO work, broader RISC-V emulation and fixes, faster Unix-socket NBD with larger buffers, migration optimizations, and experimental Emscripten/WASM builds. Rust support remains experimental with a 1.77 minimum, and Debian Bullseye host support is dropped. Commenters praised QEMU’s breadth, explained how KVM replaces CPU translation while retaining device models, and welcomed browser playground possibilities.

### Comment pulse

- QEMU and KVM divide responsibilities → hardware runs guest instructions while QEMU supplies machine setup and device emulation.
- WASM builds could broaden access → browser-hosted architecture and microcontroller playgrounds become easier to package.
- Users value mature front ends → UTM and QuickEMU hide QEMU’s sometimes awkward command-line interface.
