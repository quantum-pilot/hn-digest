# Word documents will be saved to the cloud automatically on Windows going forward

- Score: 310 | [HN](https://news.ycombinator.com/item?id=45037621) | Link: https://www.ghacks.net/2025/08/27/your-word-documents-will-be-saved-to-the-cloud-automatically-on-windows-going-forward/

### TL;DR

Microsoft is changing Word for Windows so newly created documents automatically save to OneDrive or another preferred cloud destination, beginning with version 2509. New files receive date-based names, and users can still rename or relocate them with Save. Those preferring local storage can disable cloud AutoSave, enable “Save to Computer by default,” and choose a local path in Word’s options. The article highlights privacy and consent concerns, while commenters note that cloud saving already existed and characterize automatic saving on creation as the key change.
