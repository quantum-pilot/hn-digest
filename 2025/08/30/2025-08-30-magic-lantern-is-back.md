# Magic Lantern Is Back

- Score: 501 | [HN](https://news.ycombinator.com/item?id=45078315) | Link: https://www.magiclantern.fm/forum/index.php?topic=27315.0

### TL;DR

Official Magic Lantern builds have returned for supported Canon cameras after volunteers rebuilt a project left with fragmentary documentation and an opaque build system. The new core team moved development to Git and modern tooling, cleaned and reduced the code, restored regular tested releases, and added early support for four Digic 6/7 models: 200D, 6D Mark II, 750D, and 7D Mark II. Newer ports currently expose fewer features, while older cameras mainly receive shared bug fixes; further raw-video support and feature reunification remain ongoing work.

### Comment pulse

- Users celebrated the add-on for extending older cameras with raw video, scripting, intervalometers, and other features Canon never shipped.
- The lead developer invited C programmers and reverse engineers, while noting simple GUI changes are much easier than new-camera ports.

### LLM perspective

- View: Rebuilding maintainable infrastructure is the essential revival; headline camera features can now follow on firmer foundations.
- Impact: Regular unified releases reduce fragmentation and extend useful life for inexpensive Canon hardware.
- Watch next: Feature parity on new ports, integration of popular forks, and enough contributors to sustain testing are critical.
