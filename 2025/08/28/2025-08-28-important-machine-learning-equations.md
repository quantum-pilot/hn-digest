# Important machine learning equations

### TL;DR

This practical reference collects equations, explanations, and Python examples spanning entropy, cross-entropy, KL divergence, Bayes’ theorem, affine transformations, eigendecomposition, linear regression, SVD, gradient descent, multilayer perceptrons, backpropagation, common losses, softmax, convolution, attention, and diffusion. It explicitly omits kernel methods, reinforcement learning, learning theory, graphical models, deeper optimization, and regularization. Commenters appreciate the breadth but flag technical imprecision, including earlier code errors and terminology issues, and argue that presenting related information-theory formulas separately can encourage memorization without showing their derivation and conceptual unity.
