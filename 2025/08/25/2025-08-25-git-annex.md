# Git-Annex

- Score: 225 | [HN](https://news.ycombinator.com/item?id=45010161) | Link: https://git-annex.branchable.com/

### TL;DR

Git-annex manages large-file locations and integrity with Git metadata while keeping file contents outside ordinary Git history. It can track which offline drives, servers, or encrypted special remotes hold each file, enforce copy policies, verify checksums, and synchronize a shared directory view across intermittent storage. The command-line tool targets Git users, while an assistant offers folder synchronization. Its archival examples emphasize reorganizing metadata without accidentally losing content and retaining a simple recoverable format. Commenters report both long-term institutional use and performance or workflow friction at scale.

### Comment pulse
