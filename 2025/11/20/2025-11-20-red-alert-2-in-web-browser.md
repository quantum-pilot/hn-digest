# Red Alert 2 in web browser

- Score: 384 | [HN](https://news.ycombinator.com/item?id=45991853) | Link: https://chronodivide.com/

### TL;DR

Chrono Divide is a nonprofit, browser-based recreation of Command & Conquer: Red Alert 2 built with web technologies. Its beta offers multiplayer, original maps, cross-platform play, replays, alternative control schemes, and mod support, with feature parity with the vanilla engine as the stated goal. The project says mobile and tablet play work, though Firefox is discouraged for performance. Commenters praise the technical reconstruction and nostalgic single-player design, while noting Yuri's Revenge is unsupported and debating whether original asset files are still required.
