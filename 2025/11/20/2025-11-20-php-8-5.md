# PHP 8.5

- Score: 217 | [HN](https://news.ycombinator.com/item?id=45989469) | Link: https://stitcher.io/blog/new-in-php-85

### TL;DR

PHP 8.5 adds a pipe operator for function chaining, property changes during cloning, `#[NoDiscard]` with explicit `(void)` suppression, closures in constant expressions, fatal-error backtraces, `array_first()` and `array_last()`, and a new URI API. Smaller additions cover visibility, attributes, DOM, HEIF/HEIC, and throwing filters; deprecations include nonstandard cast names, backtick shell execution, and constant redeclaration. Commenters welcome continued modernization and compatibility discipline, but debate whether accumulated syntax and features undermine PHP's traditional simplicity and accessibility.

### Comment pulse

- Longtime users praised gradual migrations and shims that kept old applications running while rewarding upgrades.
- Critics called the unary-only pipe syntax unnecessary complexity; defenders argue modern web backends demand richer language tools.
