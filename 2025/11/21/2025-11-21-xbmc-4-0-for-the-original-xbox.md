# XBMC 4.0 for the Original Xbox

- Score: 120 | [HN](https://news.ycombinator.com/item?id=46005349) | Link: https://www.xbox-scene.info/articles/announcing-xbmc-40-for-the-original-xbox-r64/

### TL;DR

XBMC 4.0 revives the original Xbox media center with its first major advance since 2016. It backports a modern Estuary interface and GUI framework to the console’s 64MB, 733MHz hardware, while adding richer game libraries, restored media metadata scraping, improved background task scheduling, network services, and an online add-on repository. Playback, FLAC support, visualizers, and Python 2.7 add-ons remain, with a Python 3.4.10 transition planned. Nightly builds are actively developed and separate from XBMC4Gamers and modern Kodi.
