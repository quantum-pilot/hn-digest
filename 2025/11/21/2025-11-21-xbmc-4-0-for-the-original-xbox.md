# XBMC 4.0 for the Original Xbox

- Score: 120 | [HN](https://news.ycombinator.com/item?id=46005349) | Link: https://www.xbox-scene.info/articles/announcing-xbmc-40-for-the-original-xbox-r64/

### TL;DR

After nearly a decade without a major release, the original console’s media-center branch gains a modernized interface and refreshed internals while still targeting 64 MB of RAM and a 733 MHz processor. The update ports Kodi’s Estuary skin and newer GUI framework, adds metadata-rich game and emulator libraries, restores online media scrapers, improves background scheduling, and retains network services, lossless audio, visualizers, trainers, and Python add-ons. Active nightly development uses Python 2.7 today, with a future 3.4.10 transition planned for broader add-on compatibility.
