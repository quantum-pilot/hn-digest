# Racket v9.0

- Score: 254 | [HN](https://news.ycombinator.com/item?id=46023460) | Link: https://blog.racket-lang.org/2025/11/racket-v9-0.html

### TL;DR

The ninth major Racket release adds lightweight parallel threads to a language that previously relied on green threads, futures, and isolated places for concurrency. Developers opt into a thread pool and can retain results for retrieval when waiting. Supporting changes include a black-box wrapper for trustworthy benchmarks, linklet decompilation, AArch64 native packages, deeper syntax-origin tracking, Weibull distributions, and numerous fixes. Commenters welcomed a more familiar route to multicore work, while noting that places were restrictive and questioning why a mature language reached conventional parallel threading only now.

### Comment pulse

- Project fit remained uncertain → enthusiasts praised experimentation and language learning, while some avoided large applications because of speed or tooling.

### LLM perspective

- View: Parallel threads close a conspicuous capability gap without discarding the language’s existing concurrency models.
- Impact: Familiar multicore primitives can broaden viable workloads and simplify ports of algorithms that share functions and state.
- Watch next: Scaling benchmarks, synchronization semantics, library thread safety, debugger support, and adoption beyond experimental workloads.
