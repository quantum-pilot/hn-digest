# How I use every Claude Code feature

- Score: 461 | [HN](https://news.ycombinator.com/item?id=45786738) | Link: https://blog.sshh.io/p/how-i-use-every-claude-code-feature

### TL;DR

An enterprise Claude Code user recommends treating repository instructions as concise guardrails, monitoring context usage, and replacing opaque compaction with explicit restarts plus durable progress notes. Simple slash commands should remain shortcuts; general cloned agents are preferred over rigid specialists. Deterministic hooks enforce tests at submission, planning aligns complex changes, and Skills expose scriptable workflows while MCP handles secure data or action boundaries. The SDK enables parallel jobs and prototypes, while GitHub Actions provide sandboxed, auditable automation whose logs can drive tooling improvements.
