# Unison 1.0

- Score: 177 | [HN](https://news.ycombinator.com/item?id=46049722) | Link: https://www.unison-lang.org/unison-1-0/

### TL;DR

After years of development, Unison declares its language, distributed runtime, and workflow stable. Definitions are content-addressed and stored in a database rather than identified by mutable file names, enabling reuse, fewer version conflicts, native collaboration, and code-driven deployment. The release includes UCM tooling, a desktop browser, Share hosting, Cloud and customer-infrastructure deployment, runtime improvements, algebraic effects, and distributed frameworks. Enthusiasts praised the radical design, while skeptics cited limited adoption, no C FFI yet, cloud lock-in concerns, and scarce production evidence beyond Unison’s own platform.

### Comment pulse
