# Launch HN: Onyx (YC W24) – Open-source chat UI

- Score: 161 | [HN](https://news.ycombinator.com/item?id=46045987) | Link: https://news.ycombinator.com/item?id=46045987

### TL;DR

Onyx’s founders describe a three-month pivot from enterprise search toward an open-source, model-agnostic workplace chat system. It combines retrieval, connectors, custom tools, assistants, memory, permission syncing, and on-premises or air-gapped deployment behind a deliberately simple interface. Large organizations reportedly use thousands of assistants, including with local models for sensitive teams. Engineering lessons include repeating crucial instructions near the context’s end and smoothing model-specific tool behavior. The founders acknowledge that administration needs substantial redesign and multimodal PDFs remain text-only.

### Comment pulse

- Enterprises value a stable, simple chat surface → consistent UX and strong retrieval matter more than elaborate agent builders.
- Administration remains underdeveloped → critics want clearer source tracing and process visibility — counterpoint: large deployments already use permissions and air-gapped models.
