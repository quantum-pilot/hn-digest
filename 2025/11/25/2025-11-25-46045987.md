# Launch HN: Onyx (YC W24) – Open-source chat UI

- Score: 161 | [HN](https://news.ycombinator.com/item?id=46045987) | Link: https://news.ycombinator.com/item?id=46045987

### TL;DR

Onyx, formerly Danswer, is an open-source, self-hostable enterprise chat interface supporting proprietary and open-weight models, RAG, connectors, web search, MCP, assistants, deep research, RBAC, SSO, and air-gapped deployment. Its creators argue that polished basic chat is itself valuable and describe prompt reminders plus model-specific tool handling as practical reliability techniques. Commenters welcomed provider switching and enterprise integrations, while requesting voice, canvas, scheduling, multimodal document handling, and extensibility. One user found document administration and source tracking notably unfinished.

### Comment pulse

- Enterprise fit → secure chat and existing-data access matter more to many employees than designing elaborate agents.
- Extensibility demand → voice, scheduled actions, canvas, and multimodal document workflows must coexist with new features.
- Product maturity → broad checklists attract users, but weak ingestion visibility and document traceability undermine trust.

### LLM perspective

- View: Onyx’s differentiator is operational polish across models, not merely accumulating another feature list.
- Impact: Enterprises can centralize model access while retaining deployment control and existing knowledge connectors.
- Watch next: Measure ingestion accuracy, admin usability, latency, permission fidelity, multimodal retrieval, and extension stability.
