# Server DRAM prices surge 50% as AI-induced memory shortage hits hyperscalers

- Score: 134 | [HN](https://news.ycombinator.com/item?id=45812403) | Link: https://www.tomshardware.com/pc-components/storage/server-dram-prices-surge-50-percent

### TL;DR

Tom's Hardware, citing DigiTimes, reports that major hyperscalers accepted fourth-quarter server-DRAM contract increases of up to 50% yet received only about 70% of requested supply. The report attributes the squeeze to AI demand and manufacturers shifting capacity toward HBM, with smaller buyers allegedly receiving still less. It also describes rising SSD and consumer-module prices, quote freezes, and tightness extending into 2026. Commenters supplied anecdotal regional price jumps, debated speculation and hoarding, and hoped dearer memory might reward more efficient models.
