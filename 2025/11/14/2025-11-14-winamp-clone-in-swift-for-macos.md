# Winamp clone in Swift for macOS

- Score: 163 | [HN](https://news.ycombinator.com/item?id=45926224) | Link: https://github.com/mgreenwood1001/winamp

### TL;DR

Winamp macOS is a native Swift recreation of the classic player for MP3 and FLAC files. It includes independent main-window and playlist minimization, M3U playlists, playback controls, file browsing and drag-and-drop, a spectrum analyzer, equalizer, multiple oscilloscope modes, Milkdrop visualization, and lyrics overlays. The MIT-licensed project requires macOS 13 or later and can be built through Xcode, Swift Package Manager, or its shell script. The frozen source is brief and describes features rather than implementation quality or stability.
