# Replicate is joining Cloudflare

- Score: 258 | [HN](https://news.ycombinator.com/item?id=45953702) | Link: https://replicate.com/blog/replicate-cloudflare

### TL;DR

Replicate is joining Cloudflare while remaining a distinct brand; it says existing APIs, models, and applications will continue unchanged. Replicate contributes Cog's open model packaging and a hosted API for publishing and running models. Cloudflare contributes Workers for orchestration, Durable Objects for state, R2 storage, WebRTC streaming, and a global network. The companies aim to build higher-level agent and real-time inference services. Commenters generally see strategic fit, but note crowded inference competition, cold-start costs, stale Workers AI models, and undisclosed transaction terms.

### Comment pulse

- Customers hope Cloudflare volume and infrastructure can improve Replicate's latency, warm capacity, pricing, marketing, and enterprise sustainability.
- Skeptics question whether this was a lucrative acquisition and whether Cloudflare will preserve Replicate's product quality.
