# Scientists find ways to boost memory in aging brains

- Score: 167 | [HN](https://news.ycombinator.com/item?id=45842263) | Link: https://news.vt.edu/articles/2025/10/cals-jarome-improving-memory.html

### TL;DR

Two Virginia Tech studies used gene-editing tools in older rats to alter molecular processes associated with memory. Reducing K63 polyubiquitination improved performance despite age-related levels moving in opposite directions across the hippocampus and amygdala. A separate CRISPR-dCas9 intervention removed DNA-methylation tags that silence the memory-supporting IGF2 gene, reactivating it and improving older rats’ memory without affecting unimpaired middle-aged animals. Researchers say multiple pathways contribute to aging. Commenters stressed that these are animal results, not demonstrated human treatments, and criticized the headline’s ambiguity.
