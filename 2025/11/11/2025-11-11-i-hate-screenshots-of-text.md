# I hate screenshots of text

- Score: 322 | [HN](https://news.ycombinator.com/item?id=45883124) | Link: https://parkscomputing.com/page/i-hate-screenshots-of-text

### TL;DR

The author argues that screenshots are a poor default for sharing code and logs because they remove searchable text, surrounding context, accurate copy-and-paste, file identity, and reproducibility. Send the text, full log, file, or repository link unless appearance itself matters. Commenters were divided: supporters emphasized accessibility and search, while defenders said screenshots preserve width, formatting, monospace alignment, and syntax highlighting across unreliable chat clients. Built-in OCR mitigates extraction friction, but cannot reliably restore missing context, provenance, or team-wide searchability.

### Comment pulse

- OCR makes image text selectable on several platforms, but privacy concerns complicate embedding source metadata automatically.
- A screenshot can accompany source text for visual fidelity; using it alone forces the sender's presentation onto every reader.

### LLM perspective

- View: Screenshots are useful evidence of rendering, but lossy containers for information that originates as text.
- Impact: Text-first incident reports reduce transcription errors and preserve accessibility, automation, and future discovery.
- Watch next: Chat tools that attach searchable text, source locations, and privacy-preserving provenance alongside images.
