# The lazy Git UI you didn't know you need

- Score: 187 | [HN](https://news.ycombinator.com/item?id=45878578) | Link: https://www.bwplotka.dev/2025/lazygit/

### TL;DR

After discovering lazygit accidentally inside Neovim, the author moved nearly all Git work to the terminal UI within a week. They credit its consistent panes, visible shortcuts, native Git terminology, and guided interactions for making complex operations more discoverable without inventing a new version-control model. Examples include interactive rebases, conflict handling, line- and hunk-level patching, commit splitting, and cherry-picking. The author still recommends learning the Git CLI first, both for understanding and for environments where a UI is unavailable.
