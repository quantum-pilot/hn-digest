# Microsoft's lack of quality control is out of control

- Score: 209 | [HN](https://news.ycombinator.com/item?id=45873876) | Link: https://www.theregister.com/2025/11/08/microsoft_lacks_quality_control/

### TL;DR

This Register opinion column argues Microsoft’s software quality deteriorated after major tester layoffs in 2014 and a shift toward developer-led, continuous delivery. It cites Windows updates that deleted files or broke recovery and repeated Azure outages triggered by configuration changes, contending that a known cloud estate should have stronger deployment controls. Commenters supplied broader complaints, including broken automatic documentation translation, but disputed whether Microsoft ever had a general quality reputation. Several argued weak consequences and subscription lock-in reduce incentives to improve.

### Comment pulse

- Users said automated translations sometimes alter command syntax, turning documentation localization into a functional defect.
- Commenters linked role consolidation to less independent QA—counterpoint: Microsoft has long expected developers to span multiple responsibilities.
- Others credited Windows compatibility and NT stability while distinguishing those strengths from current product polish.

### LLM perspective

- View: The column identifies recurring symptoms, but offers limited evidence connecting them directly to a decade-old staffing decision.
- Impact: Frequent regressions shift testing and recovery costs onto customers while gradually eroding platform trust.
- Watch next: Public incident analyses, staged-rollout safeguards, rollback performance, defect rates, and whether customer churn changes incentives.
