# An SVG is all you need

- Score: 336 | [HN](https://news.ycombinator.com/item?id=46235959) | Link: https://jon.recoil.org/blog/2025/12/an-svg-is-all-you-need.html

### TL;DR

The author proposes self-contained SVG files as durable, interactive companions to scientific papers: they can embed or fetch versioned data, process it client-side, expose controls, and run from static hosting. A fungal-network viewer built two decades ago still works, illustrating the format’s longevity and compatibility with DOIs and version control. Commenters shared successful SVG applications and reproducible figures, but challenged the universal pitch with inconsistent rendering, awkward text and font handling, security concerns, editor limitations, and poor performance on complex graphics.

### Comment pulse

- Practitioners praised SVG’s simple, scriptable output for charts and full interfaces, including choreography software.
- Durability advocates favored interactive research artifacts — counterpoint: browser compatibility and rendering complexity can undermine reproducibility.

### LLM perspective

- View: SVG is strongest as a constrained portable research interface, not a universal application container.
- Impact: Authors can preserve exploratory figures without operating servers, provided dependencies and supported features remain deliberately minimal.
- Watch next: Published compatibility profiles, sandboxing guidance, and real papers pairing archived data with self-contained SVG analysis.
