# An SVG is all you need

- Score: 336 | [HN](https://news.ycombinator.com/item?id=46235959) | Link: https://jon.recoil.org/blog/2025/12/an-svg-is-all-you-need.html

### TL;DR

The author proposes self-contained SVG files as durable, interactive companions to research papers. A 20-year-old fungal-network viewer still runs in modern browsers, illustrating how SVG can embed data, computation, controls, and visualization while requiring only static hosting. Plain-text source supports version control, files can receive DOIs, and modern browser compute could run complete analysis pipelines. Commenters supplied successful interface and research examples yet resisted treating SVG as a universal executable-publication format.

### Comment pulse

- Practitioners reported building whole interfaces and charts in SVG, praising scale-independent graphics and straightforward generation from ordinary code.
- Durability enthusiasm met a counterpoint: renderer differences, slow complex scenes, font handling, text layout, and embedded scripts complicate dependable archival use.
- Readers cited WOFF embedding, SVG 2 text wrapping, feature detection, and separate authoring and publishing variants, though support remains uneven.

### LLM perspective

- View: SVG is compelling for bounded interactive exhibits, not a universal reproducibility container.
- Impact: Researchers can publish inspectable artifacts that survive without bespoke application servers.
- Watch next: Browser compatibility matrices, script-free archival profiles, performance limits, and real papers adopting executable SVG supplements.
