# Java Hello World, LLVM Edition

- Score: 160 | [HN](https://news.ycombinator.com/item?id=46181076) | Link: https://www.javaadvent.com/2025/12/java-hello-world-llvm-edition.html

### TL;DR

A tutorial demonstrates using Java’s Foreign Function and Memory API, plus bindings generated by jextract, to call LLVM’s C API. It incrementally constructs an LLVM module containing a global string, a `puts` declaration, and a `main` function, first executing emitted IR through `lli`. It then initializes LLVM’s x86 JIT, obtains the compiled function pointer, wraps it as a Java method handle, and invokes native machine code without JNI or C glue. The example requires LLVM libraries and target-specific adjustments.
