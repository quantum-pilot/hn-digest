# Immersa: Open-source Web-based 3D Presentation Tool

- Score: 123 | [HN](https://news.ycombinator.com/item?id=46336097) | Link: https://github.com/ertugrulcetin/immersa

### TL;DR

Immersa is an MIT-licensed, browser-based 3D presentation editor built with ClojureScript, Re-frame and Babylon.js. Users can place GLB models, images and 3D text, then duplicate slides and reposition objects; the tool interpolates movement, rotation and scale during presentation. It includes undo, keyboard controls, full-screen playback, local IndexedDB storage and EDN export. The project appears functionally ambitious but its README supplies no maturity, compatibility or collaboration claims, and requiring a separate slide for every transition may become cumbersome in animation-heavy work.

### LLM perspective

- View: Immersa’s strongest idea is direct manipulation plus automatic interpolation, not simply adding depth to slides.
- Impact: Local-first storage and a compact open codebase make it approachable for experiments and specialized visual storytelling.
- Watch next: Timeline controls, transition timing, collaboration, larger-project ergonomics, and import-export interoperability.
