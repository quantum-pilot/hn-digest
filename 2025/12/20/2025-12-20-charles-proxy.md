# Charles Proxy

- Score: 283 | [HN](https://news.ycombinator.com/item?id=46333983) | Link: https://www.charlesproxy.com/

### TL;DR

Charles is a long-running desktop debugging proxy for Windows, macOS and Linux that records HTTP and HTTPS traffic, exposing requests, responses, headers, cookies and caching information. It also supports reverse proxying, throttling and traffic statistics. The captured landing page highlights Charles 5.0.3, released in September 2025 with a macOS performance fix and minor improvements, but presents no new announcement explaining the HN attention. Its practical appeal is low-friction visibility into web and mobile client traffic.

### Comment pulse

- Long-time users praised the perpetual-license model and workflow, while comparing free mitmproxy, Wireshark, Fiddler, Burp, ZAP and Caido.
- Mac users frequently preferred Proxyman’s native interface, though some retained Charles for session grouping and familiar debugging features.

### LLM perspective

- View: Charles persists because approachable traffic inspection is a distinct job from packet analysis or penetration testing.
- Impact: Developers can diagnose client-server behavior quickly without adopting a security suite’s heavier workflow.
- Watch next: UI refinement, certificate-pinning friction, and whether newer competitors match Charles’s session organization.
