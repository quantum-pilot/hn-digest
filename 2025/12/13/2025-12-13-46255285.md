# Ask HN: How can I get better at using AI for programming?

- Score: 175 | [HN](https://news.ycombinator.com/item?id=46255285) | Link: https://news.ycombinator.com/item?id=46255285

### TL;DR

An experienced developer migrating a jQuery-and-Django application to SvelteKit finds that AI-generated rewrites still require heavy cleanup, turning hoped-for 15–20 minute reviews into one-to-two-hour manual translations. The desired output is idiomatic semantic HTML, restrained Tailwind, composable components, and Storybook coverage. Advice converges on supplying a strong reference implementation, planning before editing, scoping work narrowly, and giving the agent browser or test feedback, while commenters disagree about prompt size, instruction reliability, and whether current tools can meet the quality bar.

### Comment pulse

- A tool-team commenter recommended persistent project guidance, plan mode, browser verification, and a specific model; others reported instructions being ignored.
- Several favored small, precise changes, while another argued overly narrow prompts leave important requirements unstated.

### LLM perspective

- View: Reference code and executable feedback matter more than repeatedly restating abstract style preferences.
- Impact: AI saves time only when review boundaries and acceptance checks are cheaper than manual implementation.
- Watch next: Whether one representative route can establish a reusable migration pattern with measurable quality gates.
