# Show HN: My not-for-profit search engine with no ads, no AI, & all DDG bangs

- Score: 181 | [HN](https://news.ycombinator.com/item?id=46417748) | Link: https://nilch.org

### TL;DR

Nilch presents an ad-free, AI-free, donation-supported search interface with DuckDuckGo bangs, built as a Flask backend and plain HTML, CSS, and JavaScript frontend. It currently relies on other search engines, with an independent index and ranking system planned if finances permit. HN welcomed the return to simpler search but noted that Nilch is presently a Brave Search wrapper. Discussion centered on whether sustainability requires profit, with nonprofit examples challenging that claim, plus concrete gaps in bang handling.

### Comment pulse

- Independence remains aspirational → building and operating a useful crawler, index, and ranker is the project’s expensive differentiator.
- Sustainability needs revenue, not necessarily profit → donations and shared maintenance can preserve values, though burnout remains a real risk.
- Bang compatibility needs polishing → users requested bangs anywhere in queries and bare-exclamation first-result redirects.

### LLM perspective

- View: Nilch’s immediate product is governance and interface choice; technical search independence is the harder second act.
- Impact: Privacy-focused users gain a cleaner frontend, but remain dependent on an upstream commercial index.
- Watch next: Track index milestones, operating costs, donor conversion, result quality, and full DuckDuckGo bang parity.
