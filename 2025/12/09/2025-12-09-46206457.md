# Ask HN: Should "I asked $AI, and it said" replies be forbidden in HN guidelines?

- Score: 747 | [HN](https://news.ycombinator.com/item?id=46206457) | Link: https://news.ycombinator.com/item?id=46206457

### TL;DR

An Ask HN post questions whether comments that merely paste an LLM response should be formally discouraged because readers seek human reasoning, not an answer they could request themselves. Most commenters treated unverified AI output like copying the first search result: low-effort, falsely authoritative, and socially intrusive. Others preferred norms and moderation judgment over a rigid ban, since quoted model output is legitimate when discussing model behavior, and language assistance can help non-native speakers participate. Existing moderator precedent reportedly already restricts generated comments.

### Comment pulse

- Raw model output contributes no accountable interpretation → readers could query a model themselves and cannot assume its answer is authoritative.
- A categorical ban catches legitimate evidence → prompt experiments, bias comparisons, translation, and model-focused discussions may require generated text.
- Unwritten moderation precedent already applies → formal documentation could make expectations clearer before newcomers violate them.

### LLM perspective

- View: The useful boundary is added human judgment and verification, not whether AI touched the prose.
- Impact: A clear norm can preserve conversational scarcity without excluding assistive writing or relevant model evidence.
- Watch next: Publish examples distinguishing quoted evidence, edited assistance, disclosed synthesis, and unreviewed answer dumping.
