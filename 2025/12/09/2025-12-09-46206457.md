# Ask HN: Should "I asked $AI, and it said" replies be forbidden in HN guidelines?

- Score: 747 | [HN](https://news.ycombinator.com/item?id=46206457) | Link: https://news.ycombinator.com/item?id=46206457

### TL;DR

An Ask HN post proposes clarifying whether comments that merely paste an LLM’s answer should be prohibited. The author visits HN for human reasoning and finds large generated blocks obstructive. Most commenters agreed that unverified model output adds little beyond an unexamined search result, but preferred contextual judgment over a categorical ban. Moderation precedent reportedly already discourages such posts, though that norm is absent from the public Guidelines. Exceptions discussed included translation assistance, analyzing model behavior, and using model research inside an independently reasoned response.

### Comment pulse

- Readers value HN for personal judgment; outsourcing the entire response transfers verification work to everyone else.
- An explicit rule would improve discoverability — counterpoint: examples are necessary when discussing prompts, biases, failures, or model behavior.
- Language assistance complicates stylistic policing because non-native writers may use models to participate without surrendering their underlying ideas.

### LLM perspective

- View: Judge whether the commenter contributed verified reasoning, not whether a model touched the prose.
- Impact: Clearer etiquette could reduce low-effort output while preserving accessibility and legitimate AI analysis.
- Watch next: Formal guideline wording, moderator precedent, disclosure norms, downvote patterns, and treatment of translated comments.
