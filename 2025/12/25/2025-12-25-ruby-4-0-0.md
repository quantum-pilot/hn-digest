# Ruby 4.0.0

- Score: 665 | [HN](https://news.ycombinator.com/item?id=46382011) | Link: https://www.ruby-lang.org/en/news/2025/12/25/ruby-4-0-0-released/

### TL;DR

Ruby 4.0 introduces experimental Ruby::Box isolation for definitions and monkey patches, plus ZJIT, a Rust-built method JIT intended eventually to exceed YJIT but not yet recommended for production. Ractors gain ports, shareable procs, lower lock and cache contention, and numerous stability fixes, moving closer to non-experimental status. The release also adds language conveniences, core Set and Pathname, performance and GC improvements, and Bundler 4. HN celebrated the Christmas release while debating Ruby’s typing, tooling, parallelism, and Python’s ecosystem advantage.

### Comment pulse

- Isolation potential → Box could simplify tests, blue-green deployments, and dependency comparisons; commenters imagined per-Ractor heaps and garbage collection.
- Ecosystem choice → defectors favored Python libraries or static typing, while Ruby users defended its syntax, Rails, and coherent philosophy.
