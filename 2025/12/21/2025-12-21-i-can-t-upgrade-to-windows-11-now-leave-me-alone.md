# I can't upgrade to Windows 11, now leave me alone

- Score: 291 | [HN](https://news.ycombinator.com/item?id=46347108) | Link: https://idiallo.com/byte-size/cant-update-to-windows-11-leave-me-alone

### TL;DR

A Windows 10 laptop that Microsoft deems incompatible with Windows 11 because it lacks TPM 2.0 still displays an unavoidable upgrade prompt. Its only choices are “remind me later” or “learn more,” the latter leading to a laptop-buying guide, so the author sees the interface as a deliberate sales dark pattern rather than useful support messaging. The experience reinforces broader frustration with ads, account pressure, and OneDrive promotion inside a paid operating system whose vendor can remotely alter the user experience.

### Comment pulse

- Readers shared frustration with forced deferral choices, while others noted that automatic updates substantially improved security over earlier personal-computing eras.
- Linux and BSD were proposed as exits, but proprietary applications, gaming, hardware support, and workplace requirements remain practical barriers.
