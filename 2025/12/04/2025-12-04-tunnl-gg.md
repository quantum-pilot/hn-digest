# Tunnl.gg

- Score: 165 | [HN](https://news.ycombinator.com/item?id=46145902) | Link: https://tunnl.gg

### TL;DR

Tunnl.gg exposes a local web server through an instant public HTTPS URL using one SSH reverse-tunnel command, without installation, signup, or payment. The service advertises WebSocket support and use cases including webhook testing, demos, mobile testing, and CI callbacks. Commenters liked relying on ubiquitous SSH instead of a custom client, but warned that anonymous tunneling services attract malware and abuse, can become blocklisted, and expose local development servers to automated probes. They also raised cookie isolation, public-suffix, logging, trust, and self-hosting questions.

### Comment pulse

- Operators warned that abuse previously made comparable free services unsustainable and can taint shared IP reputation.
- Security advice centered on authenticating exposed apps and removing sensitive files from guessable paths.
- Readers suggested dedicated user subdomains, same-domain email, self-hosting, and eventual open-source release.
