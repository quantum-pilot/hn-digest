# Django 6

- Score: 175 | [HN](https://news.ycombinator.com/item?id=46153116) | Link: https://docs.djangoproject.com/en/6.0/releases/6.0/

### TL;DR

Version 6.0 of the framework supports Python 3.12–3.14 and adds built-in Content Security Policy tooling, reusable template partials, and a Tasks framework for defining, validating, queueing, and tracking background work. Task execution still requires an external worker, while bundled backends target development and testing. The release also adopts Python’s modern email API, adds async pagination and broad ORM improvements, and changes several defaults and backend interfaces. Upgraders must account for dropped older Python and MariaDB support, removals, and new deprecations.
