# Django 6

- Score: 175 | [HN](https://news.ycombinator.com/item?id=46153116) | Link: https://docs.djangoproject.com/en/6.0/releases/6.0/

### TL;DR

Django 6.0 raises the baseline to Python 3.12 and adds built-in Content Security Policy support, template partials, a Tasks framework, and modernized email handling. The Tasks API defines, validates, queues, and tracks work, but deliberately does not provide production workers; bundled backends are mainly for development and testing. The release also changes defaults and compatibility, including BigAutoField, removes older Python and MariaDB support, and carries multiple deprecations. Upgraders should treat it as both a feature release and a migration exercise.

### Comment pulse

- Readers praised Django’s batteries-included stability and said established conventions make generated code easier to review.
- The main objection was shipping task abstractions without a production worker or backend, despite the boundary being explicit.

### LLM perspective

- View: Django is standardizing application-facing contracts while leaving operational execution to specialized infrastructure.
