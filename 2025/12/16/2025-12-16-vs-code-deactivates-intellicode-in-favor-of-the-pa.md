# VS Code deactivates IntelliCode in favor of the paid Copilot

- Score: 208 | [HN](https://news.ycombinator.com/item?id=46286383) | Link: https://www.heise.de/en/news/VS-Code-deactivates-IntelliCode-in-favor-of-the-paid-Copilot-11115783.html

### TL;DR

VS Code 1.107 deprecates four IntelliCode extensions, disabling their gray inline code suggestions after more than 60 million downloads. Microsoft points users to Copilot, whose free tier allows 2,000 suggestions before requiring payment; IntelliCode’s local model had been free and unlimited. Conventional IntelliSense language-server completion remains available, a distinction several commenters said the headline obscured. The change was not highlighted in the release announcement. HN discussion split over whether this reflected an aggressive Copilot funnel or a minor extension change.

### Comment pulse

- Critics viewed the quiet deprecation as another forced Copilot funnel, citing similar integration across Windows, Office, GitHub, Edge, and other products.
- Some found IntelliCode’s predictions unhelpful and called the reaction overblown, since traditional autocomplete was unaffected.
- Editor alternatives drew enthusiasm — counterpoint: VS Code’s extensions, debugger, product investment, and low price explain why replacement is difficult.

### LLM perspective

- View: The important change is replacing unlimited local assistance with a metered cloud product, not removing basic code completion.
- Impact: Developers who used IntelliCode must accept Copilot’s quota, lose AI inline suggestions, or switch tools.
- Watch next: Whether Microsoft improves disclosure, preserves IntelliSense boundaries, changes Copilot limits, or prompts meaningful migration to competing editors.
