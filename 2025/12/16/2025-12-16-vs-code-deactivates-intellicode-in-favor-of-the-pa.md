# VS Code deactivates IntelliCode in favor of the paid Copilot

- Score: 208 | [HN](https://news.ycombinator.com/item?id=46286383) | Link: https://www.heise.de/en/news/VS-Code-deactivates-IntelliCode-in-favor-of-the-paid-Copilot-11115783.html

### TL;DR

Microsoft deprecated four IntelliCode extensions in VS Code 1.107, disabling their free, unlimited local-model inline suggestions and directing users toward Copilot, whose free tier offers 2,000 suggestions before requiring payment. Traditional IntelliSense and language-server completion remain available; the change affects the AI-assisted extension, not basic autocomplete. The release also adds experimental TypeScript 7 support through the Go-based compiler preview and expands agent controls. Heise says the IntelliCode change was absent from the main release announcement and disclosed in a separate issue.

### Comment pulse

- Much anger conflated IntelliCode with IntelliSense; several commenters stressed that ordinary class and function completion remains intact.
- Others see the retirement as another Microsoft push toward Copilot and discuss moving to Neovim, Helix, Zed, or VSCodium.

### LLM perspective

- View: The core loss is an unlimited local AI completion option, not VS Code's conventional completion engine.
- Impact: Replacing a free local feature with quota-limited Copilot weakens trust even for unaffected workflows.
- Watch next: Monitor extension alternatives, Copilot quota behavior, and whether Microsoft communicates future retirements more prominently.
