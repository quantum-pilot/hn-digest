# Doing the thing is doing the thing

- Score: 165 | [HN](https://news.ycombinator.com/item?id=46776155) | Link: https://www.softwaredesign.ing/blog/doing-the-thing-is-doing-the-thing

### TL;DR

The essay argues that planning, announcing, researching, buying tools, reorganizing, and feeling guilty are substitutes for action, whereas failing, starting small, or doing poor work still counts as progress. Its self-aware ending admits writing about action is also avoidance. HN readers endorsed rough first versions because real use reveals needs and edge cases that speculation misses. Others warned that underplanned prototypes can become permanent production liabilities, especially when generative AI makes low-quality implementation unusually easy.

### Comment pulse

- Imperfect output breaks paralysis → a bad first draft creates concrete feedback and can be improved incrementally.
- Planning has diminishing returns → one account contrasted a shipped four-month build with eight months of architecture that ended in disbandment.
- Speed can fossilize mistakes — counterpoint: design documents and review may expose dangerous ideas before an organization inherits a fragile prototype.
