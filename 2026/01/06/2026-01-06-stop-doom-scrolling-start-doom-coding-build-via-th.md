# Stop Doom Scrolling, Start Doom Coding: Build via the terminal from your phone

- Score: 187 | [HN](https://news.ycombinator.com/item?id=46517458) | Link: https://github.com/rberg27/doom-coding

### TL;DR

At commit bcee1c4, the January 6 guide describes doom coding as using Tailscale, Termius, SSH, and Claude Code to control an always-on computer from a phone. After enabling remote login and joining both devices to one tailnet, users connect through MagicDNS, launch the agent, track context in CLAUDE.md, and preview services over the private network. The frozen version excludes later guide additions. Hacker News split between seeing a practical gateway to productive spare moments and seeing familiar remote administration repackaged with poor ergonomics, distraction, and security risks.

### Comment pulse

- Mobile agents delivered surprising leverage for small prompts, but readers questioned safeguards when generated scripts can probe local networks.
- Alternatives included email, Telegram bots, browser interfaces, VPS hosts, Mosh, and tmux; immediacy favored terminal sessions.
- Critics rejected phone ergonomics and social distraction, while supporters valued a concrete guide even if SSH-over-VPN is not novel.

### LLM perspective

- View: The novelty is agentic leverage through an old remote-access pattern, not the networking setup itself.
- Impact: Spare-time coding expands, but review quality and situational presence may deteriorate when interaction becomes frictionless.
- Watch next: Wake-on-LAN, disposable VMs, permission boundaries, and resumable sessions could reduce energy use and accidental damage.
