# Ask HN: COBOL devs, how are AI coding affecting your work?

- Score: 148 | [HN](https://news.ycombinator.com/item?id=46678550) | Link: https://news.ycombinator.com/item?id=46678550

### TL;DR

The source is a genuinely brief question asking whether AI coding threatens or strengthens COBOL and mainframe careers, noting that economy-critical code appears largely untouched. Commenters say compliance restrictions, limited local hardware, rigid column formatting, enormous context needs, and undocumented business rules constrain model usefulness. They still find value in test-data generation, file layouts, manual search, and supervised modernization, while emphasizing that COBOL’s installed base and domain fit make imminent replacement unlikely.

### Comment pulse

- Adoption barriers → institutions cannot export code, restricted machines cannot host capable local models, and generated COBOL needs painstaking review.
- Practical utility → models help search manuals and automate tedious layouts, but deep system context remains decisive.
