# Anthropic made a mistake in cutting off third-party clients

- Score: 200 | [HN](https://news.ycombinator.com/item?id=46586766) | Link: https://archaeologist.dev/artifacts/anthropic

### TL;DR

Anthropic blocked third-party coding agents from using Claude Pro and Max subscription credentials, closing a loophole that let OpenCode users access discounted model usage outside Claude Code. The author argues the unannounced enforcement damaged goodwill, exposed Anthropic’s desire to control the full coding stack, and handed OpenAI an opening by supporting external harnesses. HN discussion largely challenged that verdict: many viewed the restriction as ordinary protection of a valuable customer relationship, while critics objected to silent rollout, lock-in, and slower client innovation.

### Comment pulse

- Vertical integration protects margins → controlling Claude Code prevents interchangeable harnesses from commoditizing models and weakening Anthropic’s customer relationship.
- Subscription access is product-specific → users bought Claude Code, not discounted general API capacity — counterpoint: Anthropic tolerated the loophole without warning.
- Lock-in carries a trust cost → critics feared proprietary tooling, weaker open-source competition, and insufficient improvement in Claude Code itself.
