# Uncrossy

- Score: 172 | [HN](https://news.ycombinator.com/item?id=46582762) | Link: https://uncrossy.com/

### TL;DR

Uncrossy is a daily word puzzle with an archive, undo and redo controls, hints, and optional auto-hints that flag positions from which the board can no longer be solved. HN players found the concept engaging enough to revisit older puzzles, but many reached dead ends only after substantial progress and wanted earlier feedback or guaranteed-solvable move paths. The creator says each puzzle is built by hand with a custom editor because grid shape and word selection require craft. Some users also hit endless loading when cookie scripts were blocked.

### Comment pulse

- Dead ends undermine otherwise enjoyable play → discovering an unwinnable state late makes users undo many moves; auto-hints partly address this.
- Puzzle generation is handcrafted → the creator uses custom tools because shape and word choices interact in ways automation may mishandle.
- Access can fail before play → cookie-manager blocking left Brave, Safari, and filtered Firefox sessions stuck loading.
