# Project Patchouli: Open-source electromagnetic drawing tablet hardware

- Score: 416 | [HN](https://news.ycombinator.com/item?id=46537489) | Link: https://patchouli.readthedocs.io/en/latest/

### TL;DR

Project Patchouli is an open-source electromagnetic-resonance drawing-tablet design comprising a coil array, an RF front end made from commercially available parts, and digital signal-processing algorithms. It aims for low-latency input and compatibility with pens from multiple vendors, while documenting the underlying mechanism, circuits, signal processing, and vendor protocols. Begun in January 2024, it produced a small prototype that March and published documentation in January 2025. The actively developed project uses separate open licenses for documentation, hardware, and code, and has received NLnet Foundation sponsorship.
