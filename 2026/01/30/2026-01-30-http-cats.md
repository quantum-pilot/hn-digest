# HTTP Cats

- Score: 173 | [HN](https://news.ycombinator.com/item?id=46824422) | Link: https://http.cat/

### TL;DR

This compact reference pairs HTTP response codes with memorable cat photographs and their associated labels, spanning informational, success, redirect, client-error, server-error, and several vendor-specific statuses. A code can be appended directly to the site address, with an optional JPEG extension, making the collection useful for direct image retrieval or quick lookup. HN users said its fast page, searchable list, visual mnemonics, and short domain make it genuine workday muscle memory; others preferred dogs or appreciated the Catalan-language version.
