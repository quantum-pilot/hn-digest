# PlayStation 2 Recompilation Project Is Absolutely Incredible

- Score: 200 | [HN](https://news.ycombinator.com/item?id=46814743) | Link: https://redgamingtech.com/playstation-2-recompilation-project-is-absolutely-incredible/

### TL;DR

PS2Recomp is an unfinished static recompiler and runtime intended to convert individual PlayStation 2 games into native builds for targets such as Windows or Linux. It is a toolchain, not an application that automatically runs the entire catalog, so each game still needs dedicated work. The article anticipates easier modification, remastering, unlocked frame rates, controller support, and lower hardware demands than emulation, but presents these as possibilities rather than demonstrated outcomes. Commenters praise preservation potential while expecting only a subset of titles to receive ports.

### Comment pulse
