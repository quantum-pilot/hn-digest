# GitHub should charge everyone $1 more per month to fund open source

- Score: 198 | [HN](https://news.ycombinator.com/item?id=46618027) | Link: https://blog.greg.technology/2025/11/27/github-should-charge-1-dollar-more-per-month.html

### TL;DR

The proposal would add $1 per organization user each month on GitHub, place the proceeds in an opt-out open-source fund, and distribute money according to dependency usage inferred from package manifests and perhaps Dockerfiles. Its aim is to replace maintainer begging with automatic support for infrastructure companies rely on. HN sharply split over whether freely licensed code is intentionally a gift or creates obligations once it becomes load-bearing, while raising harder questions about allocation, consent, metric gaming, AI-generated dependency spam, and whether existing grants, sponsorships, and direct asks already suffice.

### Comment pulse

- Free licenses define a gift without support obligations → counterpoint: accidental criticality creates maintenance and security burdens creators never accepted.
- Usage-based payouts invite manipulation → synthetic packages and dependency stuffing could turn funding metrics into a spam economy.
- Existing channels may be enough → maintainers who clearly request donations, grants, or corporate sponsorship can already receive meaningful support.
