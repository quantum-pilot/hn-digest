# Zotero 8

- Score: 170 | [HN](https://news.ycombinator.com/item?id=46735616) | Link: https://www.zotero.org/blog/zotero-8/

### TL;DR

Version 8 unifies citation and note insertion in one dialog with fast search and a browsable library mode. PDF, EPUB, and snapshot annotations now appear beneath attachments for search, tagging, and note creation. The reader adds global themes and snapshot reading mode; notes can open in tabs, the tab menu supports keyboard search, and attachment filenames continuously follow metadata changes. Other additions include ARM64 Linux builds and Connector tag autocomplete. Commenters praised the nonprofit tool’s reliability, usefulness, and data control, while noting that fully self-hosting its server remains difficult.
