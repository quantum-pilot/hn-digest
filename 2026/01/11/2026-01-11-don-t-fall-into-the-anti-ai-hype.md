# Don't fall into the anti-AI hype

- Score: 500 | [HN](https://news.ycombinator.com/item?id=46574276) | Link: https://antirez.com/news/158

### TL;DR

The author argues coding agents have crossed a practical threshold: with occasional guidance, Claude Code completed UTF-8 library work, Redis test debugging, a 700-line C embedding library, and a Redis Streams redesign in hours rather than weeks. He sees programming shifting from typing code toward defining problems, urges sustained experimentation, favors open models, and worries about job losses and concentration. HN agreed the tools are useful but split over lost flow, early-adopter advantage, managerialization, labor outcomes, and whether unstable workflows or weak business economics justify waiting.

### Comment pulse

- Programming motivations differ → builders welcome delegation, while flow-oriented coders find reviewing generated tokens miserable and less joyful.
