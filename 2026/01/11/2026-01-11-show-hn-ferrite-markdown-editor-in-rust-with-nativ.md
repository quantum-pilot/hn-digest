# Show HN: Ferrite – Markdown editor in Rust with native Mermaid diagram rendering

- Score: 226 | [HN](https://news.ycombinator.com/item?id=46571980) | Link: https://github.com/OlaProeis/Ferrite

### TL;DR

Ferrite is an MIT-licensed Rust/egui desktop editor for Markdown, JSON, YAML, and TOML, emphasizing native startup and local files over Electron. It combines raw, rendered, split, and Zen modes with workspace search, Git status, syntax highlighting, structured-data trees, session restore, and native rendering for 11 Mermaid diagram types. The developer says Claude generated all code and documentation under human product direction and testing. HN welcomed a Windows-friendly Obsidian alternative but sharply debated trust in fully AI-generated code, disclosure timing, project goals, and unreadable screenshots.

### Comment pulse
