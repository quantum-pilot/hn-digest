# Make.ts

- Score: 211 | [HN](https://news.ycombinator.com/item?id=46792194) | Link: https://matklad.github.io/2026/01/27/make-ts.html

### TL;DR

Matklad recommends capturing ad hoc terminal commands in a consistently named, locally ignored executable file before running them, rather than relying on shell history. His TypeScript/Deno version uses dax template literals and async/await to compose commands and concurrent processes. A one-off TigerBeetle recovery experiment naturally evolved into a repeatable benchmark matrix without a later rewrite. The file is intentionally personal and disposable until a command deserves the project build system. HN readers endorse persistence but debate TypeScript versus shell, Make, just, mise, and history search.

### Comment pulse
