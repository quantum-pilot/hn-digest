# JavaScript Demos in 140 Characters

- Score: 148 | [HN](https://news.ycombinator.com/item?id=46557489) | Link: https://beta.dwitter.net

### TL;DR

Dwitter hosts animated JavaScript sketches constrained to 140 characters, with examples ranging from fractals and planetary scenes to keyboards, fields, and dynamic lighting. Creators exploit canvas APIs, mathematical shorthand, tagged templates, and sometimes Unicode packing plus runtime decompression. HN celebrated the creative pressure of code golf and the community around remixing tiny demos, but debated whether character-based limits are meaningful when multibyte symbols encode much larger ASCII programs. Several commenters favored byte limits or showing decompressed code alongside entries.

### Comment pulse

- Tight limits generate invention → contributors credit code golf with teaching compression techniques and reshaping how they think about programs.
- Unicode packing weakens the premise → a nominal 140-character entry can decode into substantially more ASCII.
- The community matters → remixing, themed collections, and appreciative feedback make browsing an alternative to doomscrolling.
