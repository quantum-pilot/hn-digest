# Photo GIMP – A Patch for GIMP 3 for Photoshop Users

- Score: 189 | [HN](https://news.ycombinator.com/item?id=48167890) | Link: https://github.com/Diolinux/PhotoGIMP

### TL;DR

PhotoGIMP is a GPLv3 configuration patch for GIMP 3 that rearranges tools and panels, maps Photoshop’s Windows shortcuts, maximizes canvas space, and adds a custom splash and Linux launcher identity. It supports Linux, Windows, and macOS without forking GIMP or replacing brushes, fonts, gradients, or plug-ins, but installation overwrites user configuration, so backups are advised. HN welcomed the low-maintenance bridge for Photoshop-trained users while reopening familiar arguments over GIMP’s opaque workflows, conservative defaults, scarce maintainers, and whether Blender-style UX progress requires substantial corporate funding.
