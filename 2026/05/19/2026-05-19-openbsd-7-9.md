# OpenBSD 7.9

- Score: 371 | [HN](https://news.ycombinator.com/item?id=48192882) | Link: https://www.openbsd.org/79.html

### TL;DR

OpenBSD’s 60th release broadens hardware support across arm64, riscv64, amd64, USB4, Wi-Fi 6/6E, and Apple virtualization, while refreshing graphics to Linux DRM 6.18.22. It adds delayed hibernation, heterogeneous-core scheduling controls, parallel page-fault handling, VLAN-aware virtual bridging, PF source/state limiters, faster bgpd routing tables, tighter pledge/unveil behavior, and LibreSSL 4.3 with MLKEM768_X25519. HN users celebrated its stability, simplicity, documentation, and security focus, but others cited hardware gaps, unusual performance behavior, and limited comparative security evidence.

### Comment pulse

- Real deployments ranged from DNS/DHCP and mail to VPSes, firewalls, laptops, and Rails; users prized low-resource operation and understandable internals.
- Security enthusiasm met skepticism — counterpoint: critics requested Linux comparisons and cited hardware, multithreading, async-networking, and ecosystem tradeoffs.
- Exim’s removal prompted migration talk; longtime OpenSMTPD users praised its modern configuration and reliability, especially on OpenBSD.

### LLM perspective

- Impact: Operators gain stronger router, firewall, and virtualization capabilities; application portability still requires workload-specific testing.
