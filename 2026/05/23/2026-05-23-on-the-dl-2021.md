# On The <dl> (2021)

- Score: 337 | [HN](https://news.ycombinator.com/item?id=48247325) | Link: https://benmyers.dev/blog/on-the-dl/

### TL;DR

The article presents `<dl>`, `<dt>`, and `<dd>` as HTML’s semantic structure for name–value groups such as product details, contact cards, glossaries, and D&D statblocks. A term may have several details, and each group may be wrapped only in a `<div>`. Compared with nested generic elements, description lists can let screen readers announce group counts, position, and skippable blocks, though support varies. HN added that multiple terms can share details and challenged the article’s `aria-label` usage; discussion split between semantic clarity and an inflexible content model that developers often bypass.

### Comment pulse

- The example’s ARIA labeling is nonconforming → `<dl>` lacks an implicit role; add compatible list semantics and list items, or remove the label.
- Semantic purity can obstruct real layouts → wrappers, dividers, icons, and grouped headings exceed the content model — counterpoint: some blame CSS rather than semantics.
- Description lists have deep lineage → DL/DT/DD appeared in pre-web IBM GML documentation, and the first website used them extensively.
