# Linux security mailing list 'almost unmanageable'

- Score: 194 | [HN](https://news.ycombinator.com/item?id=48178692) | Link: https://www.theregister.com/security/2026/05/18/linus-torvalds-says-ai-powered-bug-hunters-have-made-linux-security-mailing-list-almost-entirely-unmanageable/5241633

### TL;DR

Linus Torvalds says duplicated AI-found bug reports have overwhelmed Linux’s private security list: maintainers repeatedly route reports or explain that issues were already fixed publicly. Because independently generated findings are not secret and private reporting hides duplicates from other reporters, kernel guidance says AI-assisted discoveries should be treated as public. Torvalds welcomes useful AI work but asks reporters to read the rules, understand findings, and contribute patches instead of sending drive-by output. HN agreed this was an intake-quality problem, not anti-AI hostility, and criticized The Register for implying otherwise.
