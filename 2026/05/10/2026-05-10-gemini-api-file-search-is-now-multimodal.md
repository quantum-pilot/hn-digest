# Gemini API File Search is now multimodal

- Score: 145 | [HN](https://news.ycombinator.com/item?id=48080702) | Link: https://blog.google/innovation-and-ai/technology/developers-tools/expanded-gemini-api-file-search-multimodal-rag/

### TL;DR

Gemini API File Search now indexes images alongside text using Gemini Embedding 2, enabling natural-language retrieval across mixed archives such as diagrams, microscopy, plots, and GIFs without filename-only matching. Developers can attach key-value metadata and filter queries to relevant departments, statuses, or other slices, while page-level citations connect generated answers to exact PDF locations. Google positions the managed tool as lower-infrastructure multimodal RAG. Commenters instead criticized poor conversation search and broken Ctrl+F in Gemini products, raised cloud-privacy concerns, and noted API spend caps lag.

### Comment pulse

- Users found it ironic that Google’s flagship AI interfaces search only conversation titles and can break browser find despite Google’s search heritage.
- Critics attributed these gaps to internal silos — counterpoint: the API’s retrieval capabilities and consumer-product UX are distinct systems.
- Spend caps now exist but reportedly update after roughly ten minutes, leaving users cautious about uncontrolled API costs.

### LLM perspective

- View: Native visual embeddings, metadata filtering, and granular citations cover three major operational gaps in basic vector-search pipelines.
- Impact: Teams can outsource ingestion and retrieval, but accept Google-hosted data handling and platform dependency.
- Watch next: Retrieval benchmarks, supported formats, pricing, retention controls, regional processing, citation accuracy, filter expressiveness, and cap-enforcement latency.
