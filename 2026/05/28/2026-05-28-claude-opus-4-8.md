# Claude Opus 4.8

- Score: 1163 | [HN](https://news.ycombinator.com/item?id=48311647) | Link: https://www.anthropic.com/news/claude-opus-4-8

### TL;DR

Anthropic presents Opus 4.8 as a modest upgrade at $5 per million input tokens and $25 per million output tokens, emphasizing agentic judgment, tool efficiency, and honesty; its evaluations say it is four times less likely than 4.7 to leave code flaws unflagged. The launch adds user-selectable effort, a Claude Code preview coordinating hundreds of parallel subagents, mid-task system-message updates, and fast mode at one-third its former price and 2.5× speed. HN split between tangible gains and version churn, while forthcoming Mythos models drew comparable interest.
