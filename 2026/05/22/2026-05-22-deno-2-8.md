# Deno 2.8

- Score: 293 | [HN](https://news.ycombinator.com/item?id=48234380) | Link: https://deno.com/blog/v2.8

### TL;DR

Deno 2.8 deepens compatibility with Node projects: unprefixed packages default to npm, cold installs are 3.66× faster, and Node’s test-suite pass rate jumps from about 42% to 76.4%, versus Bun 1.3.14’s 40.6%. New commands handle locked CI installs, vulnerability fixes, versioning, npm-ready packing, transpilation, and dependency tracing; debugging gains network inspection and CPU profiles. HN users praised Deno’s permissions, TypeScript support, and unified CLI, but said Bun won early through easier Node/framework compatibility and questioned Deno’s shifting product direction.

### Comment pulse

- Early strategy shaped adoption → Bun prioritized Node and framework compatibility; Deno’s original redesign left Astro, Prisma, and Vite users facing breakage.

- Professional adoption needs stability → hobbyists report excellent ergonomics — counterpoint: business-driven direction changes can force production teams back to Node.
