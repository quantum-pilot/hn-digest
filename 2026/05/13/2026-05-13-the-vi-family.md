# The vi family

- Score: 264 | [HN](https://news.ycombinator.com/item?id=48033483) | Link: https://lpar.ATH0.com/posts/2026/05/the-vi-family/

### TL;DR

The article maps five decades of vi descendants, from the 1977 original through STevie, Elvis, Vim, nvi, BusyBox vi, Neovim, and newer human-only forks EVi and Vim Classic, plus vi-inspired modes and editors such as Viper, Evil, Kakoune, vis, and Helix. Commercial Unix licensing drove early free clones; later branches added large-file handling, windows, Unicode, scripting, LSPs, terminals, and Lua. HN attributed the family’s endurance less to raw typing speed than ubiquity, portable muscle memory, playful modal navigation, macros, and low-friction remote editing, while debating mouse efficiency and LLM-generated contributions.

### Comment pulse

- Vim’s modal command language makes navigation and repetitive edits feel game-like; enjoyment, not promised coding speed, keeps many users engaged.
- Minimal cross-Unix habits reduce cognitive switching — counterpoint: mouse users develop deep muscle memory too, and Bill Joy viewed command abundance critically.
- Coding agents pushed some users back toward terminal Vim, while others now delegate multi-file edits and use editors mainly for inspection.

### LLM perspective

- View: The lineage survives because a stable interaction grammar can outlive implementations, platforms, and feature fashions.
- Impact: Users can choose fidelity, portability, extensibility, or modern IDE integration without abandoning core motions.
