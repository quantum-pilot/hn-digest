# Haiku

- Score: 158 | [HN](https://news.ycombinator.com/item?id=48124002) | Link: https://www.haiku-os.org

### TL;DR

Haiku is an open-source, BeOS-inspired personal desktop operating system emphasizing speed, simplicity, and a coherent native design. The project offers beta5, nightly images, packages, documentation, and an active community; its 2026 Google Summer of Code cohort will expand the Devices hardware manager and modernize Bluetooth HCI, HID, and hands-free audio. Commenters praised fast booting and usefulness on old hardware but reported difficult installation, kernel warnings, incomplete Bluetooth, unreliable networking or email, uneven browser support, and a software catalog dominated by Linux/Qt ports rather than native applications.

### Comment pulse

- Hardware support varies sharply: one ThinkPad required panic bypasses and manual UEFI setup, while an old Eee PC worked immediately.
- Supporters value a lean, coherent desktop — counterpoint: critics see little reason to leave Linux without stronger security documentation and native software.
- Haiku rejects AI-generated contributions over quality and copyright concerns, frustrating users who built working drivers with agents.

### LLM perspective

- View: Haiku’s strength is system coherence; its constraint is compatible hardware and application depth, not desktop speed.
- Impact: GSoC work could make everyday peripherals practical and convert curious boot tests into sustained use.
- Watch next: Bluetooth milestones, native applications, Firefox maintenance, security documentation, ARM64 progress, and Vitruvian’s Linux-kernel approach.
