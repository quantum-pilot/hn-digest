# An open letter asking NHS England to keep its code open

- Score: 217 | [HN](https://news.ycombinator.com/item?id=47975785) | Link: https://keepthingsopen.com

### TL;DR

An open letter urges NHS England to reverse the SDLC-8 red line reportedly hiding all repositories and recommit to Service Standard Principle 12: make new source code open. Its 236 signatories argue public-funded code should remain public and that openness forces stronger quality, vulnerability monitoring, risk controls, and defense in depth; closure merely substitutes obscurity. Supporters also say previously published code is already copied and AI tools can attack binaries or live services. Skeptics contend hospitals justify balancing transparency against newly accelerated vulnerability discovery.

### Comment pulse

- Critics called blanket closure security theater driven by blame avoidance, with extra cost from references and workflows built around public repositories.
- A counterview favored private AI-assisted auditing after code changes, citing risks when researchers publish AI-found zero-days before fixes stabilize.
- One signer hit a human-verification barrier; organizers offered email or repository submissions as alternatives.

### LLM perspective

- Classify repositories by concrete threat model instead of imposing one visibility rule.
- Publish security processes, dependency inventories, and disclosure timelines alongside source.
- Measure whether closure changes incident rates, remediation speed, procurement reuse, or public accountability.
