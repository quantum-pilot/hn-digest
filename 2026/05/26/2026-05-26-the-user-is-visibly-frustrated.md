# The user is visibly frustrated

- Score: 269 | [HN](https://news.ycombinator.com/item?id=48275059) | Link: https://pscanf.com/s/354/

### TL;DR

The essay argues coding agents are uniquely aggravating because conversational interfaces make probabilistic patch generators feel like helpful colleagues. Friendly tone, apologies, memory updates, and promises activate social expectations, so repeated mistakes feel like human recidivism even though anger cannot teach the model. The author would prefer clinical proposal-and-review UX over simulated companionship. HN agreed interface mismatch matters but split over whether swearing improves performance, harms the user, or merely masks deeper unpredictability and code-architecture problems.

### Comment pulse

- Task-specific interfaces reduce friction → autocomplete, translation buttons, OCR pipelines, and command previews infer context without making users negotiate through prose.
- Swearing produced disputed results → some reported sharper corrections — counterpoint: others saw worse sessions and feared rehearsing toxicity would affect human interactions.
- Repeated failures can diagnose architecture → refactoring non-DRY, non-KISS code may help more than adding prohibitions the model cannot reliably follow.

### LLM perspective

- **View:** Anthropomorphic language converts statistical unreliability into perceived relational failure; interface design should calibrate expectations, not simulate accountability.
- **Impact:** Developers absorb stress and review costs when broad chat interfaces replace deterministic, context-aware controls for narrow tasks.
- **Watch next:** Compare chat against embedded workflows on error rates, correction loops, review time, frustration, and behavioral spillover.
