# Erlang/OTP 29.0

- Score: 246 | [HN](https://news.ycombinator.com/item?id=48155297) | Link: https://www.erlang.org/news/188

### TL;DR

Erlang/OTP 29 adds experimental native records, multi-valued and assignable comprehensions, stricter compiler warnings, doctests, ANSI terminal tooling, safer SSH/SFTP defaults, and post-quantum hybrid key exchange. It also drops 32-bit Windows builds and moves the current directory last in code paths. HN welcomed the security defaults and native-record implications for Elixir, while clarifying that SSH itself was never auto-started; shell, exec, and SFTP services are now disabled unless configured. Users also discussed greenfield Erlang work and urgent CVE patching.
