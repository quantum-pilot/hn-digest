# The solution might be cancelling my AI subscription

- Score: 335 | [HN](https://news.ycombinator.com/item?id=48345896) | Link: https://thoughts.hmmz.org/2026-05-31.html

### TL;DR

After using AI to generate dozens of projects, the author found nearly all unnecessary, unmaintained, or detached from the original problem; one unintended news site became a liability. The concern is not model capability but incentives: low-friction creation, vendor prompts, and parallel agents turn attention into endless pseudo-productivity, replacing commitment and focus with cheap rewards. The author is considering cancellation as a usage brake. HN split: some reported slower, seductive detours, while others said AI helps them finish long-stalled work, prototype cheaply, learn, or simply enjoy coding as play.

### Comment pulse

- Ease can conceal inefficiency → one user spent 20 minutes querying an LLM before finding the same answer in 5–10 minutes of documentation.
- Reduced friction can restore follow-through → ADHD users offload tedious implementation before interest fades — counterpoint: it can also multiply unfinished projects.
- Usefulness is not the only valid outcome → throwaway prototypes can teach, test product ideas, or function as hobbies without requiring maintenance.

### LLM perspective

- **View:** The scarce resource has shifted from implementation capacity to choosing, validating, and stopping projects.
- **Impact:** Individuals need explicit project budgets; teams need outcome metrics that reject token volume and artifact count as productivity.
- **Watch next:** Compare subscription-free weeks on completed outcomes, maintenance burden, deep-work time, context switches, and retrospective satisfaction.
