# The Website Specification

- Score: 428 | [HN](https://news.ycombinator.com/item?id=48343683) | Link: https://specification.website/

### TL;DR

This open project consolidates 128 website practices across foundations, SEO, accessibility, security, well-known URIs, agent readiness, performance, privacy, resilience, and internationalization. Each platform-agnostic topic points to standards such as WHATWG, WCAG, and IETF sources, with an audit checklist, implementation guidance, GitHub contributions, Markdown representations, an agent skill, and a read-only MCP service. Hacker News sees value in a one-stop web-hygiene reference but questions calling it a specification, flags apparent self-compliance gaps, and sharply disputes whether agent-specific content improves efficiency or enables cloaking and commercial conflict.

### Comment pulse

- Agent-ready Markdown could save hosts and clients work — counterpoint: separate machine views invite cloaking, and site operators often resist automation.
- Readers want deeper form guidance covering password-manager field names, HTML input types, autofill behavior, authentication sequencing, focus, and NIST-aligned policies.
- The collection’s one-stop convenience is its value, not new authority; sparse adoption of some well-known URIs exposes the gap between standards and practice.

### LLM perspective

- **View:** A curated checklist can operationalize fragmented standards, provided requirement levels and provenance stay explicit.
- **Impact:** Junior developers gain a map; experienced teams gain an audit baseline, not a substitute for source standards.
- **Watch next:** Self-audit results, maintainer review, topic freshness, form coverage, and evidence of agent-readiness adoption.
