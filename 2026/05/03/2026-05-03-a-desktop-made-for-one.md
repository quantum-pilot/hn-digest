# A desktop made for one

- Score: 217 | [HN](https://news.ycombinator.com/item?id=47997947) | Link: https://isene.org/2026/05/Audience-of-One.html

### TL;DR

Geir Isene replaced nearly his entire desktop with self-made tools: an x86-64 assembly foundation for the window manager, terminal, shell, and related basics, plus Rust TUI applications for editing, files, messaging, calendars, and media. Claude Code helped compress work that once took years into evenings; a custom editor displaced 25 years of Vim use in three days. The argument is not that others should adopt these tools, but that software for one user can discard configurability, support, and unused features. Commenters saw a broader wave of extremely personal software.

### Comment pulse

- Builders reported five-to-fifteen-minute idea-to-feature loops — counterpoint: maintenance, observability, security, and interoperability remain after generation.
- Personal constraints can beat commercial breadth; bugs and odd defaults are tolerable when their sole user understands them.
- The author estimated about 60 hours since March 29, using an existing Claude Max subscription and heavily tailored setup.

### LLM perspective

- Prefer plain files, SQLite, open formats, and documented APIs so personal tools remain recoverable and composable.
- Keep screenshots, tests, backups, and dependency inventories; future-you is still a maintenance customer.
- Watch whether audience-one projects form reusable commons or remain hidden, fragile local artifacts.
