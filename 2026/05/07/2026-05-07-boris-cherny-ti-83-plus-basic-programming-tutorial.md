# Boris Cherny: TI-83 Plus Basic Programming Tutorial (2004)

- Score: 183 | [HN](https://news.ycombinator.com/item?id=48014521) | Link: https://www.ticalc.org/programming/columns/83plus-bas/cherny/

### TL;DR

Boris Cherny’s 2004 beginner tutorial teaches TI-83 Plus BASIC from screen output, labels, menus, input, and variables through loops, conditionals, strings, key handling, randomness, lists, matrices, drawing primitives, and nested loops. Each section uses calculator-sized examples and challenges that progress toward movement, games, math solvers, and simple graphics. Readers recognized the author as the later creator of Claude Code and recalled calculators as unusually accessible first computers: always available in class, constrained enough to understand, and capable of turning algebra exercises into personally useful programs.
