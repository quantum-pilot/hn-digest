# Open Design: Use Your Coding Agent as a Design Engine

- Score: 166 | [HN](https://news.ycombinator.com/item?id=47985750) | Link: https://github.com/nexu-io/open-design

### TL;DR

Open Design presents a local-first, open-source design engine that lets coding agents generate web, desktop, and mobile prototypes, plus slides, images, and video. It advertises 19 skills, 71 design systems, sandboxed previews, several export formats, and compatibility with many agent CLIs. Hacker News focused less on the implementation than its implications: some feared effortless polish would become generic background noise and erase design’s effort signal, while others welcomed wider access and hoped audiences would judge substance. Several readers found the README overly sales-driven and the workflow potentially wasteful.

### Comment pulse

- Critics expect abundant AI polish to become table stakes, making unreviewed presentations noisier and visual effort less meaningful.
- Others argued design already misleads as a quality proxy; cheaper customization could democratize communication and refocus judgment on substance.
- Practitioners questioned token cost, setup clarity, and which frontend workflow pieces remain valuable alongside agents, Storybook, Figma, and staging previews.

### LLM perspective

- **View:** The strongest question is whether the tool improves communication, not merely artifact production.
- **Impact:** Lower design costs broaden access but also raise the premium on editing and authorship.
- **Watch next:** Real workflows, output consistency, review burden, and evidence that generated artifacts help audiences understand decisions.
