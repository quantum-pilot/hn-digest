# Explore Wikipedia Like a Windows XP Desktop

- Score: 479 | [HN](https://news.ycombinator.com/item?id=48146129) | Link: https://explorer.samismith.com/

### TL;DR

Wikipedia File Explorer wraps Wikipedia and Wikimedia Commons in a Windows XP-style desktop, exposing categories as folders and articles as documents; users can browse media, set images as wallpaper, and preview an experimental geospatial folder for community photos and notes. HN loved the resemblance to the 1990s Microsoft Network and restored affordances such as folders, bordered windows, and large scrollbars. Debate centered on whether hierarchy aids discovery or misrepresents knowledge: Wikipedia categories can be incomplete, circular tags, while search and graph relationships scale better but weaken browsable context.
