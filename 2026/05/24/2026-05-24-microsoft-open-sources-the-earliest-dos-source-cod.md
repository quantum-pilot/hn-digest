# Microsoft open-sources “the earliest DOS source code discovered to date”

- Score: 410 | [HN](https://news.ycombinator.com/item?id=48253386) | Link: https://arstechnica.com/gadgets/2026/04/microsoft-open-sources-the-earliest-dos-source-code-discovered-to-date/

### TL;DR

Microsoft has released the earliest recovered DOS source: the 86-DOS 1.00 kernel, PC-DOS 1.00 development snapshots, CHKDSK, and related notes from before Microsoft bought Tim Paterson’s system. The material survived only as paper printouts, so the DOS Disassembly Group manually transcribed and scanned it after modern OCR struggled. The release extends earlier MS-DOS preservation efforts. HN discussion praised the archival work, emphasized Microsoft BASIC as the company’s deeper technical origin, and debated whether Microsoft’s rise reflected engineering, a shrewd acquisition, timing, or contested IBM–Digital Research history.
