# OpenAI GPT–6 Astra breaks Enigma message that has resisted solution since 2005

- Score: 715 | [HN](https://news.ycombinator.com/item?id=49801324) | Link: https://www.cryptocellar.org/bgac/the-mvueh-break.html

### TL;DR

Cryptanalyst Frode Weierud validated a key and plaintext that Carter Leffer’s GPT-6 Astra agent found for MVUEH, an 82-letter 1941 German Army Enigma message unsolved since 2005. Astra reportedly selected the target, linked it to a similar solved message, used repeated ROSENOW as a crib, and built simulator and Bombe software. Transcription errors, a rare left-wheel turnover, and a wholly different key likely impeded earlier work. Logs are still being analyzed, and HN readers questioned autonomy, provenance, and computational cost.
