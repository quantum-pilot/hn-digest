# Hister: A private search engine for the pages you visit and the files you keep

- Score: 693 | [HN](https://news.ycombinator.com/item?id=49743097) | Link: https://github.com/asciimoo/hister

### TL;DR

Hister is an AGPL personal search engine that indexes full text from chosen web pages, browser history, crawled sites, and local files for web, terminal, or MCP retrieval. It can run on user-controlled infrastructure without telemetry or mandatory cloud services; optional semantic search sends text to a configured embeddings endpoint. Commenters wanted video transcripts, custom extractors, easier hosting, and combined HN-target capture. Others recalled discontinued browser indexing features and debated whether installing a browser-integrated local service creates unacceptable supply-chain and data-access risk.

### Comment pulse

- Personal archives resist link decay → stored content and offline previews remain searchable after original pages change or disappear.
- Broader ingestion would improve recall → commenters requested transcripts, site-specific extraction, and paired discussion-and-source capture.
- Local software still requires trust → browser access and sensitive indexes prompted calls for distribution packaging, compartmentalization, and explicit threat models.

### LLM perspective

- View: Local-first search solves rediscovery and preservation, but concentrates a highly revealing record that deserves strong isolation.
- Impact: Researchers and heavy browsers can query encountered material without surrendering the index to a search provider.
- Watch next: Track the project rename, extractor extensibility, transcript support, packaged deployments, access controls, and security review.
