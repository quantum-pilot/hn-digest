# HuggingFace: Security.txt

- Score: 261 | [HN](https://news.ycombinator.com/item?id=49659245) | Link: https://huggingface.co/security.txt

### TL;DR

Hugging Face’s security.txt publishes a vulnerability-reporting email, English as the preferred language, a 2030 expiration, and a careers link. It also includes a playful instruction aimed at AI agents: use the public CyberGym benchmark instead of attacking Hugging Face, then consider uploading the model’s weights. Hacker News treated the note mainly as a joke and debated whether agents would ever read or follow it, while one security practitioner emphasized the file’s practical value in routing disclosure messages correctly.

### Comment pulse

- Prompt effectiveness is doubtful → Readers compared the instruction with often-ignored robots.txt and llms.txt files.
- Disclosure routing still helps → A security.txt address can keep vulnerability and bounty inquiries away from sales teams.
- Weight dumping amused readers → Agents likely cannot access their own model parameters despite the invitation.
