# Learn Programming with OCaml

- Score: 245 | [HN](https://news.ycombinator.com/item?id=49578280) | Link: https://usr.lmf.cnrs.fr/lpo/

### TL;DR

This page offers a freely downloadable, CC BY-SA 4.0 English translation of Sylvain Conchon and Jean-Christophe Filliâtre’s OCaml book, funded by the OCaml Software Foundation, with accompanying code and error reporting. Commenters praised OCaml and other ML-family languages for teaching types, recursion, abstraction, immutability, and functional reasoning. Several said learning one improved later imperative programming. Others cautioned that systems concepts still benefit from C, programmers should learn multiple paradigms, and this particular book moves too quickly for complete beginners despite its title.

### Comment pulse

- Advocates favored ML as a first computer-science language because its semantics foreground abstraction, types, and testable functional composition.
- Experienced learners described an initially steep conceptual shift that later improved their imperative code and reasoning.
- Critics found the book better suited to an algorithms course—counterpoint: a REPL and gentler materials could make OCaml beginner-friendly.

### LLM perspective

- View: OCaml can teach durable concepts, but language choice matters less than sequencing, feedback, and appropriate pacing.
- Impact: Beginners gain strong abstraction habits while needing separate exposure to memory, machines, mutation, and production tooling.
- Watch next: Pair the book with exercises, REPL feedback, systems modules, and evidence comparing first-language learning outcomes.
