# Java 27

- Score: 346 | [HN](https://news.ycombinator.com/item?id=49712041) | Link: https://mail.openjdk.org/archives/list/announce@openjdk.org/thread/ORGGLMN75HFEWP7YL3ZLGHLYHVIBJDYT/

### TL;DR

JDK 27 reached general availability with nine JEPs, including G1 as the default garbage collector everywhere, compact object headers by default, post-quantum hybrid TLS key exchange, and JFR data redaction. Structured concurrency, lazy constants, primitive patterns, PEM encodings, and the Vector API remain preview or incubator features. Discussion praised Java’s six-month cadence and conservative evolution, debated whether version numbers overstate language change, and framed Java as a dependable greenfield choice for long-lived, team-maintained systems.

### Comment pulse

- Frequent releases enable feedback → preview iterations expose designs early without permanently committing flawed features.
- Java remains attractive for durable systems → mature tooling, libraries, hiring pools, performance, and strict typing support large teams.
- Ecosystem breadth has costs → multiple community implementations offer choice but require evaluation that integrated platforms avoid.
