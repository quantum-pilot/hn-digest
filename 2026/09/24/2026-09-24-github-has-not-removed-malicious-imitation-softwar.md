# GitHub has not removed malicious imitation software after 3 weeks

- Score: 272 | [HN](https://news.ycombinator.com/item?id=49832406) | Link: https://successfulsoftware.net/2026/09/24/github-has-not-removed-malicious-imitation-software-after-3-weeks/

### TL;DR

An Easy Data Transform customer found a GitHub repository impersonating the paid software with its name and logo. The author reported it on August 31, then added VirusTotal malware warnings and installer evidence on September 10, but received only an automated response for 23 days. On September 24, roughly ten minutes after the complaint reached Hacker News’s front page, GitHub removed the repository. HN readers criticized attention-driven support while noting review capacity and false takedowns complicate automatic removal.
