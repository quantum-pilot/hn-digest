# Ideas on modernizing the open-source desktop

- Score: 400 | [HN](https://news.ycombinator.com/item?id=49825642) | Link: https://lwn.net/SubscriberLink/1095425/2d9f411252325784/

### TL;DR

At Akademy, UX veteran Scott Jenson urged open-source desktops to experiment beyond the mature WIMP model instead of following increasingly stagnant or user-hostile commercial platforms. His prototypes explored widescreen-centered window layouts, edge windows collapsing into widgets, persistent visual collections that extend the clipboard, and attention-derived history as working memory. HN readers agreed recall and session continuity deserve work, but emphasized that desktop workflows are deeply personal and that experimentation must remain optional, stable, privacy-preserving, and compatible with established setups.

### Comment pulse

- Desktop working memory is a genuine gap → persistent cross-application collections could preserve project context beyond windows, clipboards, and individual files.
- Innovation should not erase settled workflows → users resist relearning interfaces whose benefits are subjective or whose implementations may disappear.
- No single layout fits everyone → tiling, traditional, document-centric, and experimental models serve different mental habits — counterpoint: opt-in prototypes expand choice.
