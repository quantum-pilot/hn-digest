# Muse Spark 1.3

- Score: 557 | [HN](https://news.ycombinator.com/item?id=49541256) | Link: https://developer.meta.com/ai/models/muse-spark/

### TL;DR

Meta presents Muse Spark 1.3 as a one-million-token-context model optimized for agentic coding, tool use, conflicting inputs, and native video, image, and document perception. Its contributor tier costs $0.10 per million input tokens and $0.20 per million output tokens but permits product-improvement use; the non-training tier charges $1.25 and $4.25 respectively. Meta also promotes multi-agent coding, computer use, GitHub automation, and search grounding. Commenters welcomed the explicit data-for-discount trade, while questioning whether leaderboard scores predict dependable software work.
