# Can I opt out of my input or output data being used for training?

- Score: 434 | [HN](https://news.ycombinator.com/item?id=49535284) | Link: https://help.mistral.ai/en/articles/455207-can-i-opt-out-of-my-input-or-output-data-being-used-for-training

### TL;DR

Mistral’s updated documentation says some conversations, documents, and other inputs or outputs may enter model-training programs, but users can opt out. Standard Vibe accounts are not opted out by default; Enterprise Vibe is. Web administrators disable an interaction-training toggle, while mobile users deselect data sharing. Studio and API customers must separately disable “Anonymous improvement data” in the admin privacy menu. The Vibe and API settings do not synchronize. Discussion centered on confusing terminology, recent documentation inconsistencies, centralized organization controls, and whether contractual assurances deserve trust.
