# Ambient CSS v3 – Blender meets CSS

- Score: 252 | [HN](https://news.ycombinator.com/item?id=49523387) | Link: https://ambientcss.vercel.app/

### TL;DR

Ambient CSS v3 presents an interactive, physically based styling system with global light direction, elevation, bounce, surface shapes, material finishes, colors, edge treatments, and React-only controls. The captured demo labels materials such as matte, glass, brushed, spun, and blasted, but provides no technical explanation of its output. Commenters liked the ambition of Blender-like lighting for CSS, yet reported lag, flicker, broken controls, weak dark-mode behavior, inconsistent affordances, and unattractive textures. Others questioned whether generated CSS remains practical and maintainable.

### Comment pulse

- Shared lighting could make interface surfaces visually coherent → one control can relight an entire component scene.
- Physical imitation does not ensure usable interaction → commenters criticized tiny typography, unclear button states, and pointer-hostile knobs.
- Orthographic projection stabilizes scrolling → counterpoint: elevation then changes shadows without making raised objects appear larger.
