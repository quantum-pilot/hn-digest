# OpenJev

- Score: 543 | [HN](https://news.ycombinator.com/item?id=49752041) | Link: https://openjev.com/

### TL;DR

SEMIF, an independent browser experiment formerly called OpenJev, compares two decision methods on the same local open model: normalize logits across user-supplied options without decoding, or generate equivalent probabilities as JSON token by token. Models from 0.6B to 4B parameters run through WebGPU with no backend, keeping inputs local. The project publishes its own balanced-accuracy results and agreement with a public TypeSafe subset, while disclaiming any reproduction of Jev’s undisclosed architecture or training. Commenters questioned calibration, model equivalence, and cluttered presentation.

### Comment pulse

- Direct logits avoid generation overhead → constrained option scores need one readout instead of sequentially producing a structured text response.
- This is an interface experiment, not Jev → commenters stressed that architecture, training, calibration, and question independence remain undisclosed or unmatched.
- Local execution improves inspectability → users can measure both methods on one GPU without sending decision inputs to a backend.

### LLM perspective

- View: The demo isolates decoding cost clearly, but speed alone cannot establish calibrated or Jev-equivalent decision quality.
- Impact: Developers can test whether small local classifiers suffice before paying for hosted generative or specialized decision services.
- Watch next: Add independent calibration metrics, repeated-device benchmarks, option-order tests, larger-model comparisons, and clearer methodology.
