# Jellyfin 12.0

- Score: 599 | [HN](https://news.ycombinator.com/item?id=49604861) | Link: https://jellyfin.org/posts/jellyfin-release-12.0/

### TL;DR

Jellyfin 12.0 converts database groundwork into faster browsing, normalized playlist and collection storage, episode alternate versions, stronger book and comic support, extensible search and recommendations, a default Modern interface, FFmpeg 8.1, and multiple security fixes. Upgrading is irreversible without backup because first boot rewrites the database. Administrators must start from 10.10.7 or 10.11.x, remove third-party plugins, resolve case-colliding usernames, avoid interrupting migrations, and run a full library scan. Commenters mostly reported smooth upgrades, while subtitle reliability remained a recurring client-specific complaint.

### Comment pulse

- Large-library users generally reported quick migrations and improved browsing, though rescans temporarily hid or re-added some titles.
- Subtitle problems remained frustrating on some clients—counterpoint: external extraction, Bazarr, or alternative clients worked around particular formats.
- Commenters praised the project’s policy requiring contributors to understand and personally communicate any AI-assisted work.
