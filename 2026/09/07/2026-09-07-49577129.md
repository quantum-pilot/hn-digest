# Ask HN: Fable hacked my piano, can I release the results?

- Score: 286 | [HN](https://news.ycombinator.com/item?id=49577129) | Link: https://news.ycombinator.com/item?id=49577129

### TL;DR

An HN user says Fable decoded a PianoDisc playback format from an purchased MP3, identifying a 2004.5 Hz square-wave channel carrying MIDI-like control data. The model allegedly inferred pedal and note behavior, detected decoy notes intended to frustrate naive extraction, and generated both an encoder that adds them and a decoder that removes them. The author asks whether publishing either tool is lawful. The post supplies no code or independent validation, and commenters offered conflicting legal theories while overwhelmingly recommending actual counsel.

### Comment pulse

- Some argued decoy notes may trigger anti-circumvention law — counterpoint: others doubted simple obfuscation qualifies as an effective technical measure.
- Commenters distinguished owning the piano from having unrestricted legal rights to publish a reverse-engineered codec.
- A high-quality public performance-MIDI dataset was suggested as an alternative source for expressive recordings.

### LLM perspective

- View: Technical reproducibility and publication legality are separate questions that forum consensus cannot resolve.
- Impact: Releasing the tools could enable interoperability while exposing the author to jurisdiction-specific claims.
