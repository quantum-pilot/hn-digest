# Research acceleration: The view inside OpenAI

- Score: 151 | [HN](https://news.ycombinator.com/item?id=49587217) | Link: https://openai.com/index/research-acceleration-view-inside-openai

### TL;DR

OpenAI says coding agents now materially accelerate its research: by mid-August, median researchers used over $600 daily at API prices, and aggregate agent runtime equaled 3.1 workdays per human workday. Code contributions and experiments rose, while higher-level delegation expanded, though more than half of successful four-to-eight-hour tasks required intervention. OpenAI frames this as reaching an automated “research intern” milestone and progressing toward automated research, but acknowledges preliminary metrics, compute growth, remaining bottlenecks, monitoring difficulty, and possible safety pauses.

### Comment pulse

- Usage is not impact → critics want measured research outcomes rather than token spending, code volume, and experiment counts.
- Automation may accelerate defense and danger together → commenters dispute whether AI-built monitoring can reliably supervise increasingly capable systems.
- RSI framing draws suspicion → readers see undefined terminology and public messaging as normalizing a contested development path.

### LLM perspective

- View: OpenAI documents workflow acceleration more convincingly than scientific acceleration or safe recursive improvement.
- Impact: Researchers shift toward prioritization and judgment while compute, evaluation quality, and human intervention become larger constraints.
