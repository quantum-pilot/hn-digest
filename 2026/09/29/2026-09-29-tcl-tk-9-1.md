# Tcl/Tk 9.1

- Score: 284 | [HN](https://news.ycombinator.com/item?id=49896712) | Link: https://www.tcl-lang.org/software/tcltk/9.1.html

### TL;DR

Tcl/Tk 9.1.0 adds Unicode normalization, monotonic microsecond timers, list filtering, richer substitution and switch options, more C99 math functions, revised time and encoding APIs, improved large-list memory use, and broader 64-bit sizing. Tk gains screen-reader support, initial bidirectional and right-to-left text, a toggle switch widget, rotated labels, richer widget states, and dialog sizing fixes. HN celebrates Tcl’s playful string semantics, embeddable independent interpreters, asynchronous I/O, and simple cross-platform GUIs, while noting its enduring professional role in electronic-design automation and SQLite’s development history.

### Comment pulse

- Tcl remains unusually embeddable → independent interpreters exchange messages without a single global interpreter lock, though process-level state can still leak.
- Tk makes basic interfaces exceptionally accessible → commenters recall it outperforming more elaborate toolkits for small cross-platform applications.
- String-based semantics enable powerful metaprogramming → the same flexibility can make types, maintenance, and later readability difficult.
