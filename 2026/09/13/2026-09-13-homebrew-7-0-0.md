# Homebrew 7.0.0

- Score: 597 | [HN](https://news.ycombinator.com/item?id=49681545) | Link: https://brew.sh/2026/09/13/homebrew-7.0.0/

### TL;DR

Homebrew 7.0.0 emphasizes faster concurrent installs and upgrades, stronger sandboxing, a native macOS app, vulnerability checks, and structured installation steps that reduce arbitrary Ruby execution. It drops macOS 10.15, moves Sonoma and Intel Macs to Tier 3, and plans to stop routine Intel bottles before Homebrew itself stops running there in September 2027. Other changes span diagnostics, package metadata, casks, CI, and services. Early commenters praised noticeable speed gains while Intel users considered MacPorts or Linux.
