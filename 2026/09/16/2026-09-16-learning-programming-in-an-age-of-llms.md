# Learning Programming in an Age of LLMs

- Score: 243 | [HN](https://news.ycombinator.com/item?id=49723873) | Link: https://blog.ploeh.dk/2026/09/16/on-learning-programming-in-an-age-of-llms/

### TL;DR

A novice describes using LLMs to build a large system beyond their ability to debug or truly own. Mark Seemann describes systematically studying fundamentals and using models mainly for falsifiable, easily verified questions, but doubts human understanding can accelerate as quickly as code generation. He remains uncertain about programming careers and broader employment effects. Commenters agree that AI can outpace comprehension, while debating whether disciplined learning, strong architecture, tests, or increasingly capable models can make such projects maintainable.

### Comment pulse

- Understanding must be intentional → rapid generation makes learning optional unless builders deliberately slow down to inspect, debug, and connect concepts.
- Engineering still manages complexity → clear boundaries and constraints limit both human and model mistakes — counterpoint: thorough tests may tolerate messy internals.
- Fundamentals preserve agency → without mental models, novices cannot diagnose failures or judge generated output.

### LLM perspective

- View: AI compresses implementation time more than it compresses the formation of reliable technical judgment.
- Impact: Beginners can reach production-scale complexity before acquiring the debugging skills needed to maintain it.
- Watch next: Compare cohorts using unrestricted agents, guided explanations, and delayed assistance on retention and independent repair tasks.
