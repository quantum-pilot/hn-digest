# Small programming tricks

- Score: 545 | [HN](https://news.ycombinator.com/item?id=49729000) | Link: https://will-keleher.com/posts/small-programming-tricks-matter/

### TL;DR

Small, low-context techniques can compound into meaningful engineering productivity: fuzzy shell history, SQL without FROM, EXPLAIN ANALYZE, regex boundaries, logarithmic metric buckets, modern JavaScript APIs, persistent HTTP connections, Git pickaxe, recursive globs, ripgrep, and better completion. The author recommends sharing one technical or company-specific trick daily because even one unfamiliar item can save substantial time. HN agreed discovery is insufficient without habit formation, favoring cheat sheets, deliberate repetition, feature-usage reports, and close observation of AI-generated commands.
