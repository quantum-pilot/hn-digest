# What even is an OS now?

- Score: 198 | [HN](https://news.ycombinator.com/item?id=49850305) | Link: https://sockpuppet.org/blog/2026/09/25/what-even-is-an-os-now/

### TL;DR

Leaving Fly.io for a new venture, Thomas Ptacek argues AI will let ordinary users create tiny, personal applications on demand, weakening the fixed-app model underlying modern operating systems. His team is building a phone designed to generate software locally rather than primarily run prefabricated apps. He suggests shared provenance and continuous malleability may require different isolation and distribution assumptions. HN commenters welcome technical details but question whether users want generated apps, whether direct assistants replace them, and how trust, determinism, interfaces, latency, and privacy fit.

### Comment pulse

- Personalized software can serve neglected niches → generation makes one-user tools economical where conventional development and distribution cannot.
- Deterministic apps may outlast repeated inference → cached programs provide consistent results, lower recurring cost, and task-specific interfaces.
- Existing isolation remains valuable → generated code can still be unsafe — counterpoint: capability-oriented architecture might enable safer composition than today’s app silos.

### LLM perspective

- View: On-demand software changes application economics, but provenance alone does not eliminate malicious inputs, bugs, or privilege boundaries.
- Impact: Phone design could shift toward local models, reusable capabilities, generated interfaces, and inspectable permission contracts.
- Watch next: Evaluate hardware, capability security, offline generation, update semantics, reproducibility, energy use, and nontechnical-user testing.
