# GitHub Copilot is moving to usage-based billing

- Score: 515 | [HN](https://news.ycombinator.com/item?id=47923357) | Link: https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/

### TL;DR

GitHub will replace Copilot premium requests with token-metered AI Credits on June 1. Monthly prices stay $10 for Pro, $39 for Pro+, $19 per Business seat, and $39 per Enterprise seat, each bundling an equal dollar value of credits; model API rates cover input, output, and cached tokens. Completions and Next Edit remain included, but fallback models disappear after credits run out. Businesses gain pooled allowances and budgets, while annual individual plans temporarily retain request pricing with higher multipliers. HN users questioned paying subscriptions when direct pay-as-you-go APIs cost similarly.

### Comment pulse

- Critics want rollover because monthly credits expire while API balances can persist.
- Enterprises value pooled budgets, legal approval, and GitHub integration — counterpoint: individuals see little discount for committing.
- Heavy users described consuming hundreds of dollars in monthly inference under old request caps, explaining why GitHub calls them unsustainable.
