# Who owns the code Claude Code wrote?

- Score: 232 | [HN](https://news.ycombinator.com/item?id=47932937) | Link: https://legallayer.substack.com/p/who-owns-the-claude-code-wrote

### TL;DR

The article separates three ownership risks in AI-assisted code. Machine-generated output may lack copyright because U.S. doctrine requires meaningful human authorship, but how much architectural direction, rejection, or editing qualifies remains untested for code. Copyrightable work made within employment generally belongs to the employer, and broad tool clauses may threaten side projects. Verbatim reproduction of copyleft code can carry license obligations regardless of intent. Hacker News stressed that Supreme Court certiorari denial did not settle the rule nationally, debated whether training resembles human learning, and predicted jurisdiction- and power-dependent outcomes.

### Comment pulse

- Human review alone may not establish authorship; detailed design choices, rewrites, ADRs, prompts, and commit rationale provide stronger evidence.
- Training on protected code is not automatically infringement — counterpoint: substantial reproduced expression can remain derivative and expose distributors.
- Courts may protect employer-directed work through contracts even where generated portions remain uncopyrightable, producing fragmented ownership within one codebase.
