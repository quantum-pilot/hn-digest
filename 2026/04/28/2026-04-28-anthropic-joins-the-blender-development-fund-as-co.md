# Anthropic Joins the Blender Development Fund as Corporate Patron

- Score: 237 | [HN](https://news.ycombinator.com/item?id=47936370) | Link: https://www.blender.org/press/anthropic-joins-the-blender-development-fund-as-corporate-patron/

### TL;DR

Anthropic has joined Blender’s Development Fund as a Corporate Patron, with its contribution earmarked for core development, including the Python API used to extend Blender and build custom workflows. Blender says the funding supports independent work while its GPL-based software freedom permits outside extensions, even when those uses differ from the foundation’s mission. The announcement added a notice acknowledging substantial feedback. HN discussion split between welcoming money for a major open-source project and fearing that an AI vendor seeks influence over artist tools or tighter Claude integration.

### Comment pulse

- Supporters compared Anthropic with existing patrons including Google, Meta, Nvidia, Netflix, and Adidas, arguing sponsorship simply funds useful maintenance.
- Practitioners said the Python API is powerful but fragile, especially headlessly, making better automation and debugging valuable.
- Artists welcomed resources — counterpoint: critics fear corporate influence and AI-generated work could undermine the humans Blender serves.
