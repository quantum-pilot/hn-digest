# GTFOBins

- Score: 337 | [HN](https://news.ycombinator.com/item?id=47931035) | Link: https://gtfobins.org/

### TL;DR

GTFOBins catalogs legitimate Unix-like executables whose normal features can defeat poorly designed local restrictions. Entries are searchable by capability—shell execution, file access, transfer, library loading, privilege escalation—and by context such as unprivileged use, sudo, SUID, or Linux capabilities. The programs are not inherently vulnerable; danger arises when administrators expose powerful binaries with elevated rights or rely on narrow command allowlists. HN examples ranged from restricted-shell escapes and unsafe sudo rules to coding agents synthesizing equivalent commands, reinforcing that executable names are a weak security boundary.
