# Cursor 3

- Score: 258 | [HN](https://news.ycombinator.com/item?id=47618084) | Link: https://cursor.com/blog/cursor-3

### TL;DR

Cursor 3 introduces a new agent-centered workspace built from scratch, while retaining an option to return to the editor. It unifies local and cloud agents across repositories, supports parallel sessions launched from several services, hands work between desktop and cloud, shows cloud demos, and integrates diffs, staging, commits, pull requests, file browsing, LSP navigation, a browser, and plugins. HN split over the direction: some value concurrent automation, while others fear losing code context, developer control, and a reason to pay over CLI agents.

### Comment pulse

- Serial workers say one supervised agent preserves quality and mental context—counterpoint: parallel sessions reduce idle time and can divide one feature by role.
- Several subscribers pair free Cursor autocomplete with Claude Code, questioning paid differentiation as model vendors absorb useful features.
- Code-first users want full files, LSPs, and direct editing; chat-first PR summaries feel insufficient for maintaining a system model.
