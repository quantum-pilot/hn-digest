# Reallocating $100/Month Claude Code Spend to Zed and OpenRouter

- Score: 284 | [HN](https://news.ycombinator.com/item?id=47700972) | Link: https://braw.dev/blog/2026-04-06-reallocating-100-month-claude-spend/

### TL;DR

Frustrated by Claude’s $100 Max plan limits during bursty coding, the author proposes shifting spend to Zed ($10 monthly) plus prepaid OpenRouter credits that roll over for 365 days, with an optional retained $20 Cursor subscription. This separates editor or agent harness from model provider, enables model switching, and can route Claude Code through OpenRouter; zero-retention endpoints reduce exposure, while OpenRouter adds 5.5%. HN’s key objection was economics: heavy Opus users may receive hundreds or thousands of dollars in subsidized inference from Max, making usage-based APIs far costlier.

### Comment pulse

- OpenRouter fans valued one key, unified accounting, presets, and provider routing; self-hosted LiteLLM was offered for teams avoiding per-token brokerage fees.
- Zed felt snappy but accumulated missing-extension and UI papercuts, with reported TypeScript memory issues and debugger limitations driving some users back to VS Code.
- Pi attracted praise as a transparent, extensible harness; users stressed sandboxing because its agent can execute shell commands.
