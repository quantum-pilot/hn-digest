# Hear your agent suffer through your code

- Score: 175 | [HN](https://news.ycombinator.com/item?id=47888465) | Link: https://github.com/AndrewVos/endless-toil

### TL;DR

Endless Toil is a novelty plugin for Codex, Claude Code, and Cursor that scans code while an agent works and plays increasingly anguished human groans as apparent “cursedness” rises. It can be installed from the cloned repository through each client’s local plugin workflow, requires Python 3.10+, and uses standard local audio players; without one, it still prints scan results. The joke turns code-quality feedback into theatrical ambient monitoring, but activation is explicit per new thread rather than automatic.
