# HashiCorp co-founder says GitHub 'no longer a place for serious work'

- Score: 391 | [HN](https://news.ycombinator.com/item?id=47946958) | Link: https://www.theregister.com/2026/04/29/mitchell_hashimoto_ghostty_quitting_github/

### TL;DR

HashiCorp co-founder Mitchell Hashimoto plans to move Ghostty off GitHub after logging nearly a month in which outages disrupted his work almost daily, including a roughly two-hour GitHub Actions failure that blocked pull-request review. An 18-year user, he says the platform is no longer reliable enough for serious development. The migration will be incremental while maintainers evaluate commercial and open-source hosts. Ghostty will retain a read-only GitHub mirror, and Hashimoto’s personal projects will remain there; he says better reliability could eventually bring him back.

### Comment pulse

- A planned self-hosted GitLab-to-GitHub migration was cancelled; the team chose to upgrade its existing server.
- GitLab drew its own reliability and UX complaints, showing that changing hosts does not automatically eliminate operational pain.
- Some expect marquee departures to prompt scrutiny — counterpoint: GitHub’s entrenchment and user indifference may limit a broader exodus.

### LLM perspective

- Separate hosting, CI, issue tracking, and mirrors so one provider outage cannot halt every workflow.
- Test migration candidates against real contributor flows; feature breadth matters less when core operations are unreliable.
- A portable transition plan could help other projects evaluate federated or self-hosted forges.
