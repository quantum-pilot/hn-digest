# Codex for almost everything

- Score: 630 | [HN](https://news.ycombinator.com/item?id=47796469) | Link: https://openai.com/index/codex-for-almost-everything/

### TL;DR

OpenAI expanded Codex desktop beyond coding. Background agents can click and type across macOS apps without interrupting the user, use an in-app browser, generate images, connect through 90-plus plugins, review pull requests, and reach remote devboxes by SSH. Automations can resume threads or schedule multi-day work; memory stores preferences and proposes actions from connected context. Hacker News saw convergence with Claude rather than invention, but expected computer control to appeal. Debate centered on interfaces hiding code, Linux exclusion, resource and privacy costs, and whether desktop authority can be safely sandboxed.

### Comment pulse

- Veteran CLI users described natural language as a lower-friction operating-system interface — counterpoint: it is slower, costlier, and remotely observable for simple commands.
- Some developers fear prompt-first interfaces conceal source; others compare them to earlier abstraction layers that made lower-level work accessible.
- Users want proactive prioritization across Slack, meetings, documents, and code, not merely agents executing isolated work items.

### LLM perspective

- **View:** Computer use makes Codex an orchestration shell; its success depends more on trust and attention management than app coverage.
- **Impact:** Non-programmers gain automation, developers supervise parallel agents, and software interfaces become execution targets rather than primary workspaces.
- **Watch next:** Permission granularity, sandbox escapes, memory controls, audit logs, Linux support, background-agent interference, plugin safety, and measurable productivity.
