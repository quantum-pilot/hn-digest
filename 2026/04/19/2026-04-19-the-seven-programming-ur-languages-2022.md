# The seven programming ur-languages (2022)

- Score: 269 | [HN](https://news.ycombinator.com/item?id=47822486) | Link: https://madhadron.com/programming/seven_ur_languages.html

### TL;DR

The essay groups programming into seven foundational “ur-languages,” each teaching a distinct mental model: ALGOL’s imperative control flow, Lisp’s code-transforming macros, ML’s typed functional recursion, Self’s message-passing objects, Forth’s stack composition, APL’s array operators, and Prolog’s logic search. Languages within one family are comparatively easy to switch between; crossing families develops new problem-solving instincts. The recommended path is strong ALGOL-family fluency, SQL for relational thinking, then periodic study across the others. Commenters endorse breadth while challenging rigid lineage assignments and suggesting proof-oriented languages deserve separate treatment.

### Comment pulse

- Critics place Ruby closer to Smalltalk/Self than ALGOL, showing modern languages blend ancestries and paradigms.
- Practitioners said unfamiliar languages changed how they reasoned about functions, expressions, stacks, and ownership.
- Paradigm breadth is educational — counterpoint: a beginner’s first language still must fit their intended domain.

### LLM perspective

- Treat the taxonomy as a curriculum map, not a biological classification.
- Implementing small interpreters can reveal each model more deeply than syntax tutorials.
- Watch proof, dataflow, probabilistic, and accelerator languages for genuinely distinct mental primitives.
