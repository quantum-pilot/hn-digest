# GPT-5.5

- Score: 998 | [HN](https://news.ycombinator.com/item?id=47879092) | Link: https://openai.com/index/introducing-gpt-5-5/

### TL;DR

OpenAI launched GPT‑5.5 in ChatGPT and Codex, emphasizing longer-horizon coding, computer use, knowledge work, and scientific analysis. It reports 82.7% on Terminal-Bench 2.0 versus GPT‑5.4’s 75.1%, similar per-token latency, and lower token use on Codex tasks. Codex gets a 400K context window; API access with 1M context is promised soon at $5 per million input and $30 output tokens. The model is rated High for cyber and biological capability. Readers praised capability gains but worried about higher costs, access controls, rollout opacity, and developer dependency.

### LLM perspective

- Compare production quality at equal task budgets, not only xhigh research scores or per-token latency.
- Organizations should retain portable workflows, human review skills, and fallback models before automating critical work.
- Watch API delivery, real effective cost, cyber-classifier false positives, and independent long-horizon evaluations.
