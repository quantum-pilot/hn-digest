# Swift 6.3

- Score: 289 | [HN](https://news.ycombinator.com/item?id=47527590) | Link: https://www.swift.org/blog/swift-6.3-released/

### TL;DR

Swift 6.3 broadens the language beyond Apple-first application development. The new `@c` attribute exposes Swift functions and enums to C, module selectors disambiguate imports, and specialization/inlining controls give libraries performance tools. Swift Package Manager previews a unified Swift Build engine; Testing gains warnings, cancellation, and images, while DocC adds experimental Markdown and static output. Embedded support advances, and the first official Android SDK enables native programs plus Kotlin/Java integration. Together, the release emphasizes portability and lower-level interoperability.
