# People inside Microsoft are fighting to drop mandatory Microsoft Account

- Score: 480 | [HN](https://news.ycombinator.com/item?id=47542695) | Link: https://www.windowscentral.com/microsoft/windows-11/people-inside-microsoft-are-fighting-to-drop-windows-11s-mandatory-microsoft-account-requirements-during-setup

### TL;DR

Windows Central reports an internal Microsoft effort to relax or remove Windows 11’s requirement for internet access and a Microsoft account during initial setup. Vice President Scott Hanselman publicly said he hates the rule and is “working on it,” but no change is committed. The obstacle is organizational, not technical: multiple teams benefit from account acquisition, so senior agreement is required. HN framed this as a struggle over whether Windows serves users or cross-sells services, citing recurring prompts, resurrected settings, OneDrive defaults, and account-dependent failures as trust-eroding costs.

### Comment pulse

- Windows remains productive and institutionally entrenched — counterpoint: cross-platform apps, WSL, Proton, and web software increasingly lower switching costs.
- Users described updates reviving ads, search, OneDrive, and setup prompts after opt-out, turning configuration into perpetual whack-a-mole.
- Cloud-default storage caused inaccessible or apparently deleted files during account outages, strengthening calls for local accounts and backups.
