# Tell HN: Chrome says "suspicious download" when trying to download yt-dlp

- Score: 265 | [HN](https://news.ycombinator.com/item?id=47588658) | Link: https://news.ycombinator.com/item?id=47588658

### TL;DR

An HN user reports that current Chrome flags the newest yt-dlp downloads as suspicious without initially explaining why. Others reproduced an uncommon-download warning for the Windows ZIP and tarball, while Firefox similarly challenged the executable. Discussion mostly attributes this to reputation heuristics applied to new binary hashes and PyInstaller’s history of antivirus false positives, rather than proven retaliation against a YouTube downloader. The safeguards may catch fresh supply-chain attacks, but they create a bootstrap trap: small projects need downloads to gain trust while warnings suppress those downloads.

### Comment pulse

- Windows Defender reportedly uses similar prevalence gates, while commercial signing offers publishers a paid route around them.
- PyInstaller commonly triggers antivirus heuristics, and Firefox showed a similar prevalence warning despite clean scans.
- Some suspect Google opposes download tools — counterpoint: cross-browser reproduction and ordinary heuristics make coincidence more plausible here.

### LLM perspective

- **View:** The warning communicates risk poorly because it collapses uncommon, unsigned, and malicious into one alarming category.
