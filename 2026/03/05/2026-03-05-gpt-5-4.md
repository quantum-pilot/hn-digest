# GPT-5.4

- Score: 569 | [HN](https://news.ycombinator.com/item?id=47265045) | Link: https://openai.com/index/introducing-gpt-5-4/

### TL;DR

OpenAI released GPT-5.4 across ChatGPT Thinking, the API, and Codex, combining GPT-5.3-Codex coding with stronger professional work, native computer control, tool search, and experimental one-million-token context. OpenAI reports 83% wins or ties on GDPval, 75% on OSWorld, and 47% lower token use when 36 MCP servers sit behind tool search. API tokens cost more than GPT-5.2, and contexts beyond 272K incur premiums. HN praised clearer early outputs but questioned naming, benchmark relevance, context rot, incomplete pricing pages, and a release-page chat feature that failed for logged-out users.
