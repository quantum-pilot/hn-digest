# QGIS 4.0

- Score: 192 | [HN](https://news.ycombinator.com/item?id=47285846) | Link: https://changelog.qgis.org/en/version/4.0/

### TL;DR

The open-source mapping suite’s major release completes a long-planned migration to Qt 6 while keeping the desktop experience familiar and retaining deprecated APIs where practical for plugin compatibility. More than 100 additions span customizable menus and themes, improved labeling and layouts, 3D scene layers and dynamic rendering, remote virtual-point-cloud loading, local editing, new lidar-processing algorithms, Bézier digitizing, chart-rich print layouts, and enhanced cloud-optimized raster export. Practitioners celebrated a daily driver that handles standard formats well, while flagging longstanding quirks and weak reproducibility between GUI workflows and Python.
