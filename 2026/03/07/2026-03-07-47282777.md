# Tell HN: I'm 60 years old. Claude Code has re-ignited a passion

- Score: 973 | [HN](https://news.ycombinator.com/item?id=47282777) | Link: https://news.ycombinator.com/item?id=47282777

### TL;DR

A 60-year-old developer nearing retirement says Claude Code restored the sleepless excitement once sparked by ASP, COM, and VB6. Many veteran programmers agreed: agents bypass framework churn and typing drudgery, unlock old project backlogs, and refocus work on architecture, product decisions, and user experience. Others reported the opposite—lost craft satisfaction, devalued expertise, depression, and fear that mandatory agent supervision will replace quiet programming. The discussion’s clearest consensus was personal fit: AI can be a builder, planning partner, or avoided tool, but experienced review still separates maintainable systems from rapid mistakes.
