# Create value for others and don’t worry about the returns

- Score: 646 | [HN](https://news.ycombinator.com/item?id=47332074) | Link: https://geohot.github.io//blog/jekyll/update/2026/03/11/running-69-agents.html

### TL;DR

The author rejects social-media claims that everyone must orchestrate dozens of agents or become worthless. AI is framed as continued search and optimization—useful, improving, but neither magic nor suddenly recursive. The practical advice is to leave zero-sum rent-seeking and create more value than you consume, without obsessing over comparisons or immediate returns. HN appreciated the positive-sum reminder but called it privileged and organizationally naive: valuable employees still get laid off, translators already lost work, managers mismeasure contribution, and companies readily capture value workers create.
