# OpenClaw is a security nightmare dressed up as a daydream

- Score: 276 | [HN](https://news.ycombinator.com/item?id=47479962) | Link: https://composio.dev/content/openclaw-security-and-vulnerabilities

### TL;DR

OpenClaw’s appeal is also its core danger: an agent with access to files, messages, browsers, credentials, and automation can turn one malicious instruction into broad compromise. The article documents poisoned community skills, exposed instances, persistent memory manipulation, and prompt injection arriving through ordinary content. It recommends hard isolation, minimal permissions, separate accounts, approval gates, private networking, and detailed auditing. Its practical conclusion is not that personal agents are impossible, but that convenience must never be mistaken for a security boundary.
