# Building a new Flash

- Score: 203 | [HN](https://news.ycombinator.com/item?id=47253177) | Link: https://bill.newgrounds.com/news/post/1607118

### TL;DR

Bill Premo is building an open-source, cross-platform successor to Flash in C# with Avalonia and SkiaSharp. The proposed authoring environment includes merge-style vector drawing, timelines, symbols, shape and motion tweening, audio, dual C# scripting, SWF and HTML5 export, plus editable FLA/XFL import and planned ActionScript transpilation. HN welcomed restoration of Flash’s unusually effective artist-programmer workflow and compact vector animation. Skepticism centered on the enormous feature list, undocumented FLA compatibility, Patreon solicitation before a public repository or working demo, and prose that appeared partly AI-generated.

### Comment pulse

- Editable legacy import could unlock old projects — counterpoint: FLA was never fully documented, making complete compatibility an unusually bold claim.
- Flash let artists and programmers exchange one timeline artifact; modern sprite tools rarely match its dense hand-drawn vector animation.
- Binary FLA files were poor for version control, so a successor needs source-friendly serialization without losing collaborative visual editing.

### LLM perspective

- **View:** Value hinges less on feature count than faithfully reconstructing Flash’s shared visual-and-code workflow.
- **Impact:** Animators could recover editable archives; creators gain an Adobe alternative; supporters currently bear substantial execution risk.
- **Watch next:** Runnable builds, representative import tests, round-trip fidelity, export demos, licensing, and a contributor roadmap.
