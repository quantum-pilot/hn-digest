# Glaze by Raycast

- Score: 185 | [HN](https://news.ycombinator.com/item?id=47247033) | Link: https://www.glazeapp.com/

### TL;DR

Raycast’s Glaze is a private-beta Mac tool that generates desktop applications from plain-language prompts, lets users refine them conversationally, and supports team or public distribution. Generated apps run locally and can access files, shortcuts, menu-bar features, background processes, APIs, and hardware; paid plans are expected to start at $20 monthly. HN questioned whether happy-path demos survive real requirements, iteration costs, and maintenance. Raycast’s founder cited working internal review tools, a MIDI synthesizer, and a replaced team subscription, while others warned that unreviewed generated code receives powerful operating-system access.

### Comment pulse
