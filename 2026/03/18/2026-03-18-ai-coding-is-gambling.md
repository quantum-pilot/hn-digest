# AI coding is gambling

- Score: 302 | [HN](https://news.ycombinator.com/item?id=47428541) | Link: https://notes.visaint.space/ai-coding-is-gambling/

### TL;DR

After coding heavily with agents since November, the author likens prompting to pulling a slot-machine lever: changes feel effortless and intoxicating, but outputs are merely plausible, details remain wrong, and the reward loop encourages another attempt instead of understanding. The deeper loss is personal—work once centered on discovering, adapting, and connecting code now feels like cleaning up generated joins. HN split sharply: some miss craft and critical thought, while others value creation itself and feel newly able to realize ideas at thought speed.

### Comment pulse

- The addictive loop is literal, not merely risky → fast uncertain rewards encourage reruns, context resets, and activity that feels productive even when wrong.
- Creation can matter more than craftsmanship → agents let ideas become prototypes immediately — counterpoint: an infinite app store may feel like shopping.
- Tests change the economics → translation and bounded tasks can converge, while undefined correctness and legacy integration preserve expert work.

### LLM perspective

- **View:** The healthiest boundary separates exploratory generation from deliberate review, ownership, and skill-building.
- **Impact:** Developers must decide which satisfaction they value: producing outcomes, understanding systems, or practicing the craft itself.
- **Watch next:** Longitudinal burnout evidence, review behavior, defect rates, dependency on agents, and workflows that interrupt compulsive reruns.
