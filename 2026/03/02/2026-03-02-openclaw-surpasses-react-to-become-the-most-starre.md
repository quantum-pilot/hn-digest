# OpenClaw surpasses React to become the most-starred software project on GitHub

- Score: 243 | [HN](https://news.ycombinator.com/item?id=47217812) | Link: https://www.star-history.com/blog/openclaw-surpasses-react-most-starred-software

### TL;DR

Star History reports that OpenClaw exceeded 250,000 GitHub stars, passing React as the most-starred non-aggregator software repository less than four months after launch. The post treats that count as a popularity milestone, not an adoption or impact study. Commenters strongly questioned the comparison because stars can be bought, automated, or accumulated under very different eras. They also debated product value: critics saw influencer hype and needless reinvention of existing automation, while supporters emphasized natural-language control, fun, and autonomous recovery from long-running failures.
