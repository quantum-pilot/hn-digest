# Microsoft bans the word "Microslop" on its Discord, then locks the server

- Score: 1001 | [HN](https://news.ycombinator.com/item?id=47216047) | Link: https://www.windowslatest.com/2026/03/02/microsoft-gets-tired-of-microslop-bans-the-word-on-its-discord-then-locks-the-server-after-backlash/

### TL;DR

Windows Latest found Microsoft’s official Copilot Discord automatically blocking the nickname Microslop. Users evaded the keyword rule with spelling variants, some accounts lost posting access, and sections of the server were then locked with history hidden. Microsoft later said coordinated spam, including walls of unrelated or harmful content, prompted temporary filters and a temporary lockdown while stronger safeguards were built; it denied a permanent word policy. Commenters nevertheless saw a Streisand effect and a symptom of eroding consumer trust, while acknowledging that product communities can help users share workflows.
