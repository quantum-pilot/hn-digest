# Welcome (back) to Macintosh

- Score: 187 | [HN](https://news.ycombinator.com/item?id=47224118) | Link: https://take.surf/2026/03/01/welcome-back-to-macintosh

### TL;DR

A longtime Mac user catalogs persistent failures in Time Machine, Spotlight tags and searches, Finder refreshes, AirPods audio, and full-screen focus, arguing Apple prioritizes Tahoe’s visual redesign over foundational reliability. Excellent M1 hardware keeps the author invested, but software quality, UI convergence, and the planned Rosetta 2 phaseout block upgrades and raise doubts about Apple’s organizational priorities. Commenters reported silent backup failures and migrations toward Linux or GrapheneOS; others found Tahoe broadly fine, noted that alternative desktops also break workflows, and suggested waiting beyond early releases.

### Comment pulse

- Silent Time Machine stoppages destroy backup confidence because connected disks and free space provide no assurance that recent data exists.
- Some daily users found Tahoe stable — counterpoint: others measured sluggish interfaces, recurring restarts, and broken development workflows on modern hardware.
- Linux and Windows offer more control in places, but Wayland transitions, bugs, and ecosystem gaps make every exit costly.
