# FFmpeg 101 (2024)

- Score: 207 | [HN](https://news.ycombinator.com/item?id=47463547) | Link: https://blogs.igalia.com/llepage/ffmpeg-101/

### TL;DR

A practical introduction maps FFmpeg’s command-line tools and libraries, then builds a minimal C decoder. The walkthrough opens a media file with libavformat, enumerates streams, finds the matching libavcodec decoder, copies codec parameters into a context, and loops over encoded AVPackets. Each selected video packet is sent into the decoder, whose output is drained into raw AVFrames until it returns EAGAIN or EOF; resources are then unreferenced or freed. HN found it useful but pointed beginners toward broader tutorials for deeper coverage.
