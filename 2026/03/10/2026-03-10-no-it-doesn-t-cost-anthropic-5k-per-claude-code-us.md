# No, it doesn't cost Anthropic $5k per Claude Code user

- Score: 438 | [HN](https://news.ycombinator.com/item?id=47317132) | Link: https://martinalderson.com/posts/no-it-doesnt-cost-anthropic-5k-per-claude-code-user/

### TL;DR

The viral claim that Anthropic spends $5,000 monthly on each heavy Claude Code user likely confuses retail API-equivalent usage with internal compute cost. Comparing competitive hosting prices for large open models, the author estimates an extreme Max subscriber might cost nearer $500 in inference, while average users could be profitable after caching. Cursor, which buys Anthropic access, may face something closer to retail. HN commenters challenge the proxy because Opus architecture, precision, active parameters, and contracts are undisclosed, and emphasize that serving, training, research, and depreciation are different accounting questions.

### Comment pulse

- Competitive hosting prices are evidence, not a cost ledger → architectures, quantization, subsidies, and distilled models may differ materially from Opus.
- Marginal inference can be profitable amid company losses → frontier training and researcher costs must be recovered across short model lifetimes.
