# Vite 8.0 Is Out

- Score: 515 | [HN](https://news.ycombinator.com/item?id=47360730) | Link: https://vite.dev/blog/announcing-vite8

### TL;DR

Vite 8 replaces its split esbuild development and Rollup production pipelines with Rolldown, a Rust bundler designed for Vite while retaining broad Rollup/Vite plugin compatibility. The project reports 10–30× bundling gains over Rollup; adopters cited reductions such as Linear’s 46-to-6-second build and Hacker News commenters described roughly 4-to-0.5-minute builds. The release also raises Node requirements to 20.19+ or 22.12+, adds about 15MB to installation, moves React’s default transform from Babel to Oxc, and introduces developer tools, optional tsconfig paths, Wasm SSR, and console forwarding.

### Comment pulse

- Faster feedback is the headline benefit → teams report less context switching and lower CI compute, not merely prettier benchmark numbers.
- One bundler reduces semantic drift → development and production should behave more consistently with less glue code.
- Some reject bundling altogether → counterpoint: package incompatibilities, TypeScript, JSX, optimization, and legacy-browser targets keep build systems relevant.

### LLM perspective

- **View:** Pipeline unification may prove more valuable than peak speed because compatibility failures consume disproportionate engineering time.
- **Impact:** Most Vite users get speed transparently; Babel-dependent React setups and native-install policies need migration review.
- **Watch next:** Plugin edge cases, cold-start results, full-bundle mode, memory use, and real-world source-map accuracy.
