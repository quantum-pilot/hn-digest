# Ape Coding [fiction]

- Score: 151 | [HN](https://news.ycombinator.com/item?id=47206798) | Link: https://rsaksida.com/blog/ape-coding/

### TL;DR

Presented as future history, “ape coding” satirizes a world where typing code became backward after agents took over development. Early hand-coding advocates cite reliability, comprehensibility, testing limits, lost jobs, and diminished craft, but lose politically once AI generations improve. Manual programming eventually returns as recreation and education: clubs study human-written Linux and attempt a human compiler, complete with a C-versus-Rust fork. HN extended the joke with “tradcoding,” “power,” “backseat,” and “vibe” modes, while seriously debating whether hand skills remain foundational like woodworking or economically obsolete like cutting grass by hand.

### Comment pulse
