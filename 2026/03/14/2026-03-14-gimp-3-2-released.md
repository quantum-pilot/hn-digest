# GIMP 3.2 released

- Score: 198 | [HN](https://news.ycombinator.com/item?id=47380465) | Link: https://www.gimp.org/news/2026/03/14/gimp-3-2-released/

### TL;DR

Version 3.2 adds link layers for externally sourced images and vector layers from paths, enabling non-destructive scaling, rotation, and shape editing. It also brings 20 MyPaint brushes, an Overwrite paint mode, movable text editing, better PSD styles, DDS BC7 and SVG export, expanded PDF vectors, UI refinements, ink-coverage feedback, and a GEGL filter browser. Commenters welcome preserved source quality but find the current non-destructive interface awkward; maintainers say broader layer support missed testing and GTK4 limits the present UI. Updated documentation is still being prepared.

### Comment pulse

- Link and vector layers retain transform data instead of repeatedly rasterizing, preserving quality through reversible edits.
- Some users prefer a node editor — counterpoint: Merge Filter restores the familiar destructive workflow and remembers that setting.
- Save-versus-export confusion persists, although Overwrite can already be assigned to a shortcut.
