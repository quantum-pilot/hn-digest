# Megadev: A Development Kit for the Sega Mega Drive and Mega CD Hardware

- Score: 116 | [HN](https://news.ycombinator.com/item?id=47374745) | Link: https://github.com/drojaazu/megadev

### TL;DR

MEGADEV v1.0 is an MIT-licensed, unofficial toolkit for building software on Sega Mega Drive and Mega CD hardware using C and Motorola 68k assembly. It bundles utilities, headers, documentation, examples, project scaffolding, and build configuration to spare experienced embedded developers from starting at zero. Its Mega CD focus adds complexity, so it intentionally favors flexibility over the friendlier SGDK experience. HN welcomed the release as evidence that old hardware remains creatively alive, sharing home-built dev-kit history, Sega nostalgia, and interest in higher-level authoring tools.
