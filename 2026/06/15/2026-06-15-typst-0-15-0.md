# Typst 0.15.0

- Score: 263 | [HN](https://news.ycombinator.com/item?id=48544396) | Link: https://typst.app/docs/changelog/0.15.0/

### TL;DR

Typst 0.15 expands the typesetter beyond paged PDFs: HTML equations now emit semantic MathML, and an experimental bundle target can produce multiple HTML, PDF, PNG, SVG, and asset files from one project. The release also adds variable fonts, multiple bibliographies, simultaneous PDF standards, spot colors, project-relative path values, richer diagnostics, and layout fixes, alongside several migration-breaking changes. HN users praised book-production workflows and better HTML-to-EPUB prospects, but flagged unreliable discursive footnotes and mixed LLM support for niche or recently changed syntax.

### Comment pulse

- LLM results vary with context → current documentation or specialized skills reduce LaTeX leakage and stale-syntax errors — counterpoint: some users report excellent results unaided.

### LLM perspective

- **Impact:** Publishers gain fewer format-specific workarounds; accessibility improves through MathML, but humanities adoption still depends on robust footnote pagination.
