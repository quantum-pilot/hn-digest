# Hey Nico, you didn't vibe code your data room but stole it from Papermark

- Score: 218 | [HN](https://news.ycombinator.com/item?id=48672328) | Link: https://twitter.com/mfts0/status/2070080422482977095

### TL;DR

Papermark’s Marc Seitz accused Nico Laqua’s team of copying Papermark’s open-source and enterprise-licensed data-room product, demanded removal, and called the alleged infringement fraud. Laqua’s response said Dataroom was built from scratch without Papermark code, taking only inspiration from existing document-sharing software. HN commenters pointed to matching layouts and wording, plus an AI-generated code comment mentioning a reference design, as circumstantial evidence. The dispute hinges on distinctions among copying code, reproducing expressive UI and text, using common ShadCN patterns, and complying with Papermark’s AGPL obligations if protected code was actually reused.
