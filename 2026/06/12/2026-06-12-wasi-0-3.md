# WASI 0.3

- Score: 257 | [HN](https://news.ycombinator.com/item?id=48504063) | Link: https://bytecodealliance.org/articles/WASI-0.3

### TL;DR

WASI 0.3 is a ratified stable release that moves asynchronous I/O into the WebAssembly Component Model’s canonical ABI. Instead of every component running an uncoordinated event loop, the host schedules a shared one through streams, futures, and async functions, enabling streaming and idiomatic language bindings. HTTP gains service and middleware worlds plus in-process component chaining; Wasmtime 46, jco, and guest toolchains are adopting support. HN debate focused on whether the component model enables safe cross-language plugin ecosystems or overcomplicates WASI, with frustration about sparse narration, stale documentation, and missing hot-loading.
