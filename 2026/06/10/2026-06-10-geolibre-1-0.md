# GeoLibre 1.0

- Score: 301 | [HN](https://news.ycombinator.com/item?id=48479852) | Link: https://geolibre.app/

### TL;DR

GeoLibre is a lightweight, cloud-native GIS workspace built with Tauri, React, MapLibre, DuckDB-WASM Spatial, and deck.gl, sharing one interface across desktop, web, Android, and responsive mobile layouts. It handles broad vector, raster, database, 3D, SQL, processing, plugin, Python/Jupyter, collaboration, story-map, and provider-pluggable AI workflows. Its static browser demo processes selected data client-side without accounts or analytics; heavier local features use the desktop app or Python sidecars. HN praised its convenience and subscription-free potential, but one tester reported import failures, blank screens, and lost layers with files above 1GB.
