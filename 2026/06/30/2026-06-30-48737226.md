# Tell HN: Installing Cursor on iOS irreversibly changes your privacy settings

- Score: 199 | [HN](https://news.ycombinator.com/item?id=48737226) | Link: https://news.ycombinator.com/item?id=48737226

### TL;DR

A Cursor user says setting up the iOS app silently replaced their legacy do-not-store-code setting with the newer Privacy Mode, which permits storage for cloud agents and related features, then removed the legacy option from account menus. Initial support said reversal was unavailable. A Cursor employee acknowledged the disclosure failure, explained that mobile currently requires cloud-agent state storage, said an update would make consent clearer, and offered support-assisted restoration of legacy mode. HN criticized the default change, LLM-mediated support, and an app architecture that cannot simply control local sessions.
