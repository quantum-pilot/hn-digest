# The 29th International Obfuscated C Code Contest (IOCCC) 2025 Winners

- Score: 357 | [HN](https://news.ycombinator.com/item?id=48432199) | Link: https://www.ioccc.org/2025/

### TL;DR

IOCCC29 names 22 winners after attracting submission volume and quality near historic highs, matching the previous post-hiatus contest without another four-year development window. Highlights include a SUBLEQ computer, Game Boy emulator, patch/diff quine, ocean-sound generator, and quine Pong; three authors each won three categories. Winning entries also carry judges’ follow-up challenges, while IOCCC30 is planned for late 2026 through Q1 2027. HN marveled at extreme compression—especially a 366-byte VM and a Game Boy emulator under the 2,503-character limit—while debating whether contest language permits LLM assistance and criticizing site navigation.

### Comment pulse

- Minimal machines delivered maximal spectacle → a 366-byte one-instruction VM reportedly runs Linux and Doom.
