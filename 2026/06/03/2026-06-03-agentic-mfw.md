# Agentic Mfw

- Score: 204 | [HN](https://news.ycombinator.com/item?id=48379203) | Link: https://agenticmotherfucking.website

### TL;DR

This profanity-heavy parody of minimalist web-design manifestos attacks vibe coding and agentic startup culture. It imagines maintainable code replaced by regeneration, simple sites displaced by token-burning swarms, security reduced to model reassurance, licensing dissolved into test-driven copying, and open source buried under automated pull requests. The punchline is that an agent produced the clean, fast, accessible static page simply because it was prompted to imitate 2014: craft persists, but as a style toggle. HN found the satire sharp and cathartic, though some were exhausted by synthetic hyperbole and adolescent tone.
