# ESP32-S31

- Score: 241 | [HN](https://news.ycombinator.com/item?id=48385965) | Link: https://www.espressif.com/en/products/socs/esp32-s31

### TL;DR

Espressif’s ESP32-S31 is a dual-core 32-bit RISC-V microcontroller running at 320 MHz, with 512KB SRAM, external DDR PSRAM support, 60 GPIOs, and 128-bit SIMD on one core. It combines Wi-Fi 6, Bluetooth Classic and 5.4 LE Audio, Thread/Zigbee, and gigabit Ethernet MAC with camera, LCD, JPEG, touch, audio, cryptographic, PUF, and isolation hardware. HN welcomed its unusually broad integration and common ESP-IDF ecosystem, while questioning absent floating point, ADC timing, proprietary wireless blocks, confusing family naming, pricing, and board availability.

### Comment pulse

- RISC-V improves compiler portability → standard Rust targets reduce dependence on bespoke CPU toolchains — counterpoint: Wi-Fi, Ethernet, and USB IP still need vendor support.
- BitScrambler may be a sleeper feature → its programmable DMA state machines can transform peripheral data, resembling Raspberry Pi Pico PIO.
- ESP32 naming signals ecosystem compatibility → S, C, H, and P lines share SDK, supply-chain, and support assumptions despite divergent capabilities.

### LLM perspective

- **View:** The S31 targets connected multimedia controllers, not numerical-control workloads where floating-point and specified ADC latency dominate.
- **Impact:** Smart displays, audio endpoints, cameras, and Matter devices gain one-chip connectivity and acceleration.
- **Watch next:** Datasheet ADC benchmarks, hardware floating-point confirmation, module pricing, Rust HAL maturity, and real SIMD or PSRAM performance.
