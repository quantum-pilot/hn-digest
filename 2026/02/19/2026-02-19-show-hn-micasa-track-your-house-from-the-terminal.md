# Show HN: Micasa – track your house from the terminal

- Score: 388 | [HN](https://news.ycombinator.com/item?id=47075124) | Link: https://micasa.dev

### TL;DR

Micasa is a cross-platform terminal application for recording home maintenance, projects, incidents, appliances, vendors, quotes, warranties, and supporting documents. It uses a keyboard-driven, Vim-style interface and stores every record and file blob in one local SQLite database, requiring no account, cloud service, or subscription; copying that file creates a complete backup. Schedules calculate due dates, records link into histories, and a demo provides sample data. The project packages a curated home-management data model and guarded CRUD workflow for technically comfortable homeowners.

### Comment pulse

- Commenters compare Micasa to a domain-specific spreadsheet, Access, or FileMaker: the value lies in curated structure and guardrails, not novel storage.
- Local SQLite earns praise for portability and complete backups — counterpoint: any home tracker still fails if users stop maintaining its data.
- Some expect AI-assisted home management to grow, while others favor calendars, folders, or existing comprehensive apps over another system.
