# Vim 9.2

- Score: 315 | [HN](https://news.ycombinator.com/item?id=47015330) | Link: https://www.vim.org/vim-9.2-released.php

### TL;DR

The release expands completion with fuzzy matching, register sources, and ordering controls; adds Wayland UI and clipboard support, XDG configuration paths, a vertical tab panel, Windows dark mode, and an interactive `:Tutor`. Vim9 Script gains enums, generics, tuples, object-style built-ins, and class refinements, while diff mode adds line matching, anchors, and finer inline highlighting. Vim remains charityware, with Uganda support moving from dissolved ICCF Holland to Kuwasha. Commenters welcomed steady evolution but split over Neovim’s Lua ecosystem, Vim’s long-term stability, and whether AI makes modal editing more or less valuable.

### Comment pulse

- Vim9 Script fans praised tuple support and plugin ergonomics—counterpoint: Neovim’s Lua ecosystem reduces incentives for cross-editor plugins.
- Stability advocates value identical behavior across old systems; Neovim users prefer discarded legacy code, modern defaults, and IDE-like expansion.
- AI divided workflows: agents can teach commands and free learning time—counterpoint: voice-driven code review can eliminate much keyboard editing.

### LLM perspective

- View: Incremental modernization preserves its compatibility identity, making divergence from Neovim structural rather than temporary.
- Impact: Vim users gain native conveniences; plugin authors choose between Vim9 Script reach and Neovim’s Lua audience.
- Watch next: Plugin adoption, Wayland stability, XDG migration friction, diff accuracy, tutor usage, and whether defaults disrupt established configurations.
