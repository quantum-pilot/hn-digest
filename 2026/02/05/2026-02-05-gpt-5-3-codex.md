# GPT-5.3-Codex

- Score: 1510 | [HN](https://news.ycombinator.com/item?id=46902638) | Link: https://openai.com/index/introducing-gpt-5-3-codex/

### TL;DR

OpenAI launched GPT-5.3-Codex, claiming stronger coding, terminal use, computer interaction, professional work, and long-running execution with fewer tokens and 25% faster serving. It supports mid-task steering and progress updates, and OpenAI says early versions helped debug its own training and deployment. At xhigh reasoning, company evaluations show especially large gains on Terminal-Bench and OSWorld. The model is available through paid Codex surfaces, with API access planned. Commenters debated benchmark cost, human supervision versus autonomy, self-improvement implications, and whether secure code generation deserves more emphasis than offensive capability.
