# Claude Opus 4.6

- Score: 2312 | [HN](https://news.ycombinator.com/item?id=46902223) | Link: https://www.anthropic.com/news/claude-opus-4-6

### TL;DR

Anthropic launched Claude Opus 4.6, claiming stronger coding, debugging, review, long-running agents, knowledge work, search, reasoning, and safety. It adds beta one-million-token context, 128k output, adaptive thinking, four effort levels, automatic context compaction, Claude Code agent teams, stronger Excel support, and preview PowerPoint. Base API pricing remains $5 input and $25 output per million tokens, with premiums above 200k context. Commenters immediately compared GPT-5.3 Codex, questioned benchmark stability and contaminated long-context demos, and split over Claude’s broader appeal beyond coding, especially multilingual and everyday use.
