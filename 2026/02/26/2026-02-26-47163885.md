# Tell HN: YC companies scrape GitHub activity, send spam emails to users

- Score: 582 | [HN](https://news.ycombinator.com/item?id=47163885) | Link: https://news.ycombinator.com/item?id=47163885

### TL;DR

A developer says Run Anywhere, a YC company, and Voice.AI sent unsolicited marketing after apparently matching public GitHub activity to email addresses, potentially using commit metadata. They filed complaints with both companies, GitHub, and YC Ethics, citing GDPR concerns. A GitHub representative confirmed that harvesting platform data for spam violates its terms and recommended no-reply commit addresses, but several commenters said prior reports produced no enforcement. Discussion distinguished generic automated pitches from genuinely researched, relevant recruiting outreach, which some developers would welcome.
