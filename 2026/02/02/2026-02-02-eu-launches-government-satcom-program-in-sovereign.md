# EU launches government satcom program in sovereignty push

- Score: 151 | [HN](https://news.ycombinator.com/item?id=46853888) | Link: https://spacenews.com/eu-launches-government-satcom-program-in-sovereignty-push/

### TL;DR

The EU has begun GOVSATCOM operations, giving member states a secure hub for requesting capacity pooled from eight existing geostationary satellites supplied by France, Spain, Italy, Greece, and Luxembourg. The nonpublic catalog currently offers 35 services, with broader coverage and commercial capacity planned for 2027, followed by integration with the 290-satellite IRIS² constellation from 2029. Commenters frame this as useful infrastructure and an IRIS² rehearsal, while debating whether Europe is investing enough—or can afford strategic autonomy.

### Comment pulse

- Sovereignty spending divides commenters → some cite aging-state budgets; others argue local procurement retains economic value and reduces foreign dependence.
- Strategic urgency is broadly accepted → critics call the program late or too small — counterpoint: pooled access is still concrete progress.
