# Claude Code is suddenly everywhere inside Microsoft

- Score: 335 | [HN](https://news.ycombinator.com/item?id=46854999) | Link: https://www.theverge.com/tech/865689/microsoft-claude-code-anthropic-partnership-notepad

### TL;DR

The Verge reports that Microsoft is encouraging thousands of employees across CoreAI and Experiences + Devices—including designers and project managers—to test Claude Code, with some engineers expected to compare it against GitHub Copilot. Microsoft has approved Claude Code across Business and Industry Copilot repositories while still calling OpenAI its primary frontier-model partner. Commenters read the pilot as both a strong Anthropic endorsement and an indictment of Microsoft’s fragmented Copilot products, though experiences across Copilot, Claude, and Gemini remain sharply mixed.
