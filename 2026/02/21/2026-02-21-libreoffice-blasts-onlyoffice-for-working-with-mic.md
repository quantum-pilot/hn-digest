# LibreOffice blasts OnlyOffice for working with Microsoft to lock users in

- Score: 127 | [HN](https://news.ycombinator.com/item?id=47098828) | Link: https://www.neowin.net/news/libreoffice-blasts-fake-open-source-onlyoffice-for-working-with-microsoft-to-lock-users-in/

### TL;DR

A LibreOffice/Document Foundation post accuses OnlyOffice of helping Microsoft preserve lock-in around DOCX, XLSX, and PPTX, arguing that OOXML’s ISO status masks dependence on Microsoft behavior. It promotes ODF as a genuinely open reference format that no single company or country controls and compares the standards battle with HTML. Commenters agreed that document features create costly migration traps, but split on software quality and governance: some prefer LibreOffice’s reliability, others favor OnlyOffice’s lighter interface, and several questioned whether slow standards processes constrain innovation.

### Comment pulse

- A Google Sheets migration showed that proprietary features and forms can lock users in even when file export technically succeeds.
- LibreOffice drew criticism for an aging interface — counterpoint: users praised its speed, stable controls, CSV handling, and spreadsheet reliability.
- Some commenters defended OnlyOffice as genuinely open source, while concerns about its provenance and upstream trust prompted calls for stronger desktop sandboxing.
