# I am happier writing code by hand

- Score: 346 | [HN](https://news.ycombinator.com/item?id=46934344) | Link: https://www.abhinavomprakash.com/posts/i-am-happier-writing-code-by-hand/

### TL;DR

After three Claude Code trials left him lethargic and doomscrolling, Abhinav Omprakash says deleting the agent restored his enjoyment. Manual coding is slower but forces him to test ideas, internalize the domain, and judge correctness; large generated diffs make passive review the bottleneck. He still uses Claude through copy-paste, limiting context and change size while staying engaged. Commenters split over whether hand coding remains commercially viable, but many favored it for long-term understanding and AI for tedious transformations. Others warned generated output can feel productive without yielding control or learning.
