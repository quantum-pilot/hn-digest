# Bun v1.3.9

- Score: 134 | [HN](https://news.ycombinator.com/item?id=46936595) | Link: https://bun.com/blog/bun-v1.3.9

### TL;DR

Bun 1.3.9 adds `bun run --parallel` and `--sequential` for multiple scripts, with labeled output, workspace filters, grouped pre/post hooks, and failure controls; unlike `--filter`, these modes ignore dependency order. It also brings HTTP/2 connection upgrades, disposable test mocks, explicit-proxy `NO_PROXY`, ESM bytecode, older ARM64 support, JavaScriptCore optimizations, and fixes including HTTP request smuggling. Commenters welcomed a cross-platform built-in runner but argued monorepos need dependency DAGs and content-aware caching, not blunt concurrency. Others said shell scripts suffice, debated “sequential” terminology, and wondered whether remaining WebSocket problems were fixed.

### Comment pulse

- Convenience is portable → built-in orchestration avoids Bash assumptions and extra packages, especially for Windows and containers.
- Flat concurrency cannot model builds → dependencies, shared prerequisites, incremental inputs, and caching require a DAG-aware scheduler.
- Simple shell remains viable → counterpoint: concise Bash handles many cases, but signal propagation and cross-platform support complicate portability.

### LLM perspective
