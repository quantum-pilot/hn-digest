# Vouch

- Score: 551 | [HN](https://news.ycombinator.com/item?id=46930961) | Link: https://github.com/mitchellh/vouch

### TL;DR

Vouch is an experimental, configurable gate for open-source participation: maintainers explicitly vouch for, unvouch, or denounce accounts, then GitHub Actions can allow or close pull requests accordingly. Decisions live in a flat “Trustdown” file; projects may import other lists to form a web of trust, while normal code review and permissions remain separate. The goal is to protect scarce maintainer attention from plausible-looking, low-understanding AI contributions. Commenters treated it as a spam filter, but worried cross-project inheritance creates supply-chain and account-takeover targets, excludes unknown experts, and encourages ideological bubbles.

### Comment pulse

- Inherited vouches expand reach but make trusted accounts attack targets—counterpoint: the gate grants review access, not merge rights, so existing review remains.
- Unknown experts may face exclusion; configurable projects can leave issues or discussions open, request demonstrations, or create lower-risk paths for earning trust.
- A proposed refundable submission fee internalizes review cost—counterpoint: abandoned repositories, payment friction, inequity, and incentives to retain fees could repel genuine fixes.
