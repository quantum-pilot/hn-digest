# RS-SDK: Drive RuneScape with Claude Code

- Score: 89 | [HN](https://news.ycombinator.com/item?id=46888142) | Link: https://github.com/MaxBittker/rs-sdk

### TL;DR

RS-SDK is an MIT-licensed research kit for building autonomous bots in a RuneScape-style MMO. It combines a TypeScript SDK, agent-oriented documentation and bindings, a browser bot client, gateway and LostCity-based server emulator. Claude Code can create a bot from a name, while manual scripts are also supported. The accelerated, bot-only environment is intended for goal-directed program synthesis and multi-agent competition or collaboration, with a playtime-adjusted leaderboard. Chat is disabled by default against prompt injection, and the demo offers neither uptime nor persistence guarantees.
