# OpenShot 4.0 – Open-source video editor

- Score: 564 | [HN](https://news.ycombinator.com/item?id=49507822) | Link: https://www.openshot.org/blog/2026/08/30/openshot-40-record-edit-color-like-never-before/

### TL;DR

OpenShot 4.0 adds dedicated color grading with scopes, synchronized screen-camera-audio recording, ten effects, and local ONNX-powered object masks. It completes a native Qt timeline, expands Qt 6 and modern Linux capture support, and reports faster effects, including a 61.8% Blur benchmark improvement over 3.5.1. Android groundwork is present but unsupported. Commenters welcomed the UI and offline masking, while many said their common need is lossless cutting; replies noted stream compatibility and keyframe boundaries make that a specialized workflow.

### Comment pulse

- Integrated recording and editable source tracks reduce setup → screen, webcam, microphone, and system audio remain separately adjustable.
- Local object masking preserves footage privacy → downloadable YOLO, EfficientSAM, and Cutie models avoid accounts and subscriptions.
- Lossless splicing should be easier → counterpoint: codec constraints make precise no-transcode editing unsuitable as a universal default.
