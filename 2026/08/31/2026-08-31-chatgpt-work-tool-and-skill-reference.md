# ChatGPT Work Tool and Skill Reference

- Score: 219 | [HN](https://news.ycombinator.com/item?id=49510000) | Link: https://codex-tool-reference.simonw.chatgpt.site/

### TL;DR

This static inventory distinguishes callable tools from reusable skills and captures one ChatGPT Work configuration: 232 tool interfaces—223 registry tools plus nine direct controls—and 44 complete primary skill files. It reproduces exposed descriptions, TypeScript declarations, and skill instructions across runtime, browser, web, automation, connected-app, analytics, document, and site workflows. The reference explicitly warns that availability depends on session configuration, permissions, installed plugins, and connections, so it documents an observed snapshot rather than promising every listed capability to every user.
