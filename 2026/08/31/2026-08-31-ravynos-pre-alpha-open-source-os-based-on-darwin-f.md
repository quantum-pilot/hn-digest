# RavynOS: Pre-alpha open-source OS based on Darwin, FreeBSD, Apple open-source

- Score: 200 | [HN](https://news.ycombinator.com/item?id=49511534) | Link: https://ravynos.com/

### TL;DR

ravynOS is a pre-alpha, open-source operating system combining Darwin, FreeBSD, and Apple-released code, with the long-term goal of running macOS applications without Apple hardware restrictions. Its planned experience includes global menus, Command-key shortcuts, application bundles, familiar filesystem layout, Cocoa APIs, and macOS-like utilities. The project explicitly targets developers rather than end users today. Commenters question whether Darwin offers much beyond compatibility groundwork, arguing that closed, extensive user-space frameworks—not the kernel—are the harder obstacle to meaningful application support.

### Comment pulse

- Darwin offers useful foundations → Mach IPC, XNU virtual memory, Mach-O linking, and DriverKit interest some developers.
- User space dominates compatibility → recreating Cocoa and proprietary frameworks may matter far more than matching kernel behavior.
- Presentation undersells progress → commenters found no screenshots despite the project emphasizing desktop design and polish.
