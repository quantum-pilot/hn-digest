# A walkable ASCII cyberpunk city in one HTML file [video]

- Score: 328 | [HN](https://news.ycombinator.com/item?id=49512975) | Link: https://www.youtube.com/watch?v=3YtygAx_C6A

### TL;DR

The project presents a work-in-progress cyberpunk city rendered entirely as ASCII characters through a custom JavaScript Canvas engine. A grid supplies roads, buildings, trees, vehicles, and pedestrians, while per-frame raycasting calculates perspective, depth, visibility, and collisions without conventional models, textures, or game engines. Commenters praise the atmosphere and browser delivery, but question whether added realism weakens the ASCII identity. Several also report that the purchasable prototype looks less clear than the update video, apparently because the showcased version is newer.
