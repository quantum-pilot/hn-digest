# Google has stopped pushing Git tags for some Android source code

- Score: 501 | [HN](https://news.ycombinator.com/item?id=49364745) | Link: https://grapheneos.social/@GrapheneOS/117057099753905023

### TL;DR

GrapheneOS says Google stopped publishing Git tags for Pixel kernel and userspace driver repositories, replacing direct access with manually handled Google Forms requests and Drive shares. Requests that once took hours or a day now reportedly take weeks or longer. The project says the change delayed its Android 16 port, though it has since worked around it, and helped motivate its Motorola partnership. It alleges unreasonable delays violate GPLv2; commenters dispute whether the license requires Git history, a URL, or a particular timetable.

### Comment pulse

- Discussion centered less on tags than slow, permission-gated access and lost revision metadata.
- GPL interpretations split: critics cited preferred modification form and customary interchange; others saw at most a violation of spirit.
- Several Pixel users welcomed GrapheneOS’s Motorola move or threatened to stop buying Google phones.
