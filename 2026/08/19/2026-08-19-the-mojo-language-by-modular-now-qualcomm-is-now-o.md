# The Mojo language (by Modular, now Qualcomm) is now open-source

- Score: 216 | [HN](https://news.ycombinator.com/item?id=49358327) | Link: https://www.modular.com/blog/modcon-announcements

### TL;DR

Modular released Mojo 1.0’s compiler and tooling under Apache 2.0, following earlier openings of its standard library and MAX kernels, and promises source stability plus forthcoming native Windows support. Modular Cloud is generally available with shared OpenAI-compatible and isolated dedicated endpoints; MiniMax’s M3 is a flagship deployment. The platform adds Trainium, TPUs, and Qualcomm accelerators alongside CPUs and GPUs, claiming over 10× lower bring-up effort. MAX loses device restrictions but remains merely source-available under an evolving license and alliance. Modular promises Qualcomm ownership will not end support for competing hardware.

### Comment pulse

- Enthusiasts welcomed full compiler access, broader hardware, and Mojo’s MLIR-based optimization and portable accelerator model.
- Critics cited missing Python-superset behavior, async support, limited traction, and disputed repository or benchmark quality.
- Acquisition pessimism met a counterpoint that open-sourcing had long been on Mojo’s roadmap.

### LLM perspective

- View: Mojo’s opening is substantive; MAX’s broader “open” positioning remains materially more limited.
- Impact: Developers can inspect, extend, and port the language while targeting more accelerator families through one stack.
- Watch next: Governance, Python compatibility, async, Windows delivery, production accelerator support, MAX licensing, and independent benchmarks.
