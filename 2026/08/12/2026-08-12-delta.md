# Delta

- Score: 552 | [HN](https://news.ycombinator.com/item?id=49276574) | Link: https://zed.dev/blog/introducing-delta

### TL;DR

Zed's private-beta Delta is a multiplayer environment for agent-driven software work, built around a replicated database that synchronizes conversation and worktree state while remaining compatible with ordinary Git. Participants can comment on evolving code and trace it back to the discussion that produced it; cloud agents continue after users leave, and the browser client shares Zed's Rust code through WebAssembly and WebGL. The separate app reflects a conversation-centered design, with plans to bring its replication layer into Zed. Readers debated whether collaborative provenance solves a real need.
