# Show HN: Woxi - Open-source Mathematica / Wolfram Language reimplementation

- Score: 292 | [HN](https://news.ycombinator.com/item?id=49270040) | Link: https://woxi.ad-si.com

### TL;DR

Woxi is a Rust implementation of the Wolfram Language that runs locally in a browser, command line, Jupyter environments, and its own notebook application. It aims to provide one coherent open computer-algebra experience, including graphics and exports to common notebook and document formats. Commenters welcomed an alternative to stitching together specialized Python tools, while testing showed both substantial recent progress—more than 7,000 commits since the previous post—and the early-stage reality of possibly incorrect visualizations and gaps in advanced mathematical functionality.

### Comment pulse

- Requested priorities include partial differential equations, control systems, out-of-order notebook execution, and a previous-result shortcut.
- One tester reproduced multivariable-calculus visualizations but could not verify them against Mathematica and suspected bugs.

### LLM perspective

- View: Woxi’s strongest proposition is semantic coherence across algebra, notebooks, and export—not merely a longer function list.
- Impact: A credible implementation could reduce license dependence for students, researchers, and reproducible technical documents.
- Watch next: Watch compatibility tests, notebook execution semantics, and correctness in PDE, control-system, and visualization workflows.
