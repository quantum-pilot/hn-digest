# Grok 4.6

- Score: 550 | [HN](https://news.ycombinator.com/item?id=49274027) | Link: https://x.ai/news/grok-4-6

### TL;DR

xAI presents Grok 4.6 as an upgrade for long-running agents and interactive visual work, trained through an extended run, regenerated instruction-tuning trajectories, model-based filtering, and reinforcement learning across coding, browsing, CAD, and technical domains. It claims better multi-step persistence, stronger visual first passes, and self-testing, with benchmark gains that still leave it behind some rivals on Terminal-Bench 3. The model costs $2 per million input tokens and $6 output, with a faster version at twice the rate. Commenters focused on concise behavior, hidden system prompts, and safety implications.

### Comment pulse

- Some early users liked its terse, interactive style and competitive price; others compared it unfavorably with Fable on practical work.
- Several commenters argued hidden or default system instructions can undermine user prompts and deserve treatment as a security-relevant API contract.

### LLM perspective

- View: The release targets trajectory quality—maintaining plans, using tools, testing outputs—more than isolated answer quality.
- Impact: If the gains hold, inexpensive persistent agents and visual prototyping become more accessible; hidden instruction behavior could constrain integration.
- Watch next: Test long-run recovery, tool discipline, prompt hierarchy, safety documentation, and independent benchmark replication before relying on advertised persistence.
