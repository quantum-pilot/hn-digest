# Firefox is now the last major browser that still supports uBlock Origin

- Score: 821 | [HN](https://news.ycombinator.com/item?id=49303202) | Link: https://www.pcworld.com/article/3212428/firefox-is-now-the-last-major-browser-that-still-supports-ublock-origin.html

### TL;DR

Firefox says its support for full uBlock Origin will continue as Microsoft Edge prepares to end Manifest V2 extensions and follow Chromium's Manifest V3 architecture. The article argues V3 removes capabilities needed for uBlock Origin's strongest filtering, leaving Firefox as the only major uncompromised option; Safari and DuckDuckGo do not support it, while other users must accept uBlock Origin Lite or built-in blockers. Commenters disputed the absoluteness because Brave maintains a custom V2 path, and debated whether V3's security benefits justify reduced extension power.

### Comment pulse

- Extension-freedom advocates see Chromium's dominance and Google's advertising incentives as structural threats to user-controlled filtering.
- Security defenders cite malicious extension takeovers and value declarative APIs—counterpoint: trusted uBlock Origin may warrant capabilities denied to ordinary extensions.
- Some find uBlock Origin Lite adequate, while others view Brave's compatibility as temporary engineering debt.
