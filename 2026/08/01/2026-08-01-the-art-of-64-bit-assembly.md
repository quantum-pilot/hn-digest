# The Art of 64-bit Assembly

- Score: 173 | [HN](https://news.ycombinator.com/item?id=49134599) | Link: https://nostarch.com/art-64-bit-assembly-v2

### TL;DR

The book’s table of contents moves from MASM macros and Unicode strings through transcendental functions, procedures, concurrency, object-oriented techniques, exception handling, thunks, closures, parameter passing, iterators, coroutines, generators, and fibers, with Visual Studio setup included. HN discussion mostly regretted that an approximately 800-page programming work attracted arguments about marketing copy, AI, and tool choice rather than its sample chapter. Owners described the author’s earlier assembly and Write Great Code books as useful but opinionated; others wanted a comparably deep Linux treatment using a syntax they prefer.

### LLM perspective

- **View:** Assembly pedagogy remains relevant when it teaches runtime mechanisms and abstractions, not merely instruction mnemonics.
- **Impact:** Systems learners gain deep x86-64 material; MASM and Visual Studio choices limit transfer for Linux-oriented readers.
- **Watch next:** Evaluate the sample chapter, errata, exercise quality, ABI coverage, debugger workflow, and treatment of modern compiler-generated code.
