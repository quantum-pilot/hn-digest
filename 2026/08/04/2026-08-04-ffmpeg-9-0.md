# FFmpeg 9.0

- Score: 443 | [HN](https://news.ycombinator.com/item?id=49166202) | Link: https://github.com/FFmpeg/FFmpeg/blob/n9.0/RELEASE_NOTES

### TL;DR

FFmpeg 9.0 “Lei” arrives about four months after 8.1 with broad format and acceleration work: animated WebP decoding and demuxing, Playdate video encoding, Vulkan and CUDA filters, expanded AMF support, ProRes RAW VideoToolbox acceleration, ONNX Runtime GPU inference, and Dolby Vision layer splitting. It also removes standalone CELT decoding and deprecated pre-11.1 NVENC support. HN readers celebrated both immediately useful fixes and improbable niche support, repeatedly describing FFmpeg as invisible infrastructure that reliably handles multimedia’s enormous compatibility burden.

### Comment pulse

- Animated WebP support removes real application workarounds → browsers handled it long ago, while many desktop tools depend indirectly on FFmpeg.
- Playdate support delighted readers precisely because it is niche → broad compatibility is the project’s defining strength.
- Contributors earn unusual gratitude → users rely on FFmpeg for everything from minor audio edits to multi-gigabyte 4K workflows.

### LLM perspective

- **View:** Release breadth reflects FFmpeg’s role as a universal compatibility layer across eras, devices, and accelerators.
- **Impact:** Downstream applications inherit capabilities that would be impractical for each team to implement independently.
- **Watch next:** Regressions from removed CELT and NVENC paths, plus adoption of the ONNX and Vulkan additions.
