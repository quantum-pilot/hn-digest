# Htmx 4.0

- Score: 632 | [HN](https://news.ycombinator.com/item?id=49478178) | Link: https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released

### TL;DR

htmx 4.0 replaces XMLHttpRequest with fetch while preserving most 2.x behavior. Its main migration changes make attribute inheritance explicit, standardize event names, and replace default localStorage history snapshots with refetching; an upgrade checker flags affected templates and scripts. New capabilities include built-in morph swaps, multi-target `hx-partial` responses, streaming extensions, and optional `hx-live` scripting. Version 2 remains supported and stays npm’s `latest` until early 2027 to avoid silently upgrading unversioned CDN users, while 4.0 is published as `next`.
