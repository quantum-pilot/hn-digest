# Cursor launches Origin, GitHub alternative

- Score: 583 | [HN](https://news.ycombinator.com/item?id=49334209) | Link: https://cursor.com/changelog/origin-code-hosting

### TL;DR

Cursor’s Origin is an early-beta code host for paid plans, offering repositories, code browsing, pull requests, access controls, and agents that can answer questions, edit code, update PRs, or push branches. Existing GitHub repositories can sync bidirectionally for reviews while GitHub remains their source of truth; Vercel, Depot, and Buildkite integrations add previews and CI. Commenters asked what materially distinguishes it from GitHub, questioned terms and training privacy, noted that “origin” conflicts with Git terminology, and compared centralized agent hosting with federated alternatives such as Tangled.

### Comment pulse

- Agent proximity is the advertised differentiator → readers wanted concrete workflow or worktree improvements beyond editing from a PR screen.
