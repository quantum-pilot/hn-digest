# GitHub down again? no PR access

- Score: 290 | [HN](https://news.ycombinator.com/item?id=49330632) | Link: https://news.ycombinator.com/item?id=49330632

### TL;DR

An Ask HN report said GitHub pull requests were inaccessible while GitHub’s status page still showed all systems operational. The merged discussion described unicorn errors, unexpected 404s, delayed releases, and repeated service degradations after an apparent mitigation. Commenters proposed rate-limiting automated or free-account traffic, but others warned pricing could weaken GitHub’s network effect and that capacity changes in legacy systems create new failure risks. Growing frustration pushed some toward Forgejo mirrors, although GitHub CLI, Actions, CI/CD configuration, and organizational inertia make full migration costlier than tolerating occasional downtime.
