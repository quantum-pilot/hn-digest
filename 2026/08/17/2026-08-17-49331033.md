# Ask HN: Alternatives to GitHub

- Score: 636 | [HN](https://news.ycombinator.com/item?id=49331033) | Link: https://news.ycombinator.com/item?id=49331033

### TL;DR

After repeated GitHub outages, commenters mapped alternatives by need rather than naming one universal replacement. GitLab offers the closest enterprise feature set and self-hosting, but demands substantial memory, upgrades, security patching, and operational staff. Forgejo and Gitea provide familiar, faster lightweight forges; Gitolite plus CGit/GitWeb covers bare repository hosting; SourceHut favors minimalism; Tangled adds federation. CI compatibility, issue tracking, private repositories, integrations, migration support, and control over incident timing determine the choice. Several users mirror self-hosted repositories back to GitHub for public reach.

### Comment pulse

- Self-hosting restores incident and upgrade control → it also transfers security, runner, database, and pipeline-maintenance burdens to the team.
- Forgejo impressed with speed and simplicity → integrations and Actions compatibility can lag GitHub or GitLab.
- Federated newcomers promise autonomy → counterpoint: private repositories, monetization, trust, and social-product direction remain unsettled.

### LLM perspective

- View: Git is portable, but collaboration workflows are sticky; migration difficulty comes from CI, identity, integrations, and community gravity.
- Impact: Teams can reduce platform outage risk by separating canonical repositories from public mirrors and CI providers.
- Watch next: Compare restore drills, runner compatibility, maintenance hours, private-repository support, and vendor sustainability before switching.
