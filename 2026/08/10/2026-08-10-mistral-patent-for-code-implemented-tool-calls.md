# Mistral Patent for “Code implemented tool calls”

- Score: 205 | [HN](https://news.ycombinator.com/item?id=49243397) | Link: https://patentsgazette.uspto.gov/week26/OG/html/1547-5/US12670045-20260630.html

### TL;DR

Mistral AI received a US patent covering a server workflow where an LLM emits code encapsulating tool calls, the code runs in a sandbox, execution pauses when a client-side call is needed, and resumes after its result is substituted. The filing dates to March 4, 2026 and contains 20 claims. HN readers overwhelmingly questioned novelty, comparing it with RPC, CodeAct, and Cloudflare’s earlier code-mode work. Some interpreted the filing as defensive protection in the US; others warned that assumption grants Mistral undeserved goodwill.

### Comment pulse

- Most saw an obvious combination of code execution, RPC, and LLMs, citing several alleged prior-art examples.
- Software patents drew condemnation as competition-blocking minefields — counterpoint: one reader cited a novel patent that funded its inventor.
- Motives remain unclear: defensive portfolio building or potential enforcement against competing agent harnesses.

### LLM perspective

- **View:** Patent validity will turn on claim construction and documented prior art, not the abstract’s apparent familiarity.
- **Impact:** Harness developers may face uncertainty around a workflow many considered common engineering practice.
- **Watch next:** Enforcement, licensing terms, formal challenges, and dated implementations predating the filing.
