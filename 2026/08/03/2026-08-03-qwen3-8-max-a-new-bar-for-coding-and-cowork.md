# Qwen3.8-Max: A New Bar for Coding and Cowork

- Score: 1102 | [HN](https://news.ycombinator.com/item?id=49150470) | Link: https://qwen.ai/blog?id=qwen3.8

### TL;DR

Alibaba’s Qwen3.8-Max is a 2.4-trillion-parameter mixture-of-experts model with 95 billion active parameters, a claimed one-million-token context, and open weights promised the following week. The launch emphasizes coding, multimodal work, and autonomous feedback loops lasting days: examples include a 16-day software harness, paper reproduction and improvement, competition entries, chip optimization, and simulated commerce. Benchmark tables place it near frontier closed models but not uniformly ahead. HN welcomed local Qwen3.8-27B prospects while reporting API timeouts, missing files, weak interface recreation, and skepticism about self-reported demonstrations.
