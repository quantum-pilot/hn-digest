# Developers are attached to tools because tools encode trust

- Score: 128 | [HN](https://news.ycombinator.com/item?id=49097961) | Link: https://stackoverflow.blog/2026/07/29/developers-are-attached-to-tools-because-tools-encode-trust/

### TL;DR
Developers stick to tools that stay stable because those tools embody hard-won muscle memory, workflows, and trust. Frequent, opaque changes—automatic updates, shifting UX, or AI agents with evolving models and prompts—break that trust and turn skilled users into frustrated operators of black boxes. Commenters contrast stable tools like Vim or `apt-get` with churn-heavy ecosystems, argue that product “velocity” often outpaces human learning capacity, and explore how to regain control via pinning versions, open tooling, and domain-specific agent interfaces.
