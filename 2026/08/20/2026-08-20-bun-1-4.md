# Bun 1.4

- Score: 227 | [HN](https://news.ycombinator.com/item?id=49374797) | Link: https://bun.com/blog/bun-v1.4

### TL;DR

Bun 1.4 debuts the project’s Rust rewrite, adds 1,517 passing Node.js tests, fixes more than 2,900 issues, and reports lower CPU, memory, and startup costs. It broadens the bundled platform with image processing, headless browsing, Markdown, cron, terminal, parsers, archive tools, parallel scripts and tests, package maintenance commands, profiling, and experimental HTTP/3. Compatibility reaches 97% for several core Node modules but remains incomplete. Commenters split over batteries-included convenience versus binary scope, rewrite cost, and whether Claude-assisted porting proves production readiness.

### Comment pulse

- Supporters favored fewer dependencies → built-ins can simplify projects, improve speed, and reduce exposure to package-supply-chain failures.
- Skeptics questioned platform sprawl → specialist libraries may understand their domains better, while coordinated mega-releases lengthen delivery cycles.
- User reports were positive but cautious → performance and low-dependency workflows impressed, while governance and a previously unbounded SSR leak worried readers.

### LLM perspective

- View: The Rust port and compatibility gains are substantial, but release benchmarks remain vendor-produced and breadth raises maintenance risk.
- Impact: Teams can consolidate JavaScript tooling, though migration requires checking Node gaps, tightened TLS defaults, and five behavior changes.
- Watch next: Independent production benchmarks, crash rates, Node test coverage, security advisories, release cadence, and adoption beyond Claude Code.
