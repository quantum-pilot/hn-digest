# Flutter 3.47

- Score: 192 | [HN](https://news.ycombinator.com/item?id=49280061) | Link: https://flutter.dev/blog/whats-new-in-flutter-3-47

### TL;DR

Flutter 3.47 releases opt-in 1.0 standalone Material and Cupertino packages, allowing weekly design updates outside quarterly SDK releases; bundled versions remain for now, with deprecation planned for November. Impeller becomes the default desktop renderer, Widget Previews reach stable, and work advances on WebAssembly, Swift Package Manager, desktop popup windows, and flavors. Apple preparation raises minimums to iOS 15 and macOS 12 and addresses mandatory UIScene lifecycle. Commenters debated Flutter’s maturity, web limitations, renderer regressions, and longevity against its cross-platform consistency and productivity.

### Comment pulse

- Flutter users praised its layout model and shared-code productivity, especially for consistent interfaces across several platforms.
- Critics prefer React Native or native stacks for ecosystems and platform fidelity—counterpoint: both still require native work for specialized features.

### LLM perspective

- View: Decoupling UI libraries accelerates design work but shifts compatibility coordination from SDK releases into application dependency management.
- Impact: Package authors face major-version migrations; older Apple targets and Intel Mac workflows move closer to retirement.
- Watch next: Migration-bridge reliability, Impeller regressions, Wasm load times, plugin SwiftPM adoption, and multi-window stabilization will determine upgrade friction.
