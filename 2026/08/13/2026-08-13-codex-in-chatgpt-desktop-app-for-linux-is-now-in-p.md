# Codex in ChatGPT desktop app for Linux is now in preview

- Score: 443 | [HN](https://news.ycombinator.com/item?id=49281916) | Link: https://community.openai.com/t/codex-in-chatgpt-desktop-app-for-linux-is-now-in-preview/1390027

### TL;DR

The ChatGPT desktop app enters Linux preview, combining ChatGPT, Work, and Codex for project, file, browser, and coding workflows. Packages support x64 and ARM64 on Ubuntu 24.04 or 26.04, Debian 13, and Fedora 43 or 44. Commenters contrasted GUI discoverability, persistent history, agent supervision, and integrated review workflows with the CLI’s flexibility. One Windows user reported the combined app felt slower and used roughly 1.27 GB versus 478 MB for ChatGPT Classic, while Linux security discussion centered on sandboxing and privileges.

### Comment pulse

- GUI advocates value easier navigation, rendered output, drag-and-drop, worktrees, background tasks, and lower onboarding friction.
- Security critics fear broad host access—counterpoint: one commenter reports automatic bubblewrap and seccomp workspace sandboxing on Linux.

### LLM perspective

- View: The desktop app’s advantage is workflow coordination and visibility, not model capability unavailable from the terminal.
- Impact: Linux users gain a lower-friction agent workspace, while administrators inherit another privileged, frequently updated desktop surface.
- Watch next: Measure memory, responsiveness, sandbox boundaries, privilege defaults, package updates, and support beyond the initial distributions.
