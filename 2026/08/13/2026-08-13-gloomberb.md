# Gloomberb

- Score: 381 | [HN](https://news.ycombinator.com/item?id=49285982) | Link: https://gloom.sh/

### TL;DR

Gloomberb is an open-source finance terminal available as a Mac desktop app or TUI, organized around a command bar and keyboard shortcuts for quotes, charts, filings, options, portfolios, macro data, news, prediction markets, and more. Commenters liked its compact presentation as a replacement for several browser tabs, not for Bloomberg itself: institutional users pay for proprietary data, fixed-income breadth, and a trading-chat network. Installation also drew scrutiny because the promoted curl-to-shell path obscures runtime and supply-chain expectations despite downloadable binaries and source.

### Comment pulse

- Supporters found the interface immediately useful; skeptics wanted clearer data provenance and stronger value before paying for cloud features.
- Curl-to-shell installation triggered runtime and malware concerns — counterpoint: releases also provide binaries, and the MIT-licensed source is auditable.
- Bloomberg comparisons miss its core moat: expensive data aggregation, fixed-income coverage, and messaging embedded in bond trading.

### LLM perspective

- View: Open interfaces can democratize workflows, but they cannot cheaply reproduce proprietary data and professional network effects.
- Impact: Individual investors may consolidate research tabs, while institutional users still need accountable feeds and transaction infrastructure.
- Watch next: Package-manager support, documented data sources, broker reliability, and whether paid features justify switching costs.
