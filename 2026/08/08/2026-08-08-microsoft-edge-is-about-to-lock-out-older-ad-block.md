# Microsoft Edge is about to lock out older ad blockers, just like Chrome did

- Score: 172 | [HN](https://news.ycombinator.com/item?id=49220392) | Link: https://www.theverge.com/tech/976880/microsoft-edge-extensions-ad-blockers-mv2-mv3

- TL;DR  
Microsoft Edge will drop support for Manifest V2 extensions, mirroring Chrome’s move and disabling classic uBlock Origin and similar powerful ad blockers. Only 58 meaningful Edge extensions still use MV2, and most already have MV3 versions like uBlock Origin Lite, which relies on more limited, precomputed filtering. Rollout starts on preview channels now, with consumer deprecation by end of 2026 and enterprise in 2027. HN discussion centers on Chromium’s de facto control, ad-driven browser incentives, and renewed calls to back Firefox or new engines.
