# LinkedIn Feed Blocker

- Score: 159 | [HN](https://news.ycombinator.com/item?id=49223475) | Link: https://github.com/andrewpollack/linkedin-feed-blocker

### TL;DR

LinkedIn Feed Blocker is a small Chrome extension that removes the home feed and its composer while preserving profiles, jobs, search, messaging, and notifications. CSS hides the main-feed element, and a narrowly targeted network rule stops further feed pagination without blocking other LinkedIn lists. The Chrome Web Store submission is pending, so installation currently requires loading the repository as an unpacked extension. HN readers welcomed a calmer job-search tool, requested connection-only filtering, and suggested unfollowing everyone or time-limiting `/feed`; an unsupported shadow-ban warning was challenged.

### Comment pulse

- Removing the feed preserves LinkedIn’s employment utility while eliminating promoted, suggested, and engagement-optimized posts.
- Connection-only filtering sounds better but can produce an empty feed because LinkedIn supplies so little direct-network content.
- A claimed shadow-ban risk lacks evidence; alternatives include unfollowing contacts or imposing a short URL time limit.
