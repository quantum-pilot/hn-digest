# LinkedIn Feed Blocker

- Score: 159 | [HN](https://news.ycombinator.com/item?id=49223475) | Link: https://github.com/andrewpollack/linkedin-feed-blocker

### TL;DR
A tiny Chrome extension removes LinkedIn’s home feed while leaving jobs, profiles, messaging, and search intact. It works by hiding the main feed DOM node and blocking further feed pagination, essentially turning LinkedIn into a static professional directory and inbox. HN commenters welcome anything that cuts LinkedIn’s engagement bait, discuss alternatives like custom filters, scripts, and time-blocking tools, and debate an unsubstantiated claim that LinkedIn detects DOM manipulation and shadowbans users, with others favoring lower-risk tactics like unfollowing everyone.
