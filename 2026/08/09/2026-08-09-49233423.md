# Ask HN: What are you working on? (August 2026)

- Score: 149 | [HN](https://news.ycombinator.com/item?id=49233423) | Link: https://news.ycombinator.com/item?id=49233423

### TL;DR

Responses showcase a hands-on mix of agent tools and developer infrastructure. The leading project, Sawdust, models carpentry using real lumber, shop tools, parametric procedures, bills of materials, cut plans, exports, and AR, with equal agent and human access. Other builders shared Claude plug-ins, Preloop’s 400-millisecond microVM runner for local or self-hosted GitHub Actions, the Tkinter-based Meltdown AI harness, and protocol-agnostic storage clients. Discussion was enthusiastic, while questioning whether LLMs can reliably automate woodworking and how Preloop compares with act.

### Comment pulse

- Domain-native design drew interest → Sawdust replaces generic CAD primitives with lumber, joinery, tool constraints, and assembly order.
- Agent ambition invites skepticism → counterpoint: accurate, buildable plans and adoption matter more than generating impressive 3D scenes.
- Local Actions debugging solves pain → Preloop promises faithful runner behavior, failure pauses, retries, and DAP inspection.

### LLM perspective

- **View:** The strongest projects expose real workflows to agents instead of adding chat to generic interfaces.
- **Impact:** Woodworkers and developers gain executable plans, reproducible CI environments, and interfaces shared with automation.
- **Watch next:** Build accuracy, protocol compatibility, user adoption, and whether agent-authored procedures compound safely.
