# The original URL for this prediction will no longer be available in 11 years (2011)

- Score: 198 | [HN](https://news.ycombinator.com/item?id=49228458) | Link: http://longbets.org/601/

### TL;DR

In 2011, Jeremy Keith wagered that a specific Long Bets page would disappear within eleven years; Matthew Haughey bet that stable URL practices could preserve it. The 2022 test required the original HTTP address—or a 301 redirect—to return an HTML document containing the prediction’s exact text. The page records Haughey as the winner, making the bet a self-referential demonstration that persistence is technically achievable when an institution is motivated. Discussion noted that other Long Bets pages have vanished, so one maintained URL does not settle link rot generally.
