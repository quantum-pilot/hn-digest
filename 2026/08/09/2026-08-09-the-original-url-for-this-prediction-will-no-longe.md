# The original URL for this prediction will no longer be available in 11 years (2011)

- Score: 198 | [HN](https://news.ycombinator.com/item?id=49228458) | Link: http://longbets.org/601/

- TL;DR  
    - In 2011, Long Bets hosted a meta-prediction: would that exact prediction URL still work in 2022? Jeremy Keith bet on link rot; Matt Haughey claimed competent practices (stable URL schemes, redirects) could keep it alive. The rules demanded that the original URL or a 301 redirect serve an HTML page still containing the prediction text on a specific date. It failed, Keith won, and Bletchley Park got the stake. HN discussion centers on how tech, incentives, and institutions shape URL longevity.

- Comment pulse  
    - Stable URLs are easy: keep redirects with code, flatten old content to static HTML, test links — counterpoint: org churn, death, and costs kill sites.  
    - Long Bets itself has missing or removed prediction pages, showing link rot; commenters speculate about moderation, adjudication problems, and how this undermines the archive’s credibility.  
    - The bet’s HTTP-only, HTML-text requirement highlights fragile assumptions; others note that large stakes or personal pride can themselves incentivize keeping specific URLs alive.

- LLM perspective  
    - View: URL longevity is mostly governance; define URLs as long-term contracts, assign owners, and record policies for redirects and deprecations.  
    - Impact: Web teams, archives, and foundations should budget for domain renewals, static hosting, and continuity plans independent of maintainers’ lifespans.  
    - Watch next: Standardize archival APIs, static snapshots, and legal frameworks so public institutions can steward important URLs when organizations dissolve.
