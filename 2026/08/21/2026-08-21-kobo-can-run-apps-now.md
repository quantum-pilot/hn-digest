# Kobo can run apps now

- Score: 628 | [HN](https://news.ycombinator.com/item?id=49390427) | Link: https://bandarlabs.github.io/Cobalt/

### TL;DR

Cobalt is an AGPLv3 app platform for the Kobo Clara BW: one USB install adds a launcher, signed Wi-Fi store, Rust SDK, and runtime. Static ARM apps run as separate unprivileged processes and request capability-gated network, storage, audio, frontlight, or Wi-Fi access; signatures are checked before launch, updates are recovery-safe, and rebooting returns to Kobo’s reader. Apps include arXiv, feeds, OPDS, Hacker News, terminal, games, audiobooks, and coding-agent approvals. Only exact Clara BW hardware and firmware are tested. Commenters split over versatility versus distraction-free reading.

### Comment pulse

- NickelMenu, KOReader, and PostmarketOS already extend Kobos; the author says Cobalt uses NickelMenu but targets app delivery and isolation.
- Hardware discussion weighed dual-core color models against the BW screen’s sharper text and stronger contrast.
- Some welcomed service integrations yet rejected games and general apps that could break an e-reader’s single-purpose appeal.
