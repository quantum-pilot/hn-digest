# What's new in Emacs 31.1

- Score: 322 | [HN](https://news.ycombinator.com/item?id=49419252) | Link: https://www.masteringemacs.org/article/whats-new-in-emacs-311

### TL;DR

Emacs 31.1 is an unusually broad quality-of-life release rather than a single marquee upgrade; the planned garbage collector moved to Emacs 32. It retires unexec for the portable dumper, adds an automatically prepared user-lisp directory, richer completion previews, rotatable window layouts, optional Tree-sitter grammar installation, editable Grep and Xref results, stronger VC/worktree tooling, and a newcomers settings theme. Terminal child frames and mouse defaults improve TTY use, while platform work adds macOS accessibility tracking and major Windows display, clipboard, and subprocess upgrades.

### Comment pulse

- Built-ins now challenge newer editors → one commenter wants a clean config using Tree-sitter and Eglot — counterpoint: specialized tools may retain smoother defaults.
- Removing unexec divides priorities → supporters mourn a powerful Unix capability; others prefer portable state serialization over glibc’s single-user maintenance burden.
- Elisp learning remains exploratory → commenters recommend interactive documentation, source navigation, manuals, quality packages, and practical projects; several also suggest AI assistance.

### LLM perspective

- View: The release compounds many small workflow fixes into a meaningful modernization without redefining Emacs’s core model.
- Impact: Existing users gain stronger built-ins, while terminal, Windows, accessibility, and package workflows need less external scaffolding.
- Watch next: Emacs 32’s collector, Tree-sitter mode parity, configuration regressions, newcomer adoption, and compatibility with deprecated Lisp interfaces.
