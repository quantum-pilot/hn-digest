# Coding expertise is going to collapse from AI reliance

- Score: 536 | [HN](https://news.ycombinator.com/item?id=49421554) | Link: https://larsfaye.com/articles/ai-coding-will-prevent-expertise

### TL;DR

The essay warns that code generators create an expert-novice paradox: developers need judgment to steer and audit models, yet bypassing difficult work prevents that judgment from forming. Cited studies found unrestricted assistance encouraged skipped planning and illusory competence; students learning mathematics without guardrails later scored 17% worse. Socratic tutoring preserved cognitive effort, improving practice without beating textbook learners on the test. Commenters reported enterprise artifact overload but argued tightly guided, incrementally reviewed assistance can increase productivity while keeping engineers engaged.

### Comment pulse

- Mandated generation floods teams with unreadable artifacts → engineers spend growing effort filtering verbose tickets and code nobody can honestly review.
- Guided coding retains agency → fast models handle mechanical details while developers plan, veto edits, and inspect each increment.
- Friction may migrate upward → curious engineers seek harder system problems — counterpoint: instant answers can suppress the curiosity that finds them.
