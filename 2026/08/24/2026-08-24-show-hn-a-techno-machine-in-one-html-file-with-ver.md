# Show HN: A techno machine in one HTML file, with verifiable renders

- Score: 225 | [HN](https://news.ycombinator.com/item?id=49419351) | Link: https://ssx360.github.io/rack-02/?src=hn

### TL;DR

RACK-02 is a browser-based techno workstation packaged as one dependency-free HTML file. It generates seeded loops, rerolls or mutates patterns, chains and morphs four scenes, automates controls, routes modulation cables, processes live voice, and sequences kick, rumble, bass, percussion, stab, drone, and noise voices. Performance pads add fills, drops, stutters, and freezes. Offline rendering exports sample-exact loops, songs, kits, aligned stems, or MIDI, while live capture includes microphone input. Commenters praised its portable local operation and polished interface, while requesting unrestricted melody composition and faster tempos.
