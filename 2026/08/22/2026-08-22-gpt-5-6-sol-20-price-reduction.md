# GPT 5.6 Sol 20% price reduction

- Score: 87 | [HN](https://news.ycombinator.com/item?id=49396590) | Link: https://developers.openai.com/api/docs/models/gpt-5.6-sol

### TL;DR

GPT-5.6 Sol API pricing is listed at $4 per million input tokens and $20 per million output tokens, reductions of 20% and 33%, respectively. The promotional rates last at least through 21 November 2026; requests exceeding 272,000 input tokens charge double input and 1.5 times output rates for the entire request. The model offers a 1.05-million-token context window and multiple reasoning efforts. Commenters credited competitive pressure but disputed model quality, strategic intent, and whether API savings would bring higher Codex subscription limits.

### Comment pulse

### LLM perspective

- View: The headline understates output savings, while the long-context multiplier can outweigh base-rate reductions on large requests.
- Impact: API users save on ordinary workloads; long-context users must model threshold effects, caching, output volume, and promotional expiry.
