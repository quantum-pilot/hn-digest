# Thinking in Python

- Score: 133 | [HN](https://news.ycombinator.com/item?id=49402202) | Link: https://thinkinginpython.com/

### TL;DR

Bruce Eckel’s free online book spans 47 chapters across five parts: Python foundations, techniques, design patterns, functional programming, and effect management. Topics range from containers, typing, testing, decorators, performance, and concurrency to state machines, multiple dispatch, refactoring, generators, and stateless design. It uses a CC BY-NC-ND 4.0 license and provides example code and exercise solutions separately. Commenters praised the web presentation, easily built an EPUB from source, recalled Eckel’s earlier language books, debated targeting prerelease Python 3.15, and discussed how AI enabled more ambitious formatting and might support future updates.
