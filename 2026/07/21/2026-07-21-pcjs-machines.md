# PCjs Machines

- Score: 184 | [HN](https://news.ycombinator.com/item?id=48992323) | Link: https://www.pcjs.org/

### TL;DR

PCjs is an MIT-licensed JavaScript preservation project that runs classic computers and software directly in desktop or mobile browsers. Its catalog spans IBM PCs and compatibles, DEC PDP systems, VT100 terminals, TI calculators, Space Invaders, operating systems, programming tools, applications, games, magazines, manuals, and disk archives. Hacker News highlighted remarkable interoperability: one reader built a Visual Basic executable inside emulated Windows 3.1 on an Apple Silicon Mac, exported it, and ran it unchanged on a 1992 486. Discussion balanced accessible emulation against imperfect fidelity and aging-hardware authenticity.
