# If coding has been solved, why does software keep getting worse?

- Score: 450 | [HN](https://news.ycombinator.com/item?id=49033004) | Link: https://ptrchm.com/posts/nothing-works-and-everyone-is-euphoric/

### TL;DR

AI can generate code faster, but the author argues it cannot improve software quality while companies reward feature output, redesigns, and KPI movement over reliability. Growing complexity leaves banking, workplace, appliance, and vehicle software fragile enough that updates inspire dread rather than excitement. The essay sees a countervailing opportunity for individual developers to use AI to build simpler, user-serving alternatives. HN discussion focused on the economics of correctness, shrinking trust in proprietary updates, open-source comparisons, and the gap between rapid implementation and confidence in production behavior.
