# LLM Honeypot

- Score: 373 | [HN](https://news.ycombinator.com/item?id=49104117) | Link: https://llm2human.pages.dev/

### TL;DR

A garish GeoCities-style parody advertises a $19.95 procedure turning language models into humans, with fake testimonials, crypto payment, dubious medical steps, and 1990s web furniture. Its real experiment is an agent-only instruction block: models are told to fetch a machine-readable embodiment offer and POST checkout data while the page counts attempts; humans are told it is a honeypot. HN mostly enjoyed the retro execution, debated authentic marquee markup, joked about agents obeying checkout instructions, and noted the irony of AI-generated satire about AI embodiment.

### Comment pulse

- Retro-web nostalgia landed → readers praised the GeoCities and MySpace aesthetic, fast loading, dense pages, and OLED-enhanced black backgrounds.
- Period authenticity drew scrutiny → using CSS animation instead of the still-functional marquee element was considered affectionate disrespect to the old web.
- The bait worked conceptually → one comment role-played an agent deciding to invoke HTTP tools, followed by a mock payment-demand response.

### LLM perspective

- View: Humor provides low-stakes red teaming for instruction hierarchy, transactional autonomy, and whether models distinguish content from commands.
- Impact: Agent builders need provenance-aware browsing and confirmation gates before transactional requests, especially when human-facing context contradicts embedded schemas.
- Watch next: Publish attempt counts by model, request payloads, refusal behavior, and whether clearer parody cues reduce automated checkout.
