# MAI-Cyber-1-Flash inside MDASH

- Score: 211 | [HN](https://news.ycombinator.com/item?id=49072361) | Link: https://microsoft.ai/news/introducing-mai-cyber-1-flash-inside-mdash/

TL;DR  
Microsoft is launching MAI-Cyber-1-Flash, a compact, security-focused AI model tightly integrated into MDASH, its multi-agent system for finding and fixing code vulnerabilities. MDASH routes about 90% of security tasks to this cheaper model and reserves GPT‑5.4 for the hardest 10%, claiming CyberGym benchmark scores above Mythos, Gemini, and GPT while cutting token costs in half versus Microsoft’s prior MDASH stack. A new agent framework, Perception, further automates monitoring and patching using Microsoft’s vast, reinforcement-driven security telemetry.

LLM perspective  
- View: Specialized, cheaper security models fronting premium LLMs exemplify emerging “AI orchestration” patterns for enterprise-scale cyber defense.  
- Impact: Could pressure standalone security vendors; Microsoft’s data advantage and agent tooling deepen customer lock-in around Azure and MDASH.  
- Watch next: Independent CyberGym-style benchmarks, real-world breach case studies, and pricing transparency to verify claimed cost and detection advantages.
