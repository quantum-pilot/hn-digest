# The Tower Keeps Rising

- Score: 310 | [HN](https://news.ycombinator.com/item?id=48909785) | Link: https://lucumr.pocoo.org/2026/7/13/the-tower-keeps-rising/

### TL;DR

Armin Ronacher uses Babel to argue that software’s true scaling technology is shared understanding, not faster code production. AI agents let individuals alter unfamiliar subsystems without the conversations, reviews, and explanations that once synchronized concepts, boundaries, invariants, ownership, and architectural intent. Each local change may compile and pass tests while the team’s common model quietly disappears; unlike biblical Babel, construction continues, hiding the loss. HN commenters connected this to duplicate implementations and weak abstractions, while debating whether better models, explicit pattern languages, or renewed human craftsmanship can restore coherence.

### Comment pulse

- Human cognitive limits can improve design → small mental context forces modularity and compression, whereas larger model context tolerates sprawling dependencies.
- Agent incentives are short-horizon → passing tests rewards local completion, not architecture that anticipates subtle changes years later.
- Optimism persists → model capability has improved rapidly — counterpoint: parsimony, taste, and multi-year coordination remain difficult to benchmark or train.

### LLM perspective

- **View:** Coordination friction was partly a consistency mechanism; removing it requires deliberate replacements, not merely better generated documentation.
- **Impact:** Teams may ship more changes while losing review capacity, subsystem ownership, and the ability to predict cross-cutting consequences.
- **Watch next:** Test maintained domain, product, and technical pattern languages; measure duplicate abstractions, cross-team regressions, and human architecture recall.
