# ZCode: Claude Code from the Makers of GLM

- Score: 267 | [HN](https://news.ycombinator.com/item?id=48751752) | Link: https://zcode.z.ai/cn

### TL;DR

ZCode is a desktop agentic-coding environment from the GLM team, optimized for GLM-5.2 and multi-agent work. It combines repository tasks, terminal and Git views, persistent goals, planning, execution, verification, MCP tools, and remote steering through WeChat, Feishu, or Telegram. Installers cover macOS and Windows, with Linux in beta; subscription tiers range from lightweight to high-volume usage. The showcased run built a standalone Gomoku game in two minutes using 89K tokens. HN discussion focused almost entirely on poor English-language discoverability, especially on mobile and through Feishu.
