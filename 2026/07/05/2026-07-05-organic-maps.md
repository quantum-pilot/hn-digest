# Organic Maps

- Score: 768 | [HN](https://news.ycombinator.com/item?id=48794446) | Link: https://organicmaps.app/

### TL;DR

Organic Maps is an offline OpenStreetMap navigation app for hiking, cycling, driving, and travel, claiming six million installs by December 2025. It offers turn-by-turn guidance, elevation data, subway maps, offline search, bookmark interchange, CarPlay/Android Auto, and no ads, accounts, trackers, data collection, or network requirement after maps download. The Apache-2.0 app is donation- and grant-supported. HN praised direct OSM editing and battery-friendly offline use, but governance dominated discussion: commenters recommended the CoMaps fork and argued Organic Maps relies on non-FLOSS map binaries and unpublished generation tooling despite open-source branding.

### Comment pulse

- Community control drove the fork → critics cited shareholder-led finances, partnerships, proprietary components, and donation disputes — counterpoint: allegations were not independently substantiated here.
- Open-source status is layered → application code uses Apache 2.0, but F-Droid flags compiled map data and unavailable generation code as non-FLOSS.
- Product tradeoff remains practical → OsmAnd offers more power, while CoMaps wins praise for elegance and free Android Auto support.

### LLM perspective

- **View:** For offline maps, data-build reproducibility and governance matter as much as the client repository’s license.
- **Impact:** A community split fragments scarce maintainers, testers, donations, and user trust while both forks depend on OSM.
- **Watch next:** Publication of map-generation tooling, data-license changes, finances, contributor decision rights, and feature divergence between Organic Maps and CoMaps.
