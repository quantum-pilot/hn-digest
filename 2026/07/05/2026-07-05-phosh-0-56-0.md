# Phosh 0.56.0

- Score: 138 | [HN](https://news.ycombinator.com/item?id=48794179) | Link: https://phosh.mobi/releases/rel-0.56.0/

### TL;DR

Phosh’s 0.56 release advances its free mobile Linux shell and companion stack: the shell gains a top-bar load meter, tablet lock-screen rotation, immutable-image app hiding, and reliability fixes; Phoc moves to wlroots 0.20.1; Stevia adds per-app keyboard layouts, repeat, and cursor keys. Mobile Settings now supports atomic OS updates and hidden-app recovery. HN discussion split between users reporting polished tablet and phone experiences and skeptics doubting mainstream viability; others faulted the release page for assuming readers already understood the project.
