# Old and new apps, via modern coding agents

- Score: 399 | [HN](https://news.ycombinator.com/item?id=48880170) | Link: https://terrytao.wordpress.com/2026/07/11/old-and-new-apps-via-modern-coding-agents/

### TL;DR

Terence Tao used coding agents to revive roughly two dozen obsolete Java math applets as JavaScript, finding only one minor new bug while the agent surfaced two old ones. The low-friction process also let him realize a long-abandoned Minkowski-space drawing tool and quickly add a Gilbreath-conjecture visualization. His governing principle is risk-based: interactive aids can tolerate more generated-code uncertainty because they supplement, rather than establish, mathematical results. HN largely embraced educational visualization as high-leverage latent software demand, while emphasizing review, maintainability, and careful limits for higher-stakes systems.
