# Anthropic's Method to Losing Goodwill in a Few Easy Steps

- Score: 236 | [HN](https://news.ycombinator.com/item?id=48803751) | Link: https://raheeljunaid.com/blog/anthropics-method-to-losing-goodwill-in-a-few-easy-steps/

### TL;DR

The author argues Anthropic is eroding developer trust by tying Claude subscriptions to its own tools, charging API rates for many third-party harnesses, changing billing rules, and offering a buggy, outage-sensitive Claude Code experience. A proposed June 15 split would have limited Agent SDK usage to $20–$200 credits before API billing, but Anthropic paused or rolled it back after backlash; the article also acknowledges improved July reliability and Agent SDK access. After agent-driven work reduced code understanding, the author shifted toward assistive autocomplete and configurable gateways using several open models.
