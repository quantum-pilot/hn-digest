# Kimi Work

- Score: 345 | [HN](https://news.ycombinator.com/item?id=48981703) | Link: https://www.kimi.com/products/kimi-work

### TL;DR

Kimi Work is a macOS and Windows desktop agent that mounts local folders, automates browser tasks through WebBridge, runs Python or shell jobs on schedules, coordinates agent swarms, generates PowerPoint and Excel outputs, and integrates global market data. It promises confirmation before writing files or executing code, though its page does not explain read-access or data-handling boundaries. Hacker News saw strong visual and functional resemblance to Codex and Claude products, debating whether that signals copying or inevitable interface convergence, and whether low-cost models can commoditize both model and application layers.
