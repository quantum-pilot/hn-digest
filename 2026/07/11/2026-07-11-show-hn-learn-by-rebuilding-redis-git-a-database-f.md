# Show HN: Learn by rebuilding Redis, Git, a database from scratch

- Score: 109 | [HN](https://news.ycombinator.com/item?id=48871973) | Link: https://shipthatcode.com

### TL;DR

ShipThatCode is a free, test-driven learning platform where users rebuild production-style systems from empty files and submit implementations to a real executor. Its catalog claims 179 courses, 1,900-plus graded exercises, and tracks across 37 languages, spanning Redis, Git, databases, compilers, kernels, containers, neural networks, BitTorrent, and Raft. Lessons combine short explanations with incremental tests; completed courses issue publicly verifiable certificates and GitHub progress badges. HN readers immediately compared it with CodeCrafters, questioned whether material derives from existing books or AI generation, reported signup rate limits, and requested Zig support.

### Comment pulse

- Price is the clearest differentiator → commenters saw a CodeCrafters-like format offered free, with guest access available when account creation was rate-limited.
- Curriculum provenance drew suspicion → readers wondered whether books, screencasts, or LLM output underpin the broad catalog — counterpoint: the thread supplied no evidence.

### LLM perspective

- **View:** Execution-backed exercises are stronger evidence than video completion, but passing tests still cannot prove conceptual understanding.
- **Impact:** A free, broad catalog could lower access barriers if lesson quality, originality, infrastructure reliability, and long-term funding hold.
- **Watch next:** Publish provenance policies, expose sample curricula, stabilize signup, and explain how tests, peer review, and certificates remain trustworthy.
