# Show HN: Echo – Fable-level results at 1/3 the cost using open-weight models

- Score: 186 | [HN](https://news.ycombinator.com/item?id=49026810) | Link: https://news.ycombinator.com/item?id=49026810

### TL;DR

Echo treats several open-weight models as one adaptive system: for each request it chooses participating models, compute budget, and how to combine intermediate work. Its creator reports that this beats every individual pool member and roughly matches Fable across an initial evaluation mix at one-third the inference cost, while acknowledging allocation failures and unfinished coding/agentic validation. A chat UI and OpenAI-compatible API enable testing. HN readers recognize familiar ensemble/router ideas but challenge the headline’s benchmark representativeness, undisclosed per-request routing, cache disruption, and relevance versus subsidized subscriptions.
