# NotebookLM is now Gemini Notebook

- Score: 218 | [HN](https://news.ycombinator.com/item?id=48936451) | Link: https://blog.google/innovation-and-ai/products/gemini-notebook/notebooklm-gemini-notebook/

### TL;DR

Google has renamed NotebookLM to Gemini Notebook while keeping it a standalone research product. The substantive upgrade is a secure cloud computer for each notebook, enabling code execution for source-grounded analysis and new outputs. It is available now to AI Ultra users and eligible Workspace customers; Pro web access is promised within weeks. Notebooks already sync with the Gemini app, and integration with Search’s AI Mode is planned. Google says the service has surpassed 30 million users and 600,000 organizations since its 2023 debut as Project Tailwind.
