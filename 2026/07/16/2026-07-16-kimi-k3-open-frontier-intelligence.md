# Kimi K3: Open Frontier Intelligence

- Score: 1057 | [HN](https://news.ycombinator.com/item?id=48935342) | Link: https://www.kimi.com/blog/kimi-k3

### TL;DR

Moonshot AI’s Kimi K3 is a 2.8-trillion-parameter, native-vision mixture-of-experts model with a one-million-token context window, activating 16 of 896 experts. Its Kimi Delta Attention, Attention Residuals, and Stable LatentMoE reportedly improve scaling efficiency 2.5× over Kimi K2. K3 is available by API and apps, with full weights promised by July 27; API pricing is $3 per million uncached input tokens and $15 per million output tokens. Moonshot claims frontier coding and knowledge-work performance, but acknowledges weaker user experience, unstable history handling, over-proactiveness, and a gap behind top proprietary systems.
