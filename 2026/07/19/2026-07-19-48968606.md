# Show HN: I replaced a $120k bowling center system with $1,600 in ESP32s

- Score: 1308 | [HN](https://news.ycombinator.com/item?id=48968606) | Link: https://news.ycombinator.com/item?id=48968606

### TL;DR

An SRE restoring an abandoned eight-lane rural bowling center built OpenLaneLink, a commodity-hardware replacement for a proprietary scoring and control system quoted at $80,000–$120,000. Each lane pair costs about $200, or $400 fully equipped, using ESP32 nodes, ESP-NOW with RS485 fallback, sensors, relays, and a Raspberry Pi running Redis and a state machine. Components swap in minutes, data stays local, and React developers can customize displays. Hacker News saw a broader retrofit opportunity for aging industrial machinery and enthusiast venues, while offering practical lighting and operations advice.
