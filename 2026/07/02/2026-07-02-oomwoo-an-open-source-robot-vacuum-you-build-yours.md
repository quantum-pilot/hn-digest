# Oomwoo, an open-source robot vacuum you build yourself

- Score: 452 | [HN](https://news.ycombinator.com/item?id=48755005) | Link: https://makerspet.com/blog/building-an-open-source-robot-vacuum-meet-oomwoo/

### TL;DR

OOMWOO is an early, build-in-public robot-vacuum project promising open hardware, firmware, and software; local ROS 2 navigation with 2D LiDAR; Home Assistant integration; 3D-printable parts; and no required cloud. Hardware designs, firmware, and documentation remain unfinished, but simulation and the development environment are available, with modular contribution requests intended for parallel community work. HN liked the repairability and control, yet questioned economics: piecemeal parts may cost far more than commodity LiDAR vacuums, making retrofits, salvaged components, or a standard white-label chassis potentially more practical.

### Comment pulse

- Full DIY may target learning, not savings → a working budget vacuum can cost less than OOMWOO’s wheels alone.
- Retrofitting could preserve openness economically → reuse commodity mechanics and sensors while replacing proprietary control electronics and software.
- Distributed hardware collaboration is harder than code → binary design files and physical interfaces demand unusually strong communication — counterpoint: modular RFCs enable specialization.
