# Bitchat is now on Radicle

- Score: 195 | [HN](https://news.ycombinator.com/item?id=49047365) | Link: https://radicle.network/nodes/rosa.radicle.network/rad%3Az2v9tRJz1oknFAqCSY5W5c76nVvm6

### TL;DR

Bitchat’s public-domain code is now hosted on Radicle. The iOS/macOS messenger combines offline Bluetooth LE mesh networking with Nostr relays for internet reach. It requires no accounts, phone numbers, or central server, and supports encrypted private messages, location channels, automatic transport fallback, smart queuing, and up to seven Bluetooth hops. HN readers see promise for protests, disasters, and disconnected travel, but real-world observations suggest adoption density constrains usefulness. Discussion also questions Android distribution, maintenance activity, and whether existing Bluetooth messengers already cover the niche.

### Comment pulse
