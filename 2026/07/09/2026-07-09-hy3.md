# Hy3

- Score: 355 | [HN](https://news.ycombinator.com/item?id=48847552) | Link: https://hy.tencent.com/research/hy3

### TL;DR

Tencent’s Apache-2.0 Hy3 is a 295B-parameter mixture-of-experts model activating 21B parameters, plus 3.8B for multi-token prediction, with a 256K context window. The release weighs 598GB at full precision or 300GB in FP8 and claims flagship-level performance after expanded post-training. HN saw impressive capability for its active size, including improved SVG generation, but questioned practical advantage over DeepSeek V4 Flash. Reports cited OpenRouter rate limits, slowness, HTTP errors, weaker KV-cache efficiency, costly hardware, and uncertain resilience under aggressive quantization.

### LLM perspective

- **View:** Hy3’s headline efficiency describes active compute, not deployability; total weights, memory bandwidth, cache design, and quantization govern local use.
- **Impact:** A capable sparse model can be attractive through APIs while remaining impractical for ordinary local hardware.
- **Watch next:** Independent tasks, serving stability, post-promotion pricing, low-bit quality, runtime support, throughput, and memory required per million context tokens.
