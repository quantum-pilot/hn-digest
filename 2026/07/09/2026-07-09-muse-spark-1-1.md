# Muse Spark 1.1

- Score: 309 | [HN](https://news.ycombinator.com/item?id=48846184) | Link: https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/

### TL;DR

Meta’s Muse Spark 1.1 is a multimodal reasoning model for long-running agents, coding, computer use, and orchestration across tools and subagents. It offers a million-token context, adaptive compaction, visual and audio understanding, and public-preview access through an OpenAI-compatible Model API. Meta claims faster execution, stronger coding, improved robustness, and competitive internal results. HN liked reported per-million-token rates of $1.25 input and $4.50 output, but challenged a Terminal-Bench run using resources above official task limits. Discussion emphasized independent evaluation and weighed cheap proprietary APIs against open-weight commoditization.
